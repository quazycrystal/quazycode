리스트를 공백 두고 출력하는 방법은 여러가지가 있음
join도 있고
근데 편한 건 그냥 별 찍자 (리스트 뜯어쓸 때도 용이 - ex `list(zip(*arr)))`)
f-string 안에는 못 쓰므로 ,를 찍어서 이어서 출력
***

```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):

    n = int(input())
    input_list = list(map(int,input().split()))
    sorted_list = []
    for i in range (10):
        if i % 2 == 0:
            maxi = max(input_list)
            sorted_list.append(maxi)
            input_list.remove(maxi)
        else:
            mini = min(input_list)
            sorted_list.append(mini)
            input_list.remove(mini)
    # 출력 for 문
    '''for i in sorted_list:
        print (i, end = " ")'''
    print (f'#{test_case}', *sorted_list) # Iterable unpacking!! * 붙여서 리스트 요소 따로 출력
```
==별 써서 출력하면 기본 구분자는 공백!!!==
공백 없이 쓰려면 "".join(iterable) 메소드 사용
