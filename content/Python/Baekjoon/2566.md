```python
# 2차원 리스트로 값 받기  
lst = [list(map(int, input().split())) for _ in range (9)]  
# 1차원으로 넣어서 나누면 나머지가 0-8이 나오고, 나머지 9인 경우 몫이 되므로 헷갈리고 복잡해 짐  
mx = 0  
row = 0  
col = 0  
for i in range (9):  
    for j in range (9):  
        if lst[i][j] >= mx: #모든 arr가 0일때는 row, col이 들어오지 않음  
            mx = lst[i][j]  
            row = i+1  
            col = j+1 #idx 보정  
print(mx)  
print(row, col)
```
극단적 edge case! 무조건 끝 값으로 다 채워져 있는 것을 생각...
