### 1. `list(input())` : 믹서기로 갈아버림

`list()` 함수는 괄호 안에 들어온 놈을 **"하나하나 낱개로 분해해서"** 담습니다.
`list()`는 괄호 안에 들어온 녀석을 **가장 작은 단위(글자 하나하나)**까지 인정사정없이 분해합니다. 띄어쓰기조차 하나의 문자로 취급해서 뜯어냅니다.
- **입력:** `"10 20"` (두 자리 숫자 10과 20)
- **코드:** `list("10 20")`
- **결과:** **`['1', '0', ' ', '2', '0']`** 😱
- **설명:** 10이 깨져서 1과 0이 되었습니다. 우리가 원한 게 아니죠?
####  `list()`가 필요한 경우 (미로 찾기, 그래프)
"미로 지도를 입력받습니다. 붙어서 들어옵니다. (예: 00110)"
이때는 split()을 쓰면 공백이 없어서 ['00110'] 통짜로 나옵니다.
이럴 때 **list("00110")**를 써주면 ['0', '0', '1', '1', '0']으로 예쁘게 쪼개져서 칸마다 데이터를 넣을 수 있습니다.

### 2. `[input()]` : 통째로 박스 포장

`[]`는 대괄호 안에 있는 놈을 **"그 모양 그대로"** 리스트라는 상자에 툭 던져 넣습니다.
- **입력:** `123` (엔터)
- **코드:** `a = [input()]`
- **결과:** **`['123']`**
- **해석:** `"123"`이라는 덩어리 하나가 통째로 들어간 리스트가 됩니다.

### 3. `split()` : 덩어리로 자르기 (토막 내기)

`split()`은 **"특정 기준(주로 공백)"**을 가지고 큼직하게 자릅니다.
- **입력:** `"10 20"`
- **코드:** `"10 20".split()`
- **결과:** **`['10', '20']`** 😎
- **설명:** 공백을 기준으로 싹둑 잘라서, 10과 20이라는 덩어리를 살려뒀습니다.
- 공백 대신 쓰려면 "기준 문자" ex) split("a") -> a 나오면 자르기, !!!잘린 문자 사라짐!!!
- ##### map을 써서 한 방에 숫자로 변환하고 list로 감싼다 line = list(map(int, input().split())) 숫자 min / max 비교 시

#### `split()`이 필요한 경우 (대부분의 문제)
"숫자 두 개를 입력받아 더하시오. (예: 10 20)"
이때 `list()`를 쓰면 `1`, `0`으로 다 쪼개져서 망합니다. 무조건 **`split()`**으로 덩어리를 유지해야 합니다.

### 🚨 알고리즘 문제 풀 때 주의할 점 (`split` 쓸 때)

보통 알고리즘에서는 `input().split()`을 많이 쓰시죠? 이때 실수하면 대참사가 일어납니다.
**입력:** `10 20` (공백으로 구분)
#### 케이스 A: 그냥 `split()`만 썼을 때 (정상)
Python
```
a = input().split()
# 결과: ['10', '20'] 
# (split이 이미 리스트를 만들어주기 때문에 굳이 감쌀 필요 없음)
```

#### 케이스 B: `list()`로 감쌌을 때 (정상 - 하지만 굳이?)
Python
```
a = list(input().split())
# 결과: ['10', '20']
# (이미 리스트인 애를 또 리스트로 만듦. 결과는 같음)
```

#### 케이스 C: `[]`로 감쌌을 때 (❌ 대참사)
Python
```
a = [input().split()]
# 결과: [['10', '20']] 
# (리스트 안에 리스트가 또 들어감! 이중 리스트가 됨)
```

### ⚡ 결론 (이것만 쓰세요)

1. **한 글자씩 쪼개고 싶다:** `list(input())` (예: "ABCDE" -> `['A', 'B', 'C', 'D', 'E']`)
2. **공백으로 쪼개고 싶다:** `input().split()` (그냥 이거 쓰세요. `[]`나 `list()` 안 씌워도 됩니다.)
3. **숫자로 바꾸고 싶다:** `list(map(int, input().split()))` 또는 `[int(x) for x in input().split()]`

### 패턴 2. 규칙적으로 건너뛰기 (홀수 줄만 가져오기)

만약 **"하나 건너 하나씩(1, 3, 5, 7...)"** 가져와야 한다면, 굳이 `if`문을 쓸 필요도 없이 **`input()`을 두 번 연속** 쓰면 됩니다.

Python

```
# 예를 들어 총 4세트(8줄)가 있다고 칠 때
for i in range(4):
    # 1. 내가 쓸 데이터 (홀수 번째) -> 변수에 담음
    my_data = input()
    
    # 2. 버릴 데이터 (짝수 번째) -> 변수에 안 담고 그냥 호출만 함!
    input() 
    
    print(f"내가 챙긴 데이터: {my_data}")
```

> **원리:** `input()`을 그냥 괄호만 열고 닫으면, 데이터를 읽기는 하지만 **어디에도 저장하지 않고 증발**시킵니다. 이게 바로 **"입력 씹기(Skip)"** 스킬입니다.
