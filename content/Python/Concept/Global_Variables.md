네, 바꿀 수 있습니다.

하지만 **"그 반복문이 어디에 들어있는지"**에 따라 방법이 조금 다릅니다. 파이썬에서 전역 변수(Global Variable)를 수정할 때 가장 중요한 규칙을 상황별로 정리해 드립니다.

---

### 1. 가장 일반적인 경우 (함수 없이 코드 작성 시)

함수 안에 있는 게 아니라, 그냥 스크립트 파일 내에서 작성 중이라면 **아무런 제약 없이 바로 바꿀 수 있습니다.** 파이썬의 `for`나 `while`문은 자신만의 '공간(Scope)'을 따로 만들지 않기 때문입니다.

Python

```
score = 0  # 전역 변수

for i in range(5):
    score += 10  # 그냥 바로 수정 가능

print(score)  # 결과: 50
```

---

### 2. 함수 안에서 반복문을 돌릴 때 (주의!)

만약 반복문이 **함수(`def`) 안**에 들어있고, 함수 밖의 전역 변수를 수정하려고 한다면 **`global` 키워드**가 필요합니다.

그냥 수정하려고 하면 에러(`UnboundLocalError`)가 발생하거나, 아예 새로운 지역 변수로 취급되어 전역 변수 값은 변하지 않습니다.

**❌ 틀린 예시 (에러 발생 혹은 적용 안 됨)**

Python

```
total = 0

def add_points():
    for _ in range(3):
        total += 1  # 에러 발생! (함수 안에서 total을 지역 변수로 착각함)

add_points()
```

**✅ 올바른 예시 (`global` 사용)**

Python

```
total = 0

def add_points():
    global total  # "이 변수는 밖에 있는 전역 변수 total을 쓸 거야"라고 선언
    for _ in range(3):
        total += 1

add_points()
print(total)  # 결과: 3 (정상적으로 바뀜)
```

---

### 3. 예외: 리스트나 딕셔너리 (Mutable 객체)

숫자나 문자열이 아니라 **리스트(`[]`)나 딕셔너리(`{}`)** 같은 변경 가능한 객체라면, `global` 키워드 없이도 내용을 수정(`append`, `pop` 등)할 수 있습니다.

Python

```
cart = []  # 리스트 (전역 변수)

def add_items():
    items = ["사과", "배"]
    for item in items:
        cart.append(item)  # global 키워드 없어도 내용 추가 가능

add_items()
print(cart)  # 결과: ['사과', '배']
```

_(단, `cart = [1, 2]` 처럼 리스트 자체를 아예 통째로 갈아끼울 때는 `global`이 필요합니다.)_

---

### 요약

1. **그냥 반복문:** 마음대로 수정 가능.
    
2. **함수 내부 반복문:**
    
    - 숫자/문자열 등 값 변경: `global` 키워드 **필수**.
        
    - 리스트/딕셔너리 내용 변경: `global` **없어도 됨**.
        

혹시 전역 변수 사용을 줄이고 **함수의 "반환값(return)"을 이용해 값을 전달하는 방법**이 궁금하신가요? (코드가 훨씬 안전해지는 방법입니다.)
