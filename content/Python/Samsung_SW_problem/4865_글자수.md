```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):

    str1 = set(input())
    str2 = input()
    t_dict = {} # {철자:나온 횟수}
    answer = 0
    for index in range (len(str2)):
        if str2[index] not in t_dict:
            t_dict[str2[index]] = 1
        else:
            t_dict[str2[index]] += 1
    for letter in str1: 
        if answer < t_dict[letter]:
            answer = t_dict[letter]
        else:
            pass
    print (f'#{test_case} {answer}')

```

- **`dict.get()`: ** `if-else`로 존재 여부를 확인할 필요 없이 한 줄로 끝낼 수 있다.
    ```python
    # 기존 4줄을 1줄로
    t_dict[char] = t_dict.get(char, 0) + 1
    ```
    
- **`max()`:** `for letter in str1` 루프도 한 줄로 줄일 수 있다.
    ```python
    answer = max(t_dict.get(letter, 0) for letter in str1)
    ```
