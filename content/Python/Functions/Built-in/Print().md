#### ⚖️ 튜플의 비교 원리

파이썬은 `(A, B)`와 `(C, D)` 두 튜플을 비교할 때 다음과 같이 작동합니다.

1. **1차전:** 앞의 숫자(`A` vs `C`)를 먼저 비교합니다. 여기서 승부가 나면 뒤는 보지도 않습니다.
    
2. **2차전:** 만약 앞의 숫자가 **비겼다(`A == C`)**? 그때 비로소 뒤의 숫자(`B` vs `D`)를 비교해서 승자를 가립니다.

- **`key` 파라미터**: `max(리스트, key=...)`를 쓰면 비교 기준을 바꿀 수 있습니다.
