int, float, str, 리스트 사이를 오가며 바꾸고 비교하기

| 하고 싶은 것 | 코드 | 결과 |
|---|---|---|
| 문자 → 정수 | `int("7")`, `int(" 7 ")` | 7 (공백·줄바꿈은 무시) |
| 16진수 문자 → 정수 | `int("ff", 16)` | 255 |
| 정수 → 16진수 문자 | `hex(255)` | `'0xff'` |
| 문자 ↔ 코드 | `ord("A")`, `chr(66)` | 65, `'B'` |
| 자릿수 쪼개기 | `str(123)`, `list(map(int, str(123)))` | `'123'`, `[1, 2, 3]` |
| 몫·나머지 | `-7 // 2`, `-7 % 2` | -4, 1 |

### 원리
- `//`는 내림. 음수면 0 쪽이 아니라 더 작은 쪽으로 가서 `-7 // 2 = -4`. 0 쪽으로 버리려면 `int(-7 / 2) = -3` ([[B14888_연산자_끼워넣기]])
- int와 float는 바로 비교 가능 (`3 == 3.0`은 True). 평균처럼 float가 나와도 굳이 int로 안 바꾸고 초과·미만만 비교 ([[B17822_원판_돌리기]])
- float는 오차가 있음 (`0.1 + 0.2 == 0.3`은 False). 나누기 전에 양쪽에 곱해서 정수로 비교하기 ([[B21938_영상처리]])
- `round(2.5)`는 2, `round(3.5)`는 4. .5는 가장 가까운 짝수로 반올림
- 문자열을 `int()`로 바꿀 땐 소수점이 있으면 에러 (`int("3.5")`)
- 타입 확인은 `isinstance(s, str)` 또는 `type(s) == str` ([[B1063_킹]])

### 활용
- 16진수 변환은 `int(b, 16)`. 뒤에 진수를 넣음 ([[B5658_보물상자_비밀번호]])
- 문자를 숫자로 다루기: 'A' = 65. 체스 좌표 'A1' 같은 입력 ([[B1063_킹]])
- 좌표 0.5 단위가 나오면 좌표를 2배로 늘려 정수로 ([[S5648_원자_소멸_시뮬레이션]])
- 1차원 번호를 2차원 좌표로: 행 = 번호 // 열 수, 열 = 번호 % 열 수. 1부터 시작하면 하나씩 밀리니 주의 ([[B2566_최댓값]], [[B10250_ACM]])
- 큰 값은 문제에서 나머지를 요구하면 `% 10007`처럼 매번 나누기 ([[B11727_2N_타일링]])

### 주의
- 나눗셈 전엔 0으로 나누는지 확인. 모두 0이 되는 경우가 예외 분기를 지나쳐 ZeroDivision ([[B17822_원판_돌리기]])
- 멋대로 int로 자르지 말기. 문제에서 소수점을 버리라고 할 때만 ([[B21938_영상처리]])
- 자료형이 여러 겹(dict 안 리스트 안 튜플)이면 지금 무엇을 보고 있는지 놓침 ([[B20056_마법사_상어와_파이어볼]])
- 문자열 줄 하나를 `list(map(int, input()))`로 받으면 공백까지 잘림. 공백 구분이면 `split()` 먼저 ([[B4949_균형잡힌_세상]])
