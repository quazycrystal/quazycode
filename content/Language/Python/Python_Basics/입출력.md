문제 입력을 원하는 자료형으로 받고, 정해진 형식대로 출력하기

| 입력 모양 | 코드 |
|---|---|
| 숫자 하나 | `N = int(input())` |
| 한 줄에 여러 숫자 | `a, b = map(int, input().split())` |
| 한 줄을 리스트로 | `lst = list(map(int, input().split()))` |
| 붙어 있는 숫자 한 줄 (`0110`) | `list(map(int, input()))` |
| N줄짜리 2차원 | `arr = [list(map(int, input().split())) for _ in range(N)]` |
| 글자 격자 | `arr = [list(input()) for _ in range(N)]` |

### 원리
- `input()`은 한 줄을 문자열로 받음. 줄바꿈은 빠지고, 나머지는 직접 변환
- 테스트 케이스 수가 없이 끝까지 받으면 `try / except EOFError` ([[B11279_최대_힙]])
```python
while True:
    try:
        i = int(input())
        lst.append(0-i)
    except EOFError:
        break
```
- 입력이 아주 많으면 `sys.stdin.readline`이 빠름. 끝의 줄바꿈이 남으니 `rstrip()` 또는 `int()`로 정리
- 로컬에서 파일로 테스트할 땐 `sys.stdin = open('input', 'r')`. 제출 전에 지우기 ([[C_택배_하차]])
- 한꺼번에 다 읽기: `sys.stdin.read().splitlines()`는 줄마다 하나씩 리스트로. `input()`은 한 줄씩이라 세 줄이면 세 번 또는 for. 어느 쪽이든 원하는 줄만 골라 받을 수는 없고 순서대로 다 읽어야 함
- 같은 문자열도 받는 방법에 따라 다름
  - `list("10 20")` → `['1', '0', ' ', '2', '0']`. 공백도 한 글자. 붙어 있는 미로 지도(`00110`)에 맞음
  - `[input()]` → `['123']`. 통째로 리스트에 하나
  - `"10 20".split()` → `['10', '20']`. 덩어리 유지. 대부분의 숫자 입력
  - `split("a")`처럼 기준 문자를 주면 그 글자에서 자르고, 기준 글자는 사라짐
- 여러 줄을 처음부터 1차원 하나로: `[int(x) for _ in range(3) for x in input().split()]` ([[B2563_색종이]])
- 앞의 몇 개만 따로: `k, n, *others = map(int, input().split())`

### 활용
- 안 쓰는 입력 줄은 변수 없이 `input()`만 호출해서 넘기기 ([[S4828_Min_Max]])
- 입력이 `x, y` 순서면 받을 때 바로 `c, r`로 받기. 그대로 r, c로 쓰면 행열이 뒤바뀜 ([[B9205_맥주_마시면서_걸어가기]], [[B16235_나무_재테크]])
- 좌표가 1부터 오면 받을 때 바로 -1 하거나, 0번을 비운 배열로 ([[B1913_달팽이]], [[B23747_와드]])
- 출력: `print(*lst)`는 공백 구분, `sep=''`·`end=' '`로 구분자와 끝 바꾸기, 문자 리스트는 `"".join()` ([[S4843_특별한_정렬]], [[S1873_상호의_배틀필드]])
- SWEA 형식 `print(f"#{tc}", ans)`. 리스트는 `print(f'#{tc}', *lst)`처럼 f-string 밖에서 풀기
- 2차원 입력은 컴프리헨션 한 줄 외에도, 빈 리스트에 줄마다 append하거나 `[0] * n`을 만들어 두고 `full_list[i] = ...`로 채우는 방법
- f-string 소수점: `f"{pi:.2f}"`는 소수 둘째 자리까지
- `end=`, `sep=`은 print 안에서만 쓰는 옵션. 리스트 안에 `[x, end=","]`처럼 쓰면 문법 에러
- 따옴표 출력은 다른 종류 따옴표로 감싸거나 `\'`

### 주의
- 출력 순서 확인: 좌표를 col, row로 내라고 하면 뒤집어서 ([[B13567_로봇]])
- 너무 큰 수를 출력해도 출력 초과가 날 수 있음 ([[B1715_카드_정렬하기]])
- 입력 형식 착각으로 시간을 많이 씀. 좌표계(점 vs 칸, 위아래 반전)를 입력 받을 때 정리 ([[C_미생물_연구]])
- 디버깅 출력은 제출 전에 지우기. 어디에 찍느냐가 디버깅 성과를 결정 ([[B19237_어른_상어]], [[B3190_뱀]])
