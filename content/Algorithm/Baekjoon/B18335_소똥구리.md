### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [인덱스] 1부터 시작
- [문제 읽기] 한 행동에 몇 초 걸리는지 명시 안 됨

### 코드 개선 방법
- [DFS] 시간이 정해져 있고 시나리오가 여럿이면 dfs

### 코드
```python
def bug(tm, loc, size): # 시간, 위치, 덩어리
    if tm == time: # 시간 종료
        ans_lst.append(size)
        return
    if loc == length: # 길 종료
        ans_lst.append(size)
        return

    # 밀기 = 다 1씩 추가되므로 문제 없음!
    bug(tm+1, loc+1, size + road[loc + 1])
    # 차기 = idx 2 추가되므로 리스트 길이가 짧을수도
    if loc >= length-1:
        ans_lst.append(size)
        return
    else:
        bug(tm + 1, loc + 2, (size//2) + road[loc + 2])


T = int(input())
for tc in range(1, 1 + T):
    length, time = map(int, input().split())
    road = [0] + list(map(int, input().split())) # 인덱스 맞추기
    ans_lst = []

    # 함수 호출
    bug(0, 0, 1)

    print(f"#{tc}", max(ans_lst))

# 모호한 부분: 한 행동이 몇 초 걸리는 지 명시되어 있지 않다
```
