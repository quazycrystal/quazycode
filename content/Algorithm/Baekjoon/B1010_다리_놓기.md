### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [핵심] 조합으로 고르면 중복이 없어서 겹치지 않게 놓는 조건이 자동 충족
- [범위] 29개 중 n개를 고르면 숫자가 매우 커짐

### 코드 개선 방법
- [공식] 조합 = 전체! // (구하려는 수! * (전체 - 구하려는 수)!). 약분하면 (전체/1) * ((전체-1)/2)... 누적 곱으로 계산

### 코드
```python
T = int(input())

# 답: gemini
for _ in range(T):
    ans = 1
    n, m = map(int, input().split()) # n 서쪽 m 동쪽
    for i in range(n):
        ans = ans * (m - i) // (i + 1) # for 문 돌면서 팩토리얼 처리 자동으로
    print(ans)

```
