### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 6+9를 합친 수와 다른 숫자의 max가 같을 수 있음. 틀린 코드는 index로 9가 max인지만 봄
- [반례] 1이 5개, 6+9가 4개면 5개 필요한데 4개로 찍힘

### 코드 개선 방법
- [로직] 6+9는 2로 나눈 값을 먼저 구한 뒤 max

### 코드
```python
lst = list(map(int, input()))
numlst = [0] * 10
ans = 0
for i in lst:
    if i != 6 and i != 9:
        numlst[i] += 1
    else:
        numlst[9] += 1

if numlst[9] % 2 == 0:
    numlst[9] = int(numlst[9] / 2)
else:
    numlst[9] = int((numlst[9] + 1) / 2)

# else:
ans = max(numlst)
print(ans)
```
