### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [습관] 풀어 봤던 문제인데 기억 못 함

### 코드 개선 방법
- [DP] 할 수 있는 마지막 행동 기준으로 경우 나누기 (큰 것 2가지, 세로 1가지)

### 코드
```python
N = int(input())
dp = [0]*1001
dp[1] = 1
dp[2] = 3
for i in range(3, N+1):
    dp[i] = (2 * dp[i-2]) + dp[i-1]
print(dp[N] % 10007)
```
