### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [범위] 양 끝이 이어진 맵이라 범위 체크 대신 %

### 코드 개선 방법
- [좌표] % 쓰면 N-1에서 0으로 회전 가능

### 코드
```python
def bfs(sr, sc):
    global visit
    v[sr][sc] = visit
    q = []
    q.append((sr, sc))
    while q:
        cur = q.pop(0)
        r, c = cur[0], cur[1]
        for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
            nr = (r + dr) % row # 여기다가 %!!!!!!!!!!!!!!!!!!, 범위체크 건너뜀
            nc = (c + dc) % col
            #if 0 <= nr < row and 0 <= nc < col:
            if v[nr][nc] == 0 and arr[nr][nc] == 0:
                v[nr][nc] = visit
                q.append((nr, nc))

row, col = map(int, input().split())
v = [[0] * col for _ in range(row)]
arr = [list(map(int, input().split())) for _ in range(row)]
visit = 0

for rr in range(row):
    for cc in range(col):
        if v[rr][cc] == 0 and arr[rr][cc] == 0:
            visit += 1
            bfs(rr, cc)

ans = visit
print(ans)
```
