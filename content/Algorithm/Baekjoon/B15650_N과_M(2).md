### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [조건] 2 1과 1 2를 같은 것으로 봄

### 코드 개선 방법
- [재귀] lst를 밖에 두면 호출마다 상태가 바뀌니 인자로 안 넘겨도 됨

### 코드
```python
def btk(d, p, lst):
    if d == M:
        print(*lst)
        return
    for i in range(p, N+1):
        lst.append(i)
        btk(d+1, i+1, lst)
        lst.pop()

N, M = map(int, input().split())
btk(0, 1, [])

def btk(d, p): # 밖에다가 해 두면 lst 안 넘겨도 됨!!!!
    if d == M:
        print(*lst)
        return
    for i in range(p, N+1):
        lst[d] = i # lst 안 넘겨도 호출될 때마다 상태 변경되니까
        btk(d+1, i+1)


N, M = map(int, input().split())
lst = [0] * M
btk(0, 1)

```
