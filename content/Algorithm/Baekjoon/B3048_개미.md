### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [동시 갱신] 한 칸씩 바꾸면 겹침. 바꿀 인덱스를 모아두고 한 번에 바꾸기

### 코드 개선 방법
- [자료구조] 그룹에 방향(오 1, 왼 -1)을 넣은 튜플 리스트

### 코드
```python
lenA, lenB = map(int, input().split())
groupA = input()
groupB = input()
time = int(input())

line = []
for i in range(lenA-1, -1, -1): # 맨 앞 친구가 라인에서는 맨 뒤로
    ant = groupA[i]
    direction = 1
    line.append((ant, direction))

for j in range(lenB): # 맨 앞 친구가 라인에서는 맨 뒤로
    ant = groupB[j]
    direction = -1
    line.append((ant, direction))

# time 만큼 배열을 바꾼다
for t in range(time):
    change = []
    for k in range(lenA + lenB - 1):
        front = line[k]
        back = line[k+1]
        if front[1] == 1 and back[1] == -1:
            change.append(k) # 바꿀 인덱스 모아두고
    for idx in change:
        line[idx], line[idx+1] = line[idx+1], line[idx] # 한 번에 바꾸기



#정답
ans = []
for l in range(lenA + lenB):
    ans.append(line[l][0]) # 방향 뺀 애들만 따로 모으기

print("".join(ans))
```
