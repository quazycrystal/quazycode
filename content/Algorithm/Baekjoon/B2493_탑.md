### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [인덱스] 1부터. 탑 크기가 같아도 받음

### 코드 개선 방법
- [스택] 오큰수의 반대(왼큰수). 값 대신 인덱스를 넣고 거꾸로 읽기

### 코드
```python
N = int(input())
lst = list(map(int, input().split())) # 인덱스는 그대로 두고, 거꾸로 읽다
stk = []
ans = [0] * N

# 인덱스 1 부터 시작

for i in range(N-1, -1, -1):
    while stk and lst[i] >= lst[stk[-1]]: # 탑 크기 같아도 받음
        idx = stk.pop()
        ans[idx] = i+1 # 그 값 자체가 아니라 인덱스로 갈아주므로
        # 답만 +1

    stk.append(i)

print(*ans)

```
