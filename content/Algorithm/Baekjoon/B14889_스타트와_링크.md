### 걸린 시간: 약 1시간 (실패 횟수: -)

### 실패 / 성공 이유
- [조합] 덱을 회전해 옆끼리만 구하면 1, 3 같은 조합을 못 구함. 덱 회전과 조합은 다른 문제
- [범위] N 20인데 절반만 고르면 됨

### 코드 개선 방법
- [조합] 두 명씩 뽑는 건 2중 for문
- [분기] and 대신 if로 나누기

### 코드
```python
def btk(d, j):
    if d == N/2:
        collect.append(pick[:])
        return
    else:
        for i in range(j, N):
            # N개 중 N//2개 뽑기
            pick[d] = i
            btk(d+1, i+1)

N = int(input())
arr = [list(map(int, input().split())) for _ in range(N)]

pick = [0] * (N//2) # 뽑힌 사람들
collect = [] # 뽑힌 사람들 리스트로 가능한 경우의 수
ppl = [x for x in range(N)]
btk(0, 0)
ans = [] # 팀 능력치 차이 모아둠

for case in collect:
    # 뽑는 여러 경우의 수 중 한 경우의 수
    teamA = 0 # 능력치 합
    teamB = 0

    # 뽑히지 않은 사람 리스트 만들기
    not_select = [left for left in ppl if left not in case]
    # and 대신 if!

    for one in range(N//2-1): # 리스트 안 각 요소 별로
        # 두 명 뽑아야 한다면 그냥 2중 for문 떠올리자
        for two in range(one, N//2):
            A1 = case[one]
            A2 = case[two]

            B1 = not_select[one]
            B2 = not_select[two]

            teamA += (arr[A1][A2] + arr[A2][A1])  # 쭉 돌면서 능력치 더한다
            teamB += (arr[B1][B2] + arr[B2][B1])

    ans.append(abs(teamA - teamB))

print(min(ans))
```
