- [병합] 루프 한 번에 비교 한 번, 작은 쪽 화살표 전진. 남은 건 슬라이싱으로 더하기

### 코드
```python
def merge(lst):
    if len(lst) <= 1: # 없거나 하나면
        return lst

    mid = len(lst)//2

    m_left = merge(lst[:mid])
    m_right = merge(lst[mid:])  # 재귀 되어 돌아온 친구를 merge 해야 하니까 불러서 넣기

    m_sorted = []

    i = 0
    j = 0

    while 0 <= i < len(m_left) and 0 <= j < len(m_right):
        if m_left[i] < m_right[j]:
            m_sorted.append(m_left[i])
            i += 1 # 인덱스 한 칸 이동
        else:
            m_sorted.append(m_right[j])
            j += 1  # 인덱스 한 칸 이동
    m_sorted.extend(m_left[i:])
    m_sorted.extend(m_right[j:]) # 어느쪽이 남았을 지 몰라
    return m_sorted

# 입력
N = int(input())
origin = [int(input()) for _ in range(N)]
# ans = [0] * N -> 이게 인덱스 작업?

for i in merge(origin):
    print(i)

```
