### 걸린 시간: 19분 (구상 5분, 풀이 14분) (실패 횟수: -)

### 실패 / 성공 이유
- [문제 읽기] 가장 중요한 조건(최종 위치 상하좌우만 시야 확보)이 맨 아래에 있음

### 코드 개선 방법
- [BFS] 와드는 같은 구역 bfs로 밝히기. 정답 배열을 방문 배열로 겸용
- [인덱스] 1 인덱스 주의

### 코드
```python
from collections import deque

# 함수
def is_range(r, c):
    return 0 <= r < row and 0 <= c < col

# 1. 와드 밝히기
def ward(sr, sc, color):
    # ans를 v로 쓰자
    ans[sr][sc] = "."
    q = deque()
    q.append((sr, sc))
    while q:
        r, c = q.popleft()
        for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
            nr, nc = r + dr, c + dc
            if is_range(nr, nc) and ans[nr][nc] == "#":
                if arr[nr][nc] == color:
                    ans[nr][nc] = "."
                    q.append((nr, nc))

# 2. 한별의 이동
def han_move(sr, sc, cmd):
    nr, nc = sr, sc
    if cmd == "U":
        nr, nc = nr - 1, nc
    elif cmd == "D":
        nr, nc = nr + 1, nc
    if cmd == "L":
        nr, nc = nr, nc - 1
    if cmd == "R":
        nr, nc = nr, nc + 1
    if cmd == "W":
        color = arr[nr][nc]
        ward(nr, nc, color)

    return nr, nc

# 3. 한별의 최종 위치에서 시야 밝히기
def final_han(sr, sc):
    ans[sr][sc] = "."
    for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
        nr, nc = sr + dr, sc + dc
        if is_range(nr, nc):
            ans[nr][nc] = "."

# 입력
row, col = map(int, input().split())
arr = [list(input()) for _ in range(row)]
ans = [["#"] * col for _ in range(row)]

# 한별 위치
sr, sc = map(int, input().split())
sr, sc = sr-1, sc-1

# 명령
commands = input()

# 풀이
for cmd in commands:
    sr, sc = han_move(sr, sc, cmd)

final_han(sr, sc)

for rr in ans:
    print("".join(rr))
```
