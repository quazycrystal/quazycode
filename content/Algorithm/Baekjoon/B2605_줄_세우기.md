### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 자리를 바꾸는 게 아니라 밀려서 앞에 끼워 넣어야 함

### 코드 개선 방법
- 

### 코드
```python
num = int(input())
line = [x for x in range(1, num+1)]
lst = list(map(int, input().split()))
for i in range(num):
    num = lst[i] # 뽑은 번호
    if num != 0:
        line.insert(i-num, line[i]) #앞에 끼워넣기
        line.pop(i+1)
print(*line)
```
