### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [범위] 나무 10^6개
- [엣지 케이스] 가장 앞 인덱스와 0 사이가 답일 수도 → 리스트에 0 추가
- [로직] goal이 정해져 있지 않음. 리스트에 없는 높이도 답이 될 수 있음

### 코드 개선 방법
- [이진 탐색] 자르는 높이 H 기준. 인덱스로 범위 추린 뒤 그 사이를 다시 이진 탐색
- [변수] 계속 변하는 e 말고 끝 수에서 빼기

### 코드
```python
# 나무 갯수 만도 10의 6승
num, need = map(int, input().split())
trees = [0] + list(map(int, input().split()))
trees.sort()
narrow = 0
s, e = 0, num # 0 패딩 인덱스 조절
ans = 0

while s <= e:
    m = (s + e) // 2
    if sum(trees[m+1:]) - (trees[m] * (num-m)) >= need: # e는 계속 변함 -> 그냥 끝 수인 num에서 빼야
        # 혹시 딱코일지 모르니까 ans에 값 미리 저장
        narrow = m # 인덱스 저장
        s = m + 1
    else:
        e = m - 1

ans = trees[narrow] # 앞에서 구했던 게 답일수도

srt = trees[narrow]
end = trees[narrow+1]
while srt <= end:
    mid = (srt+end) // 2
    if sum(trees[narrow+1:]) - (mid * (num - narrow)) >= need:
        ans = mid # 답 갱신
        srt = mid + 1
    else:
        end = mid - 1
    # 빼면서 내려오면 답 다 안 찾아도 됨
print(ans)
```
