### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- 

### 코드 개선 방법
- [힙] 0 아니면 자연수라 부호만 바꿔 최대 힙

### 코드
```python
import heapq
lst = []
hq = []
while True:
    try:
        i = int(input())
        lst.append(0-i)
    except EOFError:
        break

N = abs(lst.pop(0))

for x in range(N):
    if lst[x] == 0:
        if hq:
            ans = heapq.heappop(hq) # 괄호 안 리스트 이름
            print(abs(ans))
        else:
            print(0)

    else:
        heapq.heappush(hq, lst[x])  # 모듈 이름.기능

```
