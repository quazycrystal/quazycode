### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [재귀] 함수 안에서 리스트를 만들면 계속 초기화됨. 너무 길어지면 무한루프
- [인접 리스트] 양방향

### 코드 개선 방법
- [로직] 구하려는 것(부모)을 제일 간단히 어떻게 구할지 먼저 생각. 자식 idx에 부모 저장

### 코드
```python
# 만약 재귀로 간다고 하면
def dfs(s):
    v[s] = 1
    for nxt in adj[s]:
        if v[nxt] == 0:
            ans.append((nxt, s)) # 자식, 부모
            dfs(nxt)

ans = []

node = int(input())
adj = [[] for _ in range(node + 1)]
v = [0] * (node + 1)
lst = []
for i in range(node - 1):
    x, y = map(int, input().split())
    adj[x].append(y)
    adj[y].append(x) # 양방향

dfs(1)
ans.sort()
for i in range(len(ans)):
    print(ans[i][1])


```
