### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [초기화] 최댓값 초기값은 아주 작게

### 코드 개선 방법
- [DP] 나부터 새로 시작 vs 이전 값에 이어 붙이기 중 큰 값

### 코드
```python
# B1912 연속합
N = int(input())
lst = list(map(int, input().split()))
dp = [0] * (N+1)
mx = -(10**18) # 최댓값 왕 작게

for i in range(1, N+1):
    dp[i] = lst[i-1] # 이전 값 추가 안 한다 (나부터 새로 시작)
    dp[i] = max(dp[i], dp[i-1] + lst[i-1]) # 이전 값에 이어 본인 추가 한다

    if mx < dp[i]:
        mx = dp[i]

print(mx)

```
