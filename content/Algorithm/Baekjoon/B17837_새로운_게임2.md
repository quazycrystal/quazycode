---
algorithm: [시뮬레이션]
data_structure: [3차원 배열, 리스트]
technique: [룩업 테이블, 슬라이싱]
---

### 걸린 시간: 2트 약 1시간 40분 (구현 1시간, 디버깅 30분) (실패 횟수: 1트 못 품)

### 실패 / 성공 이유
- [변수] dirr = d[idx]로 빼놓고 곳곳에서 써서, 방향이 바뀌어야 할 곳에서 안 바뀜
- [자료형] 1시간 짜다가 튜플에서 방향을 받아야 하는 걸 알고 밀고 다시
- [분기] 파란 칸과 범위 밖 처리를 동시에 못 함
- [갱신] 빠진 말로 원래 칸을 갱신 안 하면 계속 쌓임

### 코드 개선 방법
- [자료구조] 말 번호 인덱스 하나로 위치·방향 모두 접근. 칸에는 말 번호 리스트
- [슬라이싱] 옮길 말은 idx부터 슬라이싱. 빨간 칸이면 [::-1]
- [분기] 범위 체크를 if 앞에 두면 파랑과 범위 밖을 함께 처리
- [룩업 테이블] opposite 방향 배열
- [분기] 파랑이면 방향 바꾸고, 반대편도 파랑/밖이면 제자리. 제자리여도 arr 표시 다시

### 코드
```python
# B17837 새로운 게임 2

DEBUG = 0
def debug(*args):
    if DEBUG:
        print(*args)


def is_range(r, c):
    return 0 <= r < size and 0 <= c < size

def move(idx):
    # 방향은 r, c 받고, 파랑/범위 밖 처리 하고 시작
    r, c = mal_loc[idx]
    dr, dc = direction[mal_dirr[idx]]
    nr, nc = r + dr, c + dc

    now = arr[r][c]
    move_lst = []

    for _ in range(len(now)):
        mal = now.pop()
        move_lst.append(mal)
        if mal == idx:
            break

    # 마지막 한 줄,.,...
    arr[r][c] = now # 빠진 애들로 갱신 안 하면 계속 쌓임,,,

    debug("d", mal_dirr[idx])

    color = 2
    nxt_jwa = (r, c)
    if not is_range(nr, nc) or color_board[nr][nc] == 2:

        mal_dirr[idx] = opposite[mal_dirr[idx] - 1] # 여기서 바로 방향 전환

        blue_dr, blue_dc = direction[mal_dirr[idx]]
        blue_nr, blue_nc = r + blue_dr, c + blue_dc

        debug("changed d", mal_dirr[idx])

        if is_range(blue_nr, blue_nc) and color_board[blue_nr][blue_nc] != 2: # 튕긴 뒷쪽은 범위 체크 안 해도 됨 -> 아님
            nxt_jwa = (blue_nr, blue_nc)
            color = color_board[blue_nr][blue_nc]

    else:
        nxt_jwa = (nr, nc)
        color = color_board[nr][nc]

    return move_lst, nxt_jwa, color

# 입력
size, mal_num = map(int, input().split())
color_board = [list(map(int, input().split())) for _ in range(size)]

# 말 보드 판
arr = [[[] for _ in range(size)] for _ in range(size)]
mal_loc = [0] * mal_num
mal_dirr = [0] * mal_num # 인덱스 말 번호로 모두 통일

# 방향 관련 룩업 테이블
direction = {1: (0, 1), 2: (0, -1), 3: (-1, 0), 4: (1, 0)}
opposite = [2, 1, 4, 3]

for idx in range(mal_num):
    r, c, d = list(map(int, input().split()))
    # 1 인덱스!!!
    r, c = r - 1, c - 1
    mal_loc[idx] = (r, c)
    mal_dirr[idx] = d
    arr[r][c].append(idx)

# 풀이
time = 0
finish = 0

while time < 1001: # 1000보다 크거나!
    time += 1
    for i in range(mal_num):
        move_lst, nxt, color = move(i)
        nr, nc = nxt

        if move_lst:
            # 말 위치도 변경
            for index in move_lst:
                mal_loc[index] = nxt

            if color != 1: # color 2인 분기일때도 다시 arr에 표시 잘 해 줘야 (원래 자리이더라도)
                arr[nr][nc].extend(move_lst[::-1]) # pop해서 리스트 만들어서 오히려 0일 때 뒤집어야

            else:
                arr[nr][nc].extend(move_lst)

        debug("arr")
        for rr in arr:
            debug(rr)

        # 옮긴 후 말 4개면 끗
        if len(arr[nr][nc]) >= 4:
            finish = 1
            break

    if finish == 1:
        break

if time == 1001:
    time = -1

print(time)
```
