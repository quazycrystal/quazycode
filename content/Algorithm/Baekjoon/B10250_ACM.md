### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [인덱스] 호수, 층이 1부터라 +1을 자꾸 놓침 (반례 1 5 4)
- [로직] 나머지/몫으로 바로 구하는 수학적 접근은 idx 때문에 어려움

### 코드 개선 방법
- [구현] 층 * 호수로 호텔을 만들고 손님을 직접 채우기

### 코드
```python
T = int(input())
for tc in range(1, T + 1):
    lv, ho, ppl = map(int, input().split())
    arr = [[0] * (lv) for _ in range(ho)]  # 가로가 항상 뒤에...
    temp = ppl
    ans = 0
    # +1 되는 거를 잘 못 잡네

    for j in range(ho):  # 가로
        for k in range(lv):  # 세로, 세로가 먼저 참
            arr[j][k] = 1
            temp -= 1

            if temp == 0:
                ans_ho = str(j + 1)
                ans_lv = str(k + 1)  # 호수, 층은 1부터 시작하므로 +1
                # print(ans_lv, ans_ho)

                if j + 1 < 10:  # 여기도 +1 해야 함... ㅠㅠㅠㅠㅠㅠㅠ
                    ans_ho = '0' + ans_ho
                ans = int(ans_lv + ans_ho)
                break
        if ans != 0:
            break
    print(ans)

# 반례 : 1 5 4
```
