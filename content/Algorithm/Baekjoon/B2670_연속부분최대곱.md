### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [시간 복잡도] 10000*10000 = 10^8 간당. float라 더 어려움

### 코드 개선 방법
- [로직] 연속 합처럼 앞까지의 최대 곱을 이어가기
- [자료형] float 출력 방법 주의

### 코드
```python
# https://www.acmicpc.net/problem/2670
num = int(input())
lst = [float(input()) for _ in range(num)]

ans = 0
mul = 1
for i in range(num-1):
    mul = 1
    for j in range (i, num):
        mul *= lst[j]
        if mul > ans:
            ans = mul

print(f'{ans:.3f}') #float 쓰는 방법에 유의!
```
