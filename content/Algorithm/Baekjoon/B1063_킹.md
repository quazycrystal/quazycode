### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [좌표] 그림 상하가 뒤집혀 있어 숫자도 뒤집어야 함. x, y라 c, r 순서
- [분기] 조건문 분기를 자꾸 빼먹음 (판 밖 / 돌과 만남 / 안 만남)
- [문법] 문자열, 튜플은 불변

### 코드 개선 방법
- [자료구조] 명령은 dict로 받아 com[c]로 처리
- [문법] 문자-숫자 변환은 A=65, 좌표 비교는 튜플로
- [분기] 안 되는 거 먼저 쳐내고 return은 똑같이

### 코드
```python
# 딕셔너리 만들어보기
com = {"R": (1, 0), # x, y이므로 c, r순으로...ㅠ
       "L": (-1, 0),
       "B": (0, 1),
       "T": (0, -1),
       "RT": (1, -1),
       "LT": (-1, -1),
       "RB": (1, 1),
       "LB": (-1, 1)}

def name(s): # 킹이든 돌이든 여기 넣으면 그냥 이름 바뀜

    if type(s) == str:
        ns1 = ord(s[0]) - 65
        ns2 = 8 - int(s[1])
        return ns1, ns2

    # 숫자 -> 문자
    if type(s) == tuple:
        ns3 = chr(s[0] + 65) # 65 더해야...
        ns4 = 8 - s[1]
        ns = ns3 + str(ns4)
        return ns

def move(c, sr, sc, dolr, dolc):  #커맨드, 킹 현 위치, 돌 현 위치

    # 일일이 다 입력 안 하고 com[c]로 퉁 칠 수 있네?
    nr, nc = sr + com[c][0], sc + com[c][1]

    # 1. 이동한 좌표가 체스 판 밖
    if 0 > nr or nr >= row or 0 > nc or nc >= col:
        # 비교 연산자 순서
        return(sr, sc, dolr, dolc)


    else:
        # 2. 이동한 좌표가 체스 판 안이나 돌과 만난 경우
        if (dolr, dolc) == (nr, nc):
            # 두 좌표 비교할 땐 튜플로
            ndolr, ndolc = nr + com[c][0], nc + com[c][1]

            # 돌이 나가면 이동 X
            if 0 > ndolr or ndolr >= row or 0 > ndolc or ndolc >= col:
                return (sr, sc, dolr, dolc)
            # 돌 안 나가면 이동
            return(nr, nc, ndolr, ndolc) # 자꾸 조건문 분기 빼먹음!!!

        #3. 이동한 좌표가 체스 판 안이나 돌과 만나지 않은 경우
        return (nr, nc, dolr, dolc)

# 입력
king, dol, N = map(str, input().split())
# map 항상 인자 2개, map(~, ~)
row = 8
col = 8

s_r, s_c = name(king)
dol_r, dol_c = name(dol) # 이름 변환

for _ in range(int(N)):
    command = input()
    s_r, s_c, dol_r, dol_c = move(command, s_r, s_c, dol_r, dol_c)

ans_king = name((s_r, s_c))
ans_dol = name((dol_r, dol_c))

print(ans_king, ans_dol)
```
