### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 정답 판별은 예측치에서 실제 경기 결과를 하나씩 빼는 접근
- [재귀] 함수 안에서 for i, for j로 경기를 만드는 건 위험

### 코드 개선 방법
- [재귀] 경기 리스트를 위에서 만들고 d를 인덱스로. 한 함수에 한 경기만, 승무패 3번 재귀
- [가지치기] 한 국가 승+무+패가 5가 아니면 컷
- [분기] flag 대신 return, 빼고 나서 복구

### 코드
```python
# 0. 입력
from itertools import *
test = [list(map(int, input().split())) for _ in range(4)]
combi = [x for x in combinations(range(6), 2)]
ans_lst = []

# 1. 가지 치기
def cut(lst):
    cnt = 0
    for i in range(0, 18, 3):
        if sum(lst[i:i+3]) == 5:
            cnt += 1
        else:
            return False

    return True

# 2. btk
ans = 0

# 제안 값에서 빼는 접근
def btk(d, lst):
    global ans
    if d == 15:
        ans = 1
        return

    a, b = combi[d][0], combi[d][1]
    for k in range(3):
        n1 = k
        n2 = 2 - k
        if lst[a*3 + n1] > 0 and lst[b*3 + n2] > 0:
            lst[a * 3 + n1] -= 1
            lst[b * 3 + n2] -= 1
            btk(d+1, lst)
            lst[a * 3 + n1] += 1
            lst[b * 3 + n2] += 1 # 복구

for tc in test:
    if cut(tc):
        ans = 0 # 정답 초기화
        btk(0, tc)
        ans_lst.append(ans)
    else:
        ans_lst.append(0)

print(*ans_lst)

```
