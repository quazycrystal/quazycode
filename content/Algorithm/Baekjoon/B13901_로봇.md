### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [시간 복잡도] 1000*1000이라 다 순회해도 충분. 방문 배열 따로 안 만듦

### 코드 개선 방법
- [방향] 방향 순서는 덱 rotate로 관리
- [종료 조건] 4방 연속 막히면 종료, 다른 곳 갈 수 있으면 cnt 초기화
- [방문 처리] 한 배열에 방문 2, 장애물 1로 표시

### 코드
```python
# B13901 로봇
from collections import deque

# 방향 지정
direction = {1: (-1, 0), 2: (1, 0), 3: (0, -1), 4: (0, 1)}
# 상 하 좌 우

# 입력
row, col = map(int, input().split())
obstacle_num = int(input())
arr = [[0] * col for _ in range(row)]

# 장애물 표시
for _ in range(obstacle_num):
    obr, obc = map(int, input().split())
    arr[obr][obc] = 1

# 로봇 시작 위치
s_r, s_c = map(int, input().split())

# 방향 돌리는 덱 생성
d_num = deque(list(map(int, input().split())))


# 함수, 안에서 스스로 돌다가 마지막 위치 반환
def robot(sr, sc):
    # 방문 표시 2, 장애물 1
    r, c = sr, sc
    cnt = 0  # 같은 자리 몇 번 탐색?

    while True:

        d = d_num[0]
        dr, dc = direction[d]

        while True:

            arr[r][c] = 2
            nr, nc = r + dr, c + dc
            if 0 <= nr < row and 0 <= nc < col:

                if arr[nr][nc] == 0:
                    if cnt != 0:  # 다른 곳 갈 수 있으면 cnt 초기화
                        cnt = 0

                    r, c = nr, nc

                else:
                    cnt += 1
                    break  # 방문 했거나 장애물
            else:
                cnt += 1
                break
                # 범위 나감

        # 방향 전환
        d_num.rotate(-1)

        # 연속 4번 범위 나가거나 다른 곳으로 이동이 안 되면
        if cnt >= 4:
            break

    return (r, c)


ans = robot(s_r, s_c)
print(*ans)

```
