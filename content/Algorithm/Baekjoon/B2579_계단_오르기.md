### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [DP] dp[i-1]과 비교하는 조건으로는 max가 연속 밟기로 온 건지 모름. 과거 추적하지 말기
- [오답] 첫 칸을 무조건 밟는다고 생각. 끝 계단을 무조건 밟아야 해서 아님
- [엣지 케이스] 리스트 길이 1일 때도 처리

### 코드 개선 방법
- [DP] 경우를 두 갈래로 못 박기: dp[i-2] + lst[i] / dp[i-3] + lst[i-1] + lst[i]

### 코드
```python
N = int(input())
lst = [int(input()) for _ in range(N)]
dp = [0] * N

dp[0] = lst[0]

if N > 1:
    dp[1] = lst[0] + lst[1]

if N > 2:
    dp[2] = max((lst[0] + lst[2]), (lst[1] + lst[2]))  # 이 경우는 두 번째 '칸' 이므로 누적 X

    for i in range(3, N):
        # 아예 가능한 수를 2개로 나누자

        pos1 = dp[i-3] + lst[i-1] + lst[i]
        pos2 = dp[i-2] + lst[i]
        dp[i] = max(pos1, pos2)

print(dp[N-1])


N = int(input())
lst = [0] + [int(input()) for _ in range(N)]
dp = [0] * (N+1)
dp[1] = lst[1]

# 리스트 길이 1일때도 봐야하고
ans = 0

if N == 1:
    ans = lst[1]

if N == 2:
    ans = lst[1] + lst[2]


if N > 2:

    for j in (lst[1]+lst[2], lst[2]):
        dp[2] = j
        for i in range(3, N+1):
            dp[i] = dp[i - 2] + lst[i] # 여기서도 경우 나누기 #dp 최대가...

            if dp[i-1] != dp[i - 2] + lst[i-1]: # 이전 칸이 한 스텝 올라온 게 아니면?
                dp[i] = max(dp[i - 1] + lst[i], dp[i - 2] + lst[i])
                # 현재의 최대가...
        result = dp[N]
        print(result)
        if ans < result:
            ans = result

print(ans)
```
