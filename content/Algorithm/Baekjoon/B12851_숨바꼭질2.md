### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [시간] 첫 트 리스트로 해서 시간 초과
- [방문 처리] 위치를 중복 방문 금지하면 경우의 수가 안 나옴. w에 방문 배열을 걸어도 안 됨
- [범위] 음수를 건너갔다 오면 최소 시간이 될 수 없음

### 코드 개선 방법
- [방문 처리] 힙에서 꺼낼 때 방문 표시가 힌트
- [다익스트라] 최소 시간과 경우의 수를 따로 저장. 같은 시간이면 경우의 수 추가

### 코드
```python
from heapq import *  # 덱 대신 힙큐?

start, goal = map(int, input().split())


def djk(s):
    v = set()

    # 여기는 한 번만 호출이라 괜찮
    dp_goal = 10 ** 18  # 현재 최소 누적값 저장해 둘 곳
    cases = 0  # 가짓수 저장

    hq = []
    heappush(hq, (0, s))
    # weight가 걸린 시간, now가 현 위치
    while hq:
        w, now = heappop(hq)  # w는 누적
        if 0 <= now <= 100_000:  # 범위!!!!!!!!!!! - 어차피 음수 건너 갔다 오면 최소 시간이 될 수가 없음
            # 근데 nxt에서 범위 처리 하면 여기 굳이 안 해도 됨
            v.add(now)  # 꺼낼 때 방문 표시

            if w <= dp_goal:
                if now == goal:
                    if w < dp_goal:
                        cases = 0

                    dp_goal = w  # 최소 시간 갱신
                    cases += 1  # 경우의 수 추가

                # 할 수 있는 행동은 3개
                for i in range(3):
                    nxt = now
                    if i == 0:
                        nxt -= 1
                    elif i == 1:
                        nxt += 1
                    else:
                        nxt *= 2

                    if nxt not in v:  # 여기서도 범위 체크
                        if 0 <= nxt <= 100_000:
                            hq.append((w + 1, nxt))  # 가중치는 언제나 1

    return dp_goal, cases


# 다익스트라 호출
time, case = djk(start)

print(time)  # 걸린 시간
print(case)  # 경우의 수

```
