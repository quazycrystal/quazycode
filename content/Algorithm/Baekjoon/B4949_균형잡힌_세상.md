### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [스택] 오른 괄호인데 스택이 비었으면 실패. 스택이 비었다는 것만으로는 판단 못 함
- [입력] 테케 개수가 없어 .이 나오면 종료
- [초기화] 줄마다 스택 초기화
- [조건] 괄호가 없어도 yes

### 코드 개선 방법
- [제어 흐름] for-else: break 안 만났을 때만 else
- [습관] for 범위, if 범위를 손으로 써 보기

### 코드
```python
# 문자열 끼리도 균형이란게??
ss = []
left = {'(':1, '[':2} #왼 괄호
right = {')':1, ']':2} #오른 괄호
# stk = [] 스택 초기화 해 줘야

while True:
    try:
        s = input()  # 그냥 공백까지 다 뜯어서
        # 리스트로 저장하니까 따옴표까지...
        ss.append(s)
    except EOFError:
        break

for s in ss:
    stk = []
    ans = 'no'
    if s == ".": # 완료 조건...
        break

    for letter in s:
        if letter in left: # 맨 위에서 기준 left로 잡았으면
            stk.append(letter)


        if letter in right: # 다음도 당연히 right가 가장 큰 분기
            if stk:
                last_left = stk[-1]
                if left[last_left] == right[letter]:
                    # 같은 종류의 괄호이면
                    stk.pop()

                # 다른 종류의 괄호이면
                else:
                    stk.append(-1)
                    break

            # 스택 비었는데 오른쪽 괄호 들어오면
            else: # 따로 if not stk이라고 하면 조건 따로, else면
                stk.append(-1) # 스택이 비면 정답 처리 되므로
                break

    if not stk:
        ans = 'yes' # 괄호검사 코드랑 다르게, 괄호 없어도 yes

    print(ans)





```
