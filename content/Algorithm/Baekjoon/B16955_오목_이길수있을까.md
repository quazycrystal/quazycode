### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [변수] 이미 돌고 있는 i, j를 갱신해서 좌표가 안 바뀜. 다른 변수를 써야 함
- [문법] if nxt == 'X' or '.'는 항상 참
- [범위] 범위는 루프 변수가 아니라 arr 크기로

### 코드 개선 방법
- [로직] 8방향 각각 1~4칸 전진하며 l을 곱해 좌표를 보냄. 5칸 중 X가 4개면 답
- [범위] 배열을 찌르기 전에 범위 체크 먼저

### 코드
```python
arr = [list(input()) for _ in range (10)]
dy = [-1, 1, 0, 0, -1, -1, 1, 1]
dx = [0, 0, -1, 1, -1, 1, -1, 1] # 상하 좌우 대각선 탐색
num = 0 # 연속된 구 사과의 돌 갯수
ans = 0
now = 0
nxt = 0
#val = 0
p_case = [] # 가능한 경우의 수 저장 리스트

# 완전히 이해 못함.
for i in range(10):
    for j in range(10):
        if arr[i][j] == 'X':
            # 8방향 탐색 시작
            for k in range(8):
                p_case = ['X']  # 현재 위치의 'X'를 리스트에 넣고 시작

                for l in range(1, 5):  # 1칸 전진부터 4칸 전진까지
                    # 핵심: l을 곱해서 좌표를 한 방향으로 멀리 보냄
                    nx = i + dx[k] * l
                    ny = j + dy[k] * l

                    # 1. 범위 체크 (배열을 찌르기 전에 먼저!)
                    if 0 <= nx < 10 and 0 <= ny < 10:
                        nxt = arr[nx][ny]

                        # 2. X이거나 . 인 경우만 인정
                        if nxt == 'X' or nxt == '.':
                            p_case.append(nxt)
                        else:
                            break  # 'O'를 만나면 이 방향은 실패
                    else:
                        break  # 보드 밖으로 나가면 이 방향은 실패

                # 5칸이 모였고, 그 중 X가 4개인 경우 (즉 빈칸이 딱 하나)
                if len(p_case) == 5 and p_case.count('X') == 4:
                    ans = 1
                    break
print (ans)
```
