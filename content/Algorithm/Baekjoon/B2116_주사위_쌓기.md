### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [시간 복잡도] 10000 * 36이라 완탐 충분

### 코드 개선 방법
- [룩업 테이블] 마주 보는 면 쌍 (a, f) / (b, d) / (c, e)
- [로직] 아랫 주사위 윗면 = 윗 주사위 바닥면. 쌓을 때마다 맞은편 숫자로 갈아줌
- [로직] 바닥 6가지만 시작으로 돌리기

### 코드
```python
# 입력
N = int(input())
dices = [list(map(int, input().split())) for _ in range(N)]

# 함수
def find_max(alpha):
    local_ans = 0
    n = 0
    if alpha in {a, f}:
        local_ans = max(b, c, d, e)
        if alpha == a:
            n = f
        else:
            n = a

    elif alpha in {b, d}:
        local_ans = max(a, c, e, f)
        if alpha == b:
            n = d
        else:
            n = b

    else: # c, e
        local_ans = max(a, b, d, f)
        if alpha == c:
            n = e
        else:
            n = c
    return n, local_ans

# 풀이
mx_ans = 0
for i in range(1, 7):
    num = i # 주사위 쌓을 때 마다 들어온 num의 맞은 편 숫자로 갈아줘야
    # 아랫 주사위의 윗면과 윗 주사위의 바닥면이 같기 때문
    ans = 0
    for dice in dices:
        a, b, c, d, e, f = dice # 여기서 6번 돌려서 찾아?
        for idx in dice:
            if idx == num:
                nxt_num, loc_ans = find_max(num)
                ans += loc_ans
                num = nxt_num
                break

    mx_ans = max(mx_ans, ans)

print(mx_ans)

```
