### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [제어 흐름] break가 루프 바로 밖에 있어서 동작했지만 중첩 루프를 나가려면 플래그 필요
- [조건] 가는 경로에 기물(왕)이 있으면 못 감. 경로가 안전할 때만 끝으로

### 코드 개선 방법
- [거리] 이동 횟수는 v에 누적하고 마지막에 1 빼기

### 코드
```python
able = {1: (-3, -2),
        2: (-3, 2),
        3: (-2, -3),
        4: (-2, 3),
        5: (2, -3),
        6: (2, 3),
        7: (3, -2),
        8: (3, 2)}
# 위에서부터 좌 우로 훑어 내려옴
not_able = {1: [(-1, 0), (-2, -1)],
            2: [(-1, 0), (-2, 1)],
            3: [(0, -1), (-1, -2)],
            4: [(0, 1), (-1, 2)],
            5: [(0, -1), (1, -2)],
            6: [(0, 1), (1, 2)],
            7: [(1, 0), (2, -1)],
            8: [(1, 0), (2, 1)]}

from pprint import pprint
row, col = 10, 9
arr = [[-1] * col for _ in range(row)]
s_r, s_c = tuple(map(int, input().split())) # 상 위치
w_r, w_c = tuple(map(int, input().split())) # 왕 위치
flag = 0 # 도달 가능 여부 판단

def bfs(sr, sc):
    global flag
    arr[sr][sc] = 0 # 이동 횟수이므로 마지막에 1 빼주면 된다
    q = []
    q.append((sr, sc))
    while q:
        r, c = q.pop(0)
        for key in range(1, 9):
            # 가는 동안에 기물이 있는지 없는지?
            gi = 0 # 기물 플래그
            for dr, dc in not_able[key]:
                nr, nc = r+dr, c+dc
                if (nr, nc) == (w_r, w_c):
                    gi = 1
                    break # 경로에 왕이 있으면 (기물)
                    # 아예 not_able 루프 나가야 함

            if not gi:
                ddr, ddc = able[key]
                nnr, nnc = r + ddr, c + ddc
                if 0 <= nnr < row and 0 <= nnc < col:
                    if arr[nnr][nnc] == -1:
                        arr[nnr][nnc] = arr[r][c] + 1
                        q.append((nnr, nnc))

                    if (nnr, nnc) == (w_r, w_c): # 목적지 도착
                        flag = 1
                        break

        if flag == 1:
            break

bfs(s_r, s_c)
print(arr[w_r][w_c])

```
