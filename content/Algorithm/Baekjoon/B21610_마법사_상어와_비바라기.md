### 걸린 시간: 2트 51분 (구상 12분, 구현 39분) / 1트 1시간 반 (실패 횟수: -)

### 실패 / 성공 이유
- [문제 읽기] 1트: 행과 열이 이어져 있다(%)를 적어놓고도 못 찾음. 문제와 생각을 섞어 적은 탓
- [엣지 케이스] 대각선 칸이 arr 밖이면 안 셈. 이전 구름 칸에는 새 구름 안 생김

### 코드 개선 방법
- [습관] 문제 요약과 아이디어 적기를 분리
- [자료구조] 구름은 arr 대신 좌표 리스트, in / not in은 set. set도 iterable

### 코드
```python
size, cmd_num = map(int, input().split())
# 물 담는 arr
arr = [list(map(int, input().split())) for _ in range(size)]
# 구름 위치 cloud arr 안 만들고 좌표로 관리

# 중요!!! set, dict도 iterable (순서만 없을 뿐)

# 명령 넣어두기
cmd_lst = []
for _ in range(cmd_num):
    d, s = map(int, input().split())
    cmd_lst.append((d, s)) # 방향 먼저, 거리 나중

cloud_lst = {(size-1, 0), (size-1, 1), (size-2, 0), (size-2, 1)}
# set으로 좀 더 빠른 탐색

# 방향 미리 만든다
direction = {1: (0, -1), 2: (-1, -1), 3: (-1, 0), 4: (-1, 1),
             5: (0, 1), 6: (1, 1), 7: (1, 0), 8: (1, -1)}
daegak = [(1, 1), (-1, 1), (1, -1), (-1, -1)]

def move_cloud(d, s):
    global cloud_lst
    temp = set() # 새 구름 담아요
    for jwa in cloud_lst:
        r, c = jwa

        dr, dc = direction[d]
        nr, nc = (r + (dr * s)) % size, (c + (dc * s)) % size
        # %로 좌표 돌아 들어오는 것 구현

        arr[nr][nc] += 1 # 새 구름 생긴 곳에 물도 추가
        temp.add((nr, nc))

    # 좌표 다 옮긴 후 리스트 갱신
    cloud_lst = temp

# 2. 물 복사 버그
def water_copy():
    for jwa in cloud_lst:
        r, c = jwa
        cnt = 0 # 대각선 칸 중에 물이 있는지
        for dr, dc in daegak:
            nr, nc = r + dr, c + dc
            # 대각선일 때는 arr 밖 나가면 쳐내
            if 0 <= nr < size and 0 <= nc < size:
                if arr[nr][nc] > 0:
                    cnt += 1

        arr[r][c] += cnt # 주변 돌아서 물 있는 갯수만큼 물 증가

# 3. 구름 다시 생성 - 완탐 1번, 시간 복잡도는 괜찮을 듯??
def make_cloud():
    global cloud_lst
    temp = set() # 새로 생길 구름 좌표
    for row in range(size):
        for col in range(size):
            if arr[row][col] >= 2:
                if (row, col) not in cloud_lst: # 이전 구름이었던 칸은 안 됨
                    arr[row][col] -= 2
                    temp.add((row, col))

    cloud_lst = temp

# 풀이
for cmd in cmd_lst:
    dirr, dist = cmd
    move_cloud(dirr, dist)
    water_copy()
    make_cloud()

# 정답
ans = 0
for rr in arr:
    ans += sum(rr)

print(ans)
```
