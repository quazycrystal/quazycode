### 걸린 시간: 1트 2시간 25분 (구상 40분, 구현 1시간 6분, 디버깅 39분) / 2트 약 1시간 반 (구현 46분, 디버깅 44분) (실패 횟수: 1트 실패)

### 실패 / 성공 이유
- [접근] arr를 45도 돌려 패딩한 새 배열로 풂. 대각 경계는 1자가 되지만 원래 1자였던 4분면 경계가 대각선이 됨
- [문제 읽기] 공식을 줬는데 주는 대로 안 함
- [인덱스] 2트: 대각선 경계까지는 좋았는데 직선 경계 인덱싱에 애먹음

### 코드 개선 방법
- [경계] 대각선은 row + col, col - row 같은 합/차로 판정. 직선 경계는 row, col로 함께
- [좌표] 문제의 x, y는 r, c로 거꾸로, -1. 상대 위치를 안에 넣기
- [검증] 사분면이 잘 나뉘면 모서리는 5구역이 될 수 없음
- [시간 복잡도] 20^6. x, y, d1, d2 4중 + 구역 합 2중

### 코드
```python
# 입력
size = int(input())
arr = [list(map(int, input().split())) for _ in range(size)]

def is_range(tpl):
    return 0 <= tpl[0] < size and 0 <= tpl[1] < size

ans = float("inf")

for row in range(size):
    for col in range(size):

        for d1 in range(1, size): # d1은 원 좌표에서 위로 얼마나 갈 건지
            for d2 in range(1, size): # d2는 아래로 얼마나 갈 건지
                # 범위 체크

                left = (row, col)
                top = (row - d1, col + d1)
                down = (row + d2, col + d2)
                right = (row - d1 + d2, col + d1 + d2)

                if all(is_range(tpl) for tpl in (left, top, down, right)):
                    area = [[0] * size for _ in range(size)]
                    top_left = row + col # 왼쪽 위 경계선, 이것보다 합이 작으면 1사분면
                    top_right = col - row + (2*d1) # 오른쪽 위 경계선, col - row가 이 값보다 크면 2사분면
                    down_left = row - col  # row - col이 이 값보다 크면 3사분면
                    down_right = row + col + (2*d2) # row + col이 이 값보다 크면 4분면

                    for r in range(size):
                        for c in range(size):
                            if r + c < top_left:
                                if r < row and c <= col + d1: # 1사분면이어라
                                    area[r][c] = 1

                            if c - r > top_right: # 2사분면이어라
                                if r <= row - d1 + d2 and c > col + d1:
                                    area[r][c] = 2

                            if r - c > down_left: # 3사분면이어라
                                if r >= row and c < col + d2:
                                    area[r][c] = 3

                            if r + c > down_right: # 4사분면이어라
                                if r > row - d1 + d2 and c >= col + d2:
                                    area[r][c] = 4

                            # 중간의 5분면은 안 세어도 나눠짐

                    a1, a2, a3, a4, a5 = 0, 0, 0, 0, 0
                    for i in range(size):
                        for j in range(size):
                            if area[i][j] == 1:
                                a1 += arr[i][j]
                            elif area[i][j] == 2:
                                a2 += arr[i][j]
                            elif area[i][j] == 3:
                                a3 += arr[i][j]
                            elif area[i][j] == 4:
                                a4 += arr[i][j]
                            else: # area[i][j] == 0:
                                a5 += arr[i][j]

                    loc_ans = max(a1, a2, a3, a4, a5) - min(a1, a2, a3, a4, a5)
                    if loc_ans < ans:
                        ans = loc_ans

print(ans)

# 베스트 코드들
```
