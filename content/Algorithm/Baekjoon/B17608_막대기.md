### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [자료구조] 굳이 체크 안 해도 되는 걸 리스트로 다 저장할 이유가 없음

### 코드 개선 방법
- [스택] 뒤에서부터 보며 현재 top보다 클 때만 추가. 반복 횟수가 많이 줄어듦

### 코드
```python
stk = []
n = int(input())
lst = [int(input()) for i in range(n)]
stk.append(lst[n-1]) # 마지막 막대기 미리 추가
for i in range (n-1, -1, -1):
    if lst[i] > stk[-1]: # 맨 위에 요소만 보고
        stk.append(lst[i])
# 뒤에서 보고 거꾸로 추가 하므로 현 ToS보다 커야만 추가
ans = len(stk)
print(ans)
```
