### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [속도] 모든 좌표에서 다시 도는 코드는 (N^2)! 중복 탐색으로 1644ms
- [백트래킹] 놓을 때 방문 배열을 복사해서 넘겨야 함

### 코드 개선 방법
- [백트래킹] 열을 순차로 늘리다 행을 늘리며 놓는다/안 놓는다 2갈래. 2^16으로 124ms
- [자료구조] arr는 찍어보기 편하지만 용량을 먹음. 10*10 이상이면 리스트 반환

### 코드
`W4/B33927_나이트 오브 나이츠.py`

```python
direction = [(1, -2),
     (2, -1),
     (2, 1),
     (1, 2),
     (-1, -2),
     (-2, -1),
     (-2, 1),
     (-1, 2)] # 나이트 이동 가능한 곳

def btk(d, sm):
    global ans
    if d == size**2:
        ans.append(sm)
        return

    for i in range(size):
        for j in range(size):
            if v[i][j] == 0:
                v[i][j] = 1
                btk(d+1, sm)
                v[i][j] = 0

                for dr, dc in direction:
                    nr, nc = i + dr, j + dc
                    if 0 <= nr < size and 0 <= nc < size:
                        if v[nr][nc] == 0:
                            v[nr][nc] = 1

                btk(d+1, sm + arr[i][j])

                for dr, dc in direction:
                    nr, nc = i + dr, j + dc
                    if 0 <= nr < size and 0 <= nc < size:
                        v[nr][nc] = 0


size = int(input())
arr = [list(map(int, input().split())) for _ in range(size)]
v = [[0] * size for _ in range(size)]
ans = []
btk(0, 0)
print(ans)
```

`W7/B33927_나이트 오브 나이츠.py`

```python
# 2의 16승과 16!의 차이

# 124ms 2^16
size = int(input())
arr = [list(map(int, input().split())) for _ in range(size)]

direction = [(-2, -1), (-1, -2), (1, -2), (2, -1),
             (2, 1), (1, 2), (-1, 2), (-2, 1)]

visited = [[0] * size for _ in range(size)]
ans = 0

def check(r, c):
    for dr, dc in direction:
        nr, nc = r + dr, c + dc
        if 0 <= nr < size and 0 <= nc < size:
            if visited[nr][nc] == 1:
                return False
    return True


# 리팩토링
def btk2(r, c, sm):
    global ans
    if r == size: # 열 순차적으로 늘리다가 행 늘리고, 행이 다 늘어나면 끗
        ans = max(ans, sm)
        return


    if c == size-1:
        nr, nc = r + 1, 0
    else:
        nr, nc = r, c+1

    if visited[r][c] == 0:
        if check(r, c): # 방문 안 했고 놓을 수 있으면
            visited[r][c] = 1
            btk2(nr, nc, sm + arr[r][c])
            visited[r][c] = 0

    # 안 놓고 다음 불러
    btk2(nr, nc, sm)

btk2(0, 0, 0)
print(ans)

#=== 1644ms 중복 탐색 코드 === (N^2)!
```
