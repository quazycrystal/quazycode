### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [프림] dfs처럼 현재 정점에서만 보지 말고 방문된 모든 정점에서 가장 작은 간선
- [힙] hq에 다 섞여 들어가므로 pop할 때 방문한 노드는 걸러야 함

### 코드 개선 방법
- [힙] (weight, 노드)를 함께 넣으면 pop할 때 다음 행선지가 정해짐

### 코드
```python
# prim 템플릿
import heapq

nodes, edges = map(int, input().split())
v = [0] * (nodes+1)
adj = [[] for _ in range(nodes + 1)]
for _ in range(edges):
    s, e, w = map(int, input().split())
    adj[s].append((w, e))
    adj[e].append((w, s))

for i in range(nodes + 1):
    adj[i].sort()

sm = 0

def prim(s): # 깊이니까 제일 앞에 정렬되어 있는걸로 간다
    # 어떤 노드와 연결?
    global sm
    hq = [] # 이건 weight와 노드 함께 보관
    heapq.heappush(hq, s)
    while hq:
        cw, cur = heapq.heappop(hq) # 갈 수 있는 방문 된 노드 중에 가장 짧은 거
        if v[cur] == 0:
            v[cur] = 1
            sm += cw # 더할 때도 거르고 나서

            for nxt_t in adj[cur]:
                nw, nxt = nxt_t[0], nxt_t[1]
                if v[nxt] == 0:
                    heapq.heappush(hq, nxt_t) # 이러면 hq는?
                    # 여기까지 다 던져넣고 나서...

prim((0, 1)) # 1은 무조건
print(sm)

```
