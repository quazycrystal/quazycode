### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [시간 복잡도] 10만 이상에서 for 2중 정렬은 터짐

### 코드 개선 방법
- [정렬] 병합 정렬: size만큼 쪼갠 덩어리를 두 개씩 합치고 덩어리 크기를 2배로. x 같으면 y 비교

### 코드
```python
# https://www.acmicpc.net/problem/11650

import sys

input = sys.stdin.readline


def merge_sort_iterative(arr):
    n = len(arr)
    size = 1
    while size < n:
        # size만큼씩 쪼개진 덩어리들을 두 개씩 잡아서 합침
        for left in range(0, n, 2 * size):
            mid = min(left + size, n)
            right = min(left + 2 * size, n)

            # 왼쪽 덩어리와 오른쪽 덩어리 합치기 (이게 핵심 로직)
            l_idx, r_idx = left, mid
            merged = []

            while l_idx < mid and r_idx < right:
                # x좌표 비교, 같으면 y좌표 비교
                if arr[l_idx][0] < arr[r_idx][0] or (arr[l_idx][0] == arr[r_idx][0] and arr[l_idx][1] < arr[r_idx][1]):
                    merged.append(arr[l_idx])
                    l_idx += 1
                else:
                    merged.append(arr[r_idx])
                    r_idx += 1

            # 남은 것들 처리
            while l_idx < mid:
                merged.append(arr[l_idx])
                l_idx += 1
            while r_idx < right:
                merged.append(arr[r_idx])
                r_idx += 1

            # 원래 배열에 덮어쓰기
            for i in range(len(merged)):
                arr[left + i] = merged[i]

        size *= 2  # 덩어리 크기를 2배로 키움


# 데이터 입력
N = int(input())
points = []
for _ in range(N):
    points.append(list(map(int, input().split())))

# 정렬 실행
merge_sort_iterative(points)

# 출력
for p in points:
    print(p[0], p[1])
```
