---
algorithm: [시뮬레이션]
data_structure: [2차원 배열, 덱]
technique: [달팽이]
---

### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [좌표] 입력 좌표는 1부터, row, col 순

### 코드 개선 방법
- [달팽이] 한 방향으로 갈 횟수는 방향이 2번 바뀔 때마다 1 증가. 방향은 덱 rotate

### 코드
```python
from collections import deque

size = int(input())
goal = int(input())
goal_jwa = tuple()
arr = [[0] * size for _ in range(size)]

d = deque([(-1, 0), (0, 1), (1, 0), (0, -1)])  # 위, 오른, 아래, 왼


# 2번에 한 번 씩 횟수가 늘어남
def snail(g):
    global d, goal_jwa
    sr, sc = size // 2, size // 2
    arr[sr][sc] = 1
    q = deque()
    q.append((sr, sc))
    times = 1  # 지금 한 방향으로 몇 번 가야하는지
    cnt = 0  # 지금 한 방향으로 몇 칸 째 가고 있는지 - times 되면 방향 전환
    two = 0  # 2 되면 times += 1

    if cnt > size:
        return

    while q:
        r, c = q.popleft()
        # 목표 숫자일 때 좌표 저장
        if arr[r][c] == g:
            goal_jwa = (r + 1, c + 1)

        dr, dc = d[0]

        nr, nc = r + dr, c + dc
        if 0 <= nr < size and 0 <= nc < size:
            arr[nr][nc] = arr[r][c] + 1
            q.append((nr, nc))  # 방향 바뀔 때만 q.append
            cnt += 1

        if cnt == times:  # 방향 전환
            cnt = 0  # 초기화
            d.rotate(-1)
            two += 1

            # 방향 2번 바뀔 때 마다 cnt 하나씩 추가
        if two == 2:
            two = 0  # 초기화
            # d.rotate(-1) # 위에서 이미 회전 하고 들어옴
            times += 1


# bfs 실행
snail(goal)

# 답 출력
for rr in arr:
    print(*rr)
print(*goal_jwa)

```
