### 코드
```python
def binary(s, e, goal):
    mid = 0

    while mid * mid != goal:
        mid = (s + e) // 2

        if mid*mid < goal:
            s = mid + 1
        if mid*mid > goal:
            e = mid - 1

    print(mid)

g = int(input())
binary(1, g, g)

```
