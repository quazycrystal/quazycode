### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [시간 복잡도] N 10^4, M 10^6이라 시간 초과
- [방향] 단방향, a가 b를 신뢰하면 b에서 a 해킹
- [로직] num >= mx로 합치지 말고 클 때와 같을 때 구분

### 코드 개선 방법
- [초기화] bfs 돌 때마다 v 초기화
- [분기] 가능하면 예외 조건 만들지 않기

### 코드
```python
from collections import deque #덱 쓰기
def bfs(s):
    global cnt
    v = [0] * (node + 1) # 돌 때마다 v 초기화 되어야 하므로
    v[s] = 1
    q = deque()
    q.append(s)
    while q:
        cur = q.popleft()
        cnt += 1
        # 방문, append, 범위, 조건
        for nxt in adj[cur]:
            if v[nxt] == 0:
                v[nxt] = 1
                q.append(nxt)

#
ans = []
node, edge = map(int, input().split())
adj = [[] for _ in range(node+1)]


for i in range(edge): # 리스트 만들지 말고...
    x, y = map(int, input().split())
    # adj[x].append(y)
    adj[y].append(x) # 단 방향, a가 b를 신뢰시 b에서 a 해킹 가능

for j in range(1, len(adj)): #앞에 안 쓰는 0 버린다
    cnt = 0
    #if adj[j]: # 가능하면 예외 조건 만들지 말기
    bfs(j)
    ans.append((j, cnt)) # 컴퓨터 번호, 갈 수 있는 넓이
    # 컴퓨터 번호는 1-N

mx = 0
r_ans = []
for k in ans:
    idx, num = k[0], k[1] # 노드 수, 넓이
    if num == mx:
        mx = num
        r_ans.append(idx)
    if num > mx:
        mx = num
        r_ans.clear()
        r_ans.append(idx)

print(*r_ans)
```
