### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [조건] 12, 21처럼 순서만 다른 건 제외
- [종료 조건] len(lst)로는 답을 못 구함

### 코드 개선 방법
- [재귀] 종료 조건 파라미터를 맨 앞에, start도 넘기기
- [재귀] append / pop, 임시 변수 최대한 자제

### 코드
```python
def btk(n, s, lst):
    if n == N:
        print(*lst)
        return
    else:
        for i in range(s, 7): # 함수 종료 후 호출
            btk(n+1, i, lst + [i])

T = int(input())
for tc in range(1, T+1):
    N = int(input())
    lst = []
    print(f"#{tc}")
    btk(0, 1, lst) # 처음엔 던진 횟수가 0번!
```
