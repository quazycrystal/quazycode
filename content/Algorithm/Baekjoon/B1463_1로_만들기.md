### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [분기] 6처럼 2와 3 둘 다 가능하므로 elif 쓰면 안 됨
- [시간 복잡도] bfs도 10^6

### 코드 개선 방법
- [DP] bottom-up: 1부터 dp 테이블 채우기

### 코드
```python
N = int(input())
dp = [0] * (N + 1)
dp[1] = 0  # 목표치니까 연산 안 해도 된다

for i in range(2, N + 1):
    dp[i] = dp[i - 1] + 1  # 더하기 연산
    if i % 2 == 0:
        dp[i] = min(dp[i], dp[i // 2] + 1)
    if i % 3 == 0:
        dp[i] = min(dp[i], dp[i // 3] + 1)
        # 6처럼 2의 배수와 3의 배수 모두 가능하므로 elif 쓰면 안 됨

print(dp[N])
```
