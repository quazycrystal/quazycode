### 걸린 시간: 1시간 40분 (구상 9분, 구현 41분, 디버깅 49분) + 추가 5분 (실패 횟수: 1회 (56분 경 제출 실패))

### 실패 / 성공 이유
- [엣지 케이스] 목표 좌표(r, c)가 현 배열 밖일 수 있음. 미봉책으로 3*3까지 0 패딩했다가 행/열 길이 판정 분기가 틀어짐
- [변수] 분기를 잘 나눠놓고 arr[0] 대신 arr의 길이를 봄
- [디버깅] 큰 배열을 통째로 찍어 파악 실패. len이라도 봤어야

### 코드 개선 방법
- [전치] 열 연산은 zip(*arr)로 전치 후 행 연산과 같은 함수, 다시 전치. 튜플이 되니 새 배열에 넣기
- [분기] 목표 칸이 배열 안에 들어오는지부터 확인
- [정렬] (개수, 수) 오름차순, 0은 세지 않기. 100 넘으면 자르기
- [습관] 마음대로 0 패딩 금지. 문제에서 시킨 대로만. N, M, K는 손으로 적기

### 코드
```python
# 한 줄 평: N, M, K 제발 손으로 적자

# 함수 설계
def cal(array):
    # 행만 보고 하면 된다
    n_arr = []
    mx_row_len = 0 # 새 배열에서 가장 길이 긴 열 길이

    for row in array:
        set_row = set([x for x in row if x != 0]) # 0 세면 안된다!!!
        temp = []
        for num in set_row:
            cnt = row.count(num)
            temp.append((cnt, num))

        temp.sort() # 이러면 cnt 적은 거 num 적은 게 먼저 옴 -> 문제에 맞는 오름차순

        n_row = []

        for tpl in temp:
            n_row.append(tpl[1]) # 숫자 먼저 적고
            n_row.append(tpl[0])  # 갯수 그 다음에

        n_arr.append(n_row)
        mx_row_len = max(mx_row_len, len(n_row))

    for idx in range(len(n_arr)):
        if len(n_arr[idx]) < mx_row_len: # 제일 긴 행보다 짧으면
            n_arr[idx] = n_arr[idx] + ([0] * (mx_row_len - len(n_arr[idx])))

    if len(n_arr) > 100:
        n_arr = n_arr[:100]

    if len(n_arr[0]) > 100:
        n_arr = [line[:100] for line in n_arr]

    return n_arr

# 입력
gr, gc, goal = map(int, input().split())
# 인덱스 1 부터이므로
gr, gc = gr-1, gc-1
arr = [list(map(int, input().split())) for _ in range(3)] # 처음엔 3줄

time = 0
while True:
    if len(arr) > gr and len(arr[0]) > gc and arr[gr][gc] == goal:
        break

    else:
        if time >= 100:
            time = -1 # 답 못 찾은 경우
            break
        time += 1
        #  함수 호출

        if len(arr) >= len(arr[0]):
            # 행 갯수가 열 갯수보다 많거나 같음
            new_arr = cal(arr)
            arr = new_arr
        else:
            new_arr = cal(list(zip(*arr))) # 열의 경우 전치 행렬 넣기
            arr = list(zip(*new_arr)) # 다시 전치해서 arr로

print(time)

```
