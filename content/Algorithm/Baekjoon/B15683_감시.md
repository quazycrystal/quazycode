---
algorithm: [백트래킹, 완전탐색]
data_structure: [2차원 배열, 리스트]
technique: [룩업 테이블]
---

### 걸린 시간: 1시간 34분 (구상 10분, 1차 구현 53분, 2차 구현 31분) (실패 횟수: 1차 greedy 접근 틀림)

### 실패 / 성공 이유
- [그리디] CCTV마다 감시 구역이 최대인 방향만 고름. 최대가 2개 이상이면 엣지를 놓침 → 모든 경우를 봐야 함
- [판단] K = 8, 4^8이라 백트래킹 가능했는데 시간·디버깅이 무서워 회피

### 코드 개선 방법
- [복사] 8*8이라 배열을 복사해 인자로 넘김. 전역이면 원복 필요
- [룩업 테이블] CCTV별 방향 조합을 하드코딩
- [함수 설계] 방문 배열 밀고 arr 색칠하는 함수 분리

### 코드
```python
# 하드코딩 가보즈아
U = (-1, 0)
D = (1, 0)
R = (0, 1)
L = (0, -1)

CCTV = {1: [[U], [D], [R], [L]],
        2: [(U, D), (R, L), (U, D), (R, L)],
        3: [(U, R), (R, D), (D, L), (L, U)],
        4: [(U, R, D), (R, D, L), (D, L, U), (L, U, R)],
        5: [(U, R, D, L), (U, R, D, L), (U, R, D, L), (U, R, D, L)]}

# 입력
row, col = map(int, input().split())
arr = [list(map(int, input().split())) for _ in range(row)]
cctv_lst = []

# CCTV 찾아요
for i in range(row):
    for j in range(col):
        if 0 < arr[i][j] < 6:
            cctv_type = arr[i][j]
            cctv_lst.append((cctv_type, i, j))

# 함수 설계 - v 밀고 arr 색칠하는 함수
v = [line[:] for line in arr]
def is_range(r, c):
    return 0 <= r < row and 0 <= c < col

def color(sr, sc, lst, v):
    v1 = [line[:] for line in v] # 들어올 때마다 밀고 다시
    for dirr in lst:
        dr, dc = dirr
        r, c = sr, sc
        while True:
            nr, nc = r + dr, c + dc
            if is_range(nr, nc) and arr[nr][nc] != 6:
                if arr[nr][nc] == 0:
                    v1[nr][nc] = "#" # 나머지 숫자는 cctv이므로 일단 건들지 말자
                r, c = nr, nc
            else:
                break # 함수는 굿
    return v1

# 백트래킹 가자...
v2 = [line[:] for line in arr] # 백트래킹용;;
cctv_num = len(cctv_lst)

final_ans = 10*18
def btk(d, vv): # 상태를 잘 쌓아야
    global final_ans
    if d == cctv_num:
        ans = 0
        for rr in vv:
            ans += rr.count(0)
        final_ans = min(final_ans, ans)
        return

    now_cctv = cctv_lst[d][0] # 맨 앞에거 가져오기
    r, c = cctv_lst[d][1], cctv_lst[d][2]
    dirr_lst = CCTV[now_cctv]
    for i in range(4):
        dirr = dirr_lst[i]
        v1 = color(r, c, dirr, vv)
        btk(d+1, v1) # 그냥 바뀐 배열 넘기면 안돼?

btk(0, v)
print(final_ans)
```
