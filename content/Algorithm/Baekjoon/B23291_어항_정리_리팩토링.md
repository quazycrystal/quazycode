### 걸린 시간: 20분 (실패 횟수: -)

### 실패 / 성공 이유

### 코드 개선 방법
- [슬라이싱] 잘라서 말기를 다시 연습 (20분). 슬라이드가 커지면 break
- [최적화] list 슬라이싱 기법 이용

### 코드
```python
# 어항 정리 연습

# 입력
t_num, _ = map(int, input().split())
tank = list(map(int, input().split()))

# 잘라서 말기 - 20분 걸림
def fish_tank(tank):
    size = 1
    slide = [tank[:size]]
    tank = tank[size:]
    check = 1
    while True:

        slide = slide + [tank[:size]]
        tank = tank[size:]
        # 슬라이드 커졌을 때를 보고 break point
        if len(tank) < len(slide):
            break

        slide = [list(line[::-1]) for line in zip(*slide)]

        check += 1
        if check == 2:
            check = 0
            size += 1

    tank = slide + [tank]
    print(tank)

fish_tank(tank)
```
