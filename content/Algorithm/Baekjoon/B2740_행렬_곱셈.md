### 코드
`W2/B2740_행렬_곱셈.py`

```python
r1, c1 = map(int, input().split())
arr1 = [list(map(int, input().split())) for _ in range(r1)]

r2, c2 = map(int, input().split())
arr2 = [list(map(int, input().split())) for _ in range(r2)]

t_arr2 = list(zip(*arr2))

ans = [[0] * c2 for _ in range(r1)]
for i in range(r1):
    for j in range(c2):
        for k in range(c1): # 각 요소별 곱하기 횟수
            ans[i][j] += arr1[i][i+k] * t_arr2[j][j+k]
print(ans)
```

`W4/B2740_행렬 곱셈.py`

```python
# B2740 행렬 곱셈
row1, col1 = map(int, input().split())
arr1 = [list(map(int, input().split())) for _ in range(row1)]
row2, col2 = map(int, input().split())
arr2 = [list(map(int, input().split())) for _ in range(row2)]

ans = [[0] * col2 for _ in range(row1)] # row가 뒤에 온다고,,,

for new_r in range(row1):
    for new_c in range(col2):
        for col in range(col1):
            ans[new_r][new_c] += arr1[new_r][col] * arr2[col][new_c]

for rr in ans:
    print(*rr)

```
