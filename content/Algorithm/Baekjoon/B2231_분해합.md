### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [범위] 1차 시도 런타임 에러: for문을 잘못된 범위에 넣음
- [로직] for문이 끝나야 제대로 된 답

### 코드 개선 방법
- [범위] 자릿수만큼 for문 범위를 압축. 자릿수는 str로 쪼개기

### 코드
```python
goal = int(input()) # str으로 들어옴
ans = 0
goal_l = len(str(goal)) # goal 자릿수
start = 0

if goal > (9*goal_l):
    start = goal - (9*goal_l) # 자릿수 쪼개기
else:
    start = 0

for i in range(start, goal): # for 문 범위 압축
    goal_s = str(i)
    sm = i
    for j in str(i):
        sm += int(j)

    # for문 끝나야 제대로 된 답 구할 수 있음
    if sm == goal:
        ans = i
        break

print(ans)
```
