### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [범위] for j in range(i, n)는 i가 커질수록 j 범위가 줄어 틀림. 사람 수 * 사람 수로

### 코드 개선 방법
- [로직] 순위 = 나보다 큰 사람 수 + 1. 동점자는 셀 필요 없음

### 코드
```python
num = int(input())
lst = [list(map(int, input().split())) for _ in range(num)]
ans = [1] * num # 순위

for i in range(len(lst)):
    for j in range(len(lst)): # 안전하게 그냥 사람 수 * 사람 수,
        if lst[i][0] > lst[j][0] and lst[i][1] > lst[j][1]: # 덩치 클 수록 등수 앞으로
            ans[j] += 1
print (*ans)


```
