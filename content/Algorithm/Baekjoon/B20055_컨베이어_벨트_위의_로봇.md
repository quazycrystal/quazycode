### 걸린 시간: 1시간 25분 (구상 5분, 구현 36분, 디버깅 43분) + 30분 (실패 횟수: 시간 내 못 풂)

### 실패 / 성공 이유
- [문제 읽기] 가장 먼저 올라간 로봇부터 이동. 먼저 올라간 건 맨 뒤라 뒤에서부터 돌아야 함
- [로직] 앞에서부터 돌면 보낸 로봇이 다음 i에서 또 밀려 끝까지 감
- [인덱스] belt[i] -= 1을 belt[i-1]로 적음
- [문제 읽기] 4개 행동을 다 돈 게 하나의 '단계'

### 코드 개선 방법
- [구현] 내구도 0인 칸이 생길 때마다 cnt 올리기
- [습관] 빨리 풀고 싶은 욕구 줄이고 구현 방법을 꼼꼼히

### 코드
```python
from collections import deque

# 입력
N, can = map(int, input().split())
belt = deque(list(map(int, input().split())))
robot = deque([0]*(2*N))

# 매 단계 쓰일 벨트 체크 함수
def belt_check():
    broken_can = 0
    for i in belt:
        if i == 0:
            broken_can += 1
    if broken_can >= can:
        return False
    else:
        return True

ans = 0

while True:

    ans += 1
    cnt = 0

    # 1단계: 한 칸 회전
    belt.rotate(1)
    robot.rotate(1)

    # 로봇이 끝에 도달하면 즉시 내림
    if robot[N-1] == 1:
        robot[N - 1] = 0


    for i in range(2*N-1, 0, -1):

        if robot[i] == 0:
            if robot[i-1] == 1 and belt[i] > 0:
                robot[i-1] = 0
                robot[i] = 1
                belt[i] -= 1

        # 여기서 내구도 다 한 벨트 있으면 즉시 추가
        if belt[i] == 0:
            cnt += 1

    # 로봇이 끝에 도달하면 즉시 내림
    if robot[N - 1] == 1:
        robot[N - 1] = 0


    # 3단계: 올리는 칸의 내구도 0 아니면 로봇 올리기
    if belt[0] != 0:
        robot[0] += 1
        belt[0] -= 1
    else:
        cnt += 1 # 앞에서는 맨 끝에서 맨 앞 직전까지 셌고, 여기는 맨 앞 셈


    if cnt >= can:
        break

    print(cnt)
    print(belt)

print(ans) # 왜 cnt 적용하니까 갑자기 정답이 1씩 늘지???

```
