### 걸린 시간: 1시간 반 (구상 11분, 구현 25분, 디버깅 54분) (실패 횟수: 26% WA, 80% 메모리 초과)

### 실패 / 성공 이유
- [상태 확장] 1차: 2차원 배열이라 나중에 더 좋아질 가지가 잘림. 거울 수만으로는 방향이 묻힘
- [메모리] 2차: 등호를 넣어 중복을 허용하니 메모리 초과
- [입력] W, H가 거꾸로 주어짐

### 코드 개선 방법
- [상태 확장] (r, c, 방향)별 거울 수를 저장하는 3차원 다익스트라
- [원칙] bfs로 들고 다녀야 할 상태만큼 v 차원을 만들기. 그 칸에 '어떤 상태'로 왔는지
- [체크리스트] 문제·최대최소·우선순위 / 인덱스 / bfs 초기화 / continue·break / 변화량 누적 / scope / 갱신 / 중력 / 얕은 복사

### 코드
```python
from collections import deque
from heapq import *

# 함수
def is_range(r, c):
    return 0 <= r < row and 0 <= c < col


direction = {0: [(-1, 0), (0, -1), (0, 1)],
             1: [(0, 1), (-1, 0), (1, 0)],
             2: [(1, 0), (0, 1), (0, -1)],
             3: [(0, -1), (1, 0), (-1, 0)]}  # 임의로 상우하좌 시계방향
# 2, 3 뒤집혀 있음, 번호 새로 넘겨 줘야 할 때 대비

def bfs3(begin):
    # 내가 온 방향도 저장을 해야 함!
    sr, sc = begin
    v = [[[10**18, 10**18, 10**18, 10**18]for _ in range(col)] for _ in range(row)]
    hq = []
    for sd in range(4):
        v[sr][sc][sd] = 0
        heappush(hq, (0, sr, sc, sd))

    while hq:
        dist, r, c, d = heappop(hq)
        if dist <= v[r][c][d]: # 여기서 1차 거른다봉
            for i in range(3):
                dr, dc = direction[d][i]
                nr, nc = r + dr, c + dc
                nd = d
                if i == 1:
                    nd = (d - 1) % 4
                elif i == 2:
                    nd = (d + 1) % 4

                # 직진 중
                if i == 0:
                    if is_range(nr, nc) and v[nr][nc][nd] > dist:

                        if arr[nr][nc] != "*": # 벽이면 못 가지롱
                            v[nr][nc][nd] = dist
                            heappush(hq, (dist, nr, nc, nd))

                # 방향 틀기 - 거울 추가
                else:
                    if is_range(nr, nc) and v[nr][nc][nd] > dist + 1:
                        if arr[nr][nc] != "*":
                            v[nr][nc][nd] = dist + 1
                            heappush(hq, (dist + 1, nr, nc, nd))

    er, ec = finish
    return min(v[er][ec])


# 입력
col, row = map(int, input().split()) # 거꾸로 줌 주의
arr = [list(input()) for _ in range(row)]

# 시작과 끝 찾아요
start = ()
finish = ()
for r in range(row):
    for c in range(col):
        if arr[r][c] == "C":
            if start == ():
                start = (r, c)
            else:
                finish = (r, c)

# 풀이
print(bfs3(start))
```
