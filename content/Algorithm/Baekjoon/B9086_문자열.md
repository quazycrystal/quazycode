### 코드 개선 방법
- [출력] print의 구분자는 sep으로 지정

### 코드
```python

n = int(input())
for i in range(n):
    string = input()
    print(string[0], string[-1], sep="")
    # 쉼표로 프린트 할 때는 sep으로 지정 가능, 기본적으로 공백
```
