### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [인덱스] 1부터 시작
- [조건] 개수가 같으면 가장 작은 번호

### 코드 개선 방법
- 

### 코드
```python
length = int(input())
roll = [0] * (length + 1)  # 인덱스 맞추기
ppl = int(input())
papers = []
ans = [0] * 2
expected = 0
real = 0

for _ in range(ppl):
    s, e = map(int, input().split())
    papers.append((s, e))

for i in range(ppl):
    idx = i + 1
    srt, end = papers[i][0], papers[i][1]

    expect = (end + 1 - srt)
    if expect > expected:
        expected = expect
        ans[0] = idx
        # 제일 많이 기대한 사람의 번호

    for j in range(srt, end + 1):
        if roll[j] == 0:
            roll[j] = idx

for k in range(1, ppl + 1):
    mx = roll.count(k)
    if mx > real:
        real = mx
        ans[1] = k  # 이것도 실제로 가장 많이 받은 사람의 번호

print(ans[0])
print(ans[1])
```
