### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [좌표] 행이 뒤집혀 있음. 출력은 col, row 순
- [범위] 좌표를 벗어나면 끝

### 코드 개선 방법
- [좌표] 보이는 대로 row, col로 두고 (row-1, 0)에서 시작 후 출력 때 변환
- [함수 설계] 회전, 이동 함수 2개

### 코드
```python
direction = {0: (0, 1), 1: (1, 0), 2: (0, -1), 3: (-1, 0)} # 우하좌상, 시계방향(turn 1 기준)
d_idx = 0

def turn(com):
    global d_idx
    if com == "TURN 0":
        d_idx -= 1
        d_idx = d_idx % 4

    if com == "TURN 1":
        d_idx += 1
        d_idx = d_idx % 4

    return direction[d_idx]

def move(com, jwa, direct):
    r, c = jwa[0], jwa[1]
    dr, dc = direct[0], direct[1]
    if com != "TURN 0" and com != "TURN 1":
        a, can = com.split()
        can = int(can)
        nr, nc = r + (dr * can), c + (dc * can)
        if 0 <= nr < size and 0 <= nc < size:
            return((nr, nc))
        else:
            return False
    else:
        return ((r, c))
size, calls = map(int, input().split())
start = ((size-1), 0)
ans = 0

for i in range(calls):
    call = input()
    d = turn(call) # 방향 정해짐
    start = move(call, start, d)
    if not start:
        ans = -1
        print(ans)
        break

if ans != -1:
    y = size - start[0] - 1
    x = start[1]
    print(x, y)
```
