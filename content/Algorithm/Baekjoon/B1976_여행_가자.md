### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [유니온] 인접 리스트가 그대로 부모 테이블이 되는 게 아님. 간선 위주로 합치기
- [인덱스] +1 인덱스 이슈. x가 자식, p[x]가 부모

### 코드 개선 방법
- [유니온] find는 부모를 갈아치우며 올라가 최종 부모를 return. 여행지들의 부모가 모두 같은지 확인
- [유니온] 어느 쪽이 부모가 되든 같은 그룹인지만 보면 됨

### 코드
```python
# 입력
N = int(input()) # 전체 도시 수
M = int(input()) # 여행 계획 속한 도시 수

# adj = [0] + [0] * N # 인덱스 맞추기
edges = [(0, 0)] + []

arr = [list(map(int, input().split())) for _ in range(N)]
calls = list(map(int, input().split()))

# adj 채우기
for i in range(N-1):
    for j in range(i, N):
        if arr[i][j] == 1: # +1씩 해 줘야 함! 인덱스 이슈
            edges.append((i+1, j+1))


###!!!!! x가 자식, adj[x]가 부모!!!!!!!!!!!!

# 연결 정보 담을 p 리스트를 만들어야 함
p = [y for y in range(N+1)]

def find(x):
    if x != p[x]: # 나 스스로랑 부모 값 다르면
        p[x] = find(p[x]) # 부모 갈아치우면서 간다
    return p[x] # 계속 부모를 리턴해야 마지막에 최종 부모가 됨

def union(a, b):
    if p[a] != p[b]: # 부모 다르면
        p[find(a)] = find(b) # 부모 통일

for k in range(1, len(edges)):
    A, B = edges[k]
    union(A, B)

ans = ""
goal = find(calls[0]) # 여기서 각각 부모 찾자
if all(find(call) == goal for call in calls):
    ans = "YES"
else:
    ans = "NO"

print(ans)

```
