### 걸린 시간: 29분 (구상 5분, 풀이 24분) (실패 횟수: -)

### 실패 / 성공 이유
- [시간 복잡도] 200*200*200*2 = 1600만

### 코드 개선 방법
- [구현] 칸마다 설치 시간을 저장. 빈 곳 채우기 → 3초 된 것 터뜨리기 반복
- [출력] 마지막에 시간 배열을 문자로 변환

### 코드
```python
# B16918 봄버맨

def is_range(r, c):
    return 0 <= r < row and 0 <= c < col

# 1. 빈 곳 채우기
def fill():
    if nowtime % 2 == 0:
        for r in range(row):
            for c in range(col):
                if arr[r][c] == 0:
                    arr[r][c] = (nowtime + 3)

# 2. 시간 된 거 터뜨리기
def bomb():
    new_arr = [line[:] for line in arr]
    for r in range(row):
        for c in range(col):
            if arr[r][c] == nowtime:
                new_arr[r][c] = 0
                for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
                    nr, nc = r + dr, c + dc
                    if is_range(nr, nc):
                        new_arr[nr][nc] = 0

    return new_arr

# 3. 정답 변환
def change():
    for r in range(row):
        for c in range(col):
            if arr[r][c] == 0:
                arr[r][c] = "."
            elif arr[r][c] > 0:
                arr[r][c] = "O"

    for rr in arr:
        print("".join(rr))


# 입력
row, col, times = map(int, input().split())
arr = [list(input()) for _ in range(row)]

# 격자 초기화
for i in range(row):
    for j in range(col):
        if arr[i][j] == ".":
            arr[i][j] = 0
        elif arr[i][j] == "O":
            arr[i][j] = 3

# 풀이
for nowtime in range(1, 1+times):
    fill()
    arr = bomb()

change()
```
