### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [조건] 구간 사이와 마지막 구간까지 나무가 1개 이상씩 있어야 함
- [초기화] 곱이므로 기본값은 1

### 코드 개선 방법
- 

### 코드
```python
num = int(input()) # 나무 갯수
lst = list(map(int, input().split())) # 벛꽃 갯수
sm = 0 # 최종 잎 합
mx_sm = 0 # 최종 잎 합 중 최대
s_1 = 1 # 섹션별 합, 곱하기이므로 기본 1이 되어야 함
s_2 = 1
s_3 = 1
s_4 = 1

for i in range (num-3):
    for j in range (i+1, num-2): # i, j, k 사이에 무조건 1개 이상의 나무
        for k in range (j+1, num-1): # 그 뿐 아니라 k+1 : num 까지도 1개 이상의 나무
            # for 문으로 누적 곱 가능
            s_1, s_2, s_3, s_4 = 1, 1, 1, 1
            for one in lst[0:i+1]: # 슬라이스 내부 요소별 곱하기
                s_1 *= one
            for two in lst[i+1:j+1]: # 슬라이스 내부 요소별 곱하기
                s_2 *= two
            for thr in lst[j+1:k+1]: # 슬라이스 내부 요소별 곱하기
                s_3 *= thr
            for four in lst[k+1:num]: # 슬라이스 내부 요소별 곱하기
                s_4 *= four
            sm = s_1 + s_2 + s_3 + s_4
            if sm > mx_sm:
                mx_sm = sm
print (mx_sm)
```
