### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [범위] 거리가 10이면 x+10까지 (x+11 아님)

### 코드 개선 방법
- 

### 코드
```python
arr = [[0 for _ in range (100)] for _ in range (100)]
ln = int(input()) # 색종이 장수
lst = [int(x) for _ in range(ln) for x in input().split()] #range -> input().split()

for i in range (0, ln*2, 2):
    x = lst[i]
    y = lst[i+1]

    for j in range(x, x+10): # x+11 아님. 거리가 10
        for k in range (y, y+10):
            if arr[j][k] == 0:
                arr[j][k] = 1

ans = sum(row.count(1) for row in arr)
print(ans)
```
