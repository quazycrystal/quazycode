### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 육목 처리, 가장 왼쪽 좌표 구하기. 방향 바로 앞 칸까지 체크
- [범위] 다음 칸은 있어야 하지만 앞 칸(br, bc)은 없어도 돌아야 함. 조건 분리
- [시간] while로 다 따라가니 시간이 터짐. 앞 돌 하나만 보면 됨

### 코드 개선 방법
- [변수] 변수를 여러 개 만들지 말고 i, j 섞어 쓰지 않기
- [델타] 4방향(우상, 우, 우하, 하)만, 곱하기로 거리

### 코드
```python
row = 19
col = 19
ans = 0
p_ans = ""
arr = [list(map(int, input().split())) for _ in range(row)]

def find(s):
    global ans
    global p_ans
    if arr[i][j] == s:
        r = i
        c = j #i, j 섞어쓰지 말기... 다른 그릇에 담기
        cnt = 1 # 이미 돌 하나 만족하고 들어왔음
        # 우상, 우, 우하, 하 탐색
        for dr, dc in ((-1, 1), (0, 1), (1, 1), (1, 0)):
            nr = r + dr
            nc = c + dc
            br = r - dr
            bc = c - dc

            if 0 <= br < row and 0 <= bc < col and arr[br][bc] == s:
                continue # break는 아니고 실행 그냥 건너뜀

            else: #br, bc가 범위 밖 이거나 arr[br][bc]가 s가 아니면
                if 0 <= nr < row and 0 <= nc < col:
                    if arr[nr][nc] == s:
                        cnt += 1
                        for _ in range(4): # while문 하니까 시간이 터지고 뒤에 돌 하나만 보면 되니까...
                            nrr, ncc = nr + dr, nc + dc
                            if 0 <= nrr < row and 0 <= ncc < col: # 이 부분 함수로 처리 후 건너뛰어도 좋다
                                if arr[nrr][ncc] == s: # 항상 범위 처리!!
                                    cnt += 1
                                    nr, nc = nrr, ncc

            if cnt == 5:
                ans = s
                p_ans = (i+1, j+1) # 좌표 1씩 더함

            else:
                cnt = 1 # 같은 돌 다른 방향... 다시 for문 내부로 들어가니까


for i in range(row):
    for j in range(col):
        find(1)
        if ans == 0:
            find(2)

print(ans)
print(*p_ans)

```
