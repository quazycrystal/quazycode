### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [컴프리헨션] 이중 for를 한 줄에 쓰면 평탄화되어 1차원이 됨. 위계가 안 섬

### 코드 개선 방법
- [컴프리헨션] 바깥 행 반복은 밖에서 따로

### 코드
```python
row, column = map(int,input().split())
array_a = []
array_b = []
answer = []

for i in range (2):
    for j in range (row):
        if i == 0:
            array_a.append(list(map(int, input().split())))
        else:
            array_b.append(list(map(int, input().split())))

answer = [[x+y for x, y in zip(array_a[k], array_b[k])] for k in range(row)]
for r in range (row):
    print(*answer[r])
```
