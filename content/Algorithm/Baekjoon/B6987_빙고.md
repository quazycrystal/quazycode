### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [함수 설계] 확인 함수가 문제: 행, 열, 대각선 2개

### 코드 개선 방법
- [로직] 들어온 좌표가 속한 행, 열, 대각선만 체크. 빙고 배열 0-1 대각선, 2-6 가로, 7-11 세로
- [제어 흐름] 최종 체크는 루프 안에서

### 코드
```python
yes_bingo = [0] * 12
deagak = {0: {(0, 0), (1, 1), (2, 2), (3, 3), (4, 4)},
          1: {(0, 4), (1, 3), (2, 2), (3, 1), (4, 0)}}
# set에서 찾는 건 편함

arr = [list(map(int, input().split())) for _ in range(5)]
calls = []
for _ in range(5):
    calls.extend(list(map(int, input().split())))


# 판에 표시하는 함수, input은 cmd, return 좌표
def mark(cmd):
    for row in range(5):
        for col in range(5):
            if arr[row][col] == cmd:
                arr[row][col] = 0
                return (row, col)


# 그냥 들어올 때마다 그 좌표가 속한 열, 행 체크하는 함수로,,,
def check(jwa):
    row, col = jwa

    for i in (0, 1):
        if jwa in deagak[i]:
            cnt = 0
            for r1, c1 in deagak[i]:
                if arr[r1][c1] == 0:
                    cnt += 1
            if cnt == 5:
                yes_bingo[i] = 1

    j = 0
    if all(arr[row][j] == 0 for j in range(5)):
        yes_bingo[row + 2] = 1

    k = 0
    if all(arr[k][col] == 0 for k in range(5)):
        yes_bingo[col + 7] = 1


# 최종 체크는 루프 안에서!
ans = 0

for i in range(25):
    call = calls[i]
    now = mark(call)
    check(now)

    if yes_bingo.count(1) >= 3:
        ans = i + 1
        break

print(ans)

```
