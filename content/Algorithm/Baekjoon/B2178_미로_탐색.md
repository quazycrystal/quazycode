### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [좌표] 시작 좌표를 그대로 들고 가지 말고 큐에서 꺼낸 현재 위치에서 다음 위치 계산
- [거리] v[s] = 1로 시작하면 v[nxt] = v[cur] + 1 후 -1 해야 거리
- [범위] 배열 크기 끝 인덱스 + 1까지. 입력 좌표는 1부터라 -1

### 코드 개선 방법
- [거리] 2차원이면 v에 0/1 대신 거리 값을 쌓아 저장
- [템플릿] 초기화(방문 표시, 큐 생성, 큐에 시작) → 꺼내서 현재 위치 → 범위, 미방문, 조건이면 방문 표시 + 큐 추가

### 코드
```python
def dfs(sx, sy, ex, ey): #gemini 도움

    v[sx][sy] = 1
    q = []
    q.append((sx, sy)) # 그냥 좌표 통으로 튜플로 넣는군
    while q:
        cur = q.pop(0) # 맨 앞에 있는게 현 위치
        x, y = cur[0], cur[1] # 요기서 위치 잡아줘야 v배열에 거리 만큼 추가가 가능
        for dy, dx in ((-1, 0), (1, 0), (0, -1), (0, 1)): # 상하좌우
            nx = x + dx
            ny = y + dy
            if 0 <= nx < ex+1 and 0 <= ny < ey+1:
                if v[nx][ny] == 0 and arr[nx][ny] != 0: # 방문 하지 않은 곳이고 배열 값 0이 아니면
                    v[nx][ny] = v[x][y] + 1 # v 배열 값 추가
                    q.append((nx, ny)) # q 값 append 해야 내 위치 갱신

# 예외 처리, 경계값
row, col = map(int, input().split())
arr = [list(map(int, input())) for _ in range(row)]

v = [[0]*col for _ in range(row)]
# v가 항상 0이 아닐 수도 , str 0으로

# 시작 좌표 구하기
str_x , str_y = 0, 0 # 배열 idx는 한 칸씩 당겨진 모양새
end_x, end_y = row-1, col-1 # 배열 인덱스는 -1

dfs(str_x , str_y, end_x, end_y)
print(v[end_x][end_y])
```
