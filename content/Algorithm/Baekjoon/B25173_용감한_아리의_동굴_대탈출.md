### 걸린 시간: 1시간 54분 (구상 26분, 구현·검증 1시간 13분, 디버깅 15분) (실패 횟수: 1회 (68퍼 WA))

### 실패 / 성공 이유
- [변화량 누적] 루프 안에서 ari_h -= i로 체력을 누적해 깎음
- [갱신] 보스 이동 후 arr 갱신 누락

### 코드 개선 방법
- [변수] 루프 안 누적 금지. 변화량은 새 변수로
- [달팽이] 방문 체크는 set 대신 2중 arr. 넉넉히 2N * 2N
- [속도] while 안에서 sum(v)처럼 배열 전체를 돌지 않기 (약 200ms 차이)

    return (pr, pc), pd

def monster(tpl):
    global ari_h

    mv = [[-1] * col for _ in range(row)]
    mv[sr][sc] = 0
    q = deque()
    q.append((sr, sc))

        r, c = q.popleft()
        if (r, c) == ari:
