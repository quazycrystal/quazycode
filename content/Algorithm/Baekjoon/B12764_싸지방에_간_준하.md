### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 그리디 접근 틀림. 시뮬레이션 문제
- [힙] 사용 중 좌석 힙과 빈 좌석 힙 두 개를 생각 못 함
- [구현] 빈 좌석 중 가장 위 좌석 배정이 빠졌었음

### 코드 개선 방법
- [힙] 시작 시간 순으로 보면서 끝난 좌석을 빈 좌석 힙으로 옮기고, 빈 좌석이 없을 때만 새 좌석

### 코드
```python
from heapq import *

N = int(input())
lst = []

using = []
able = []
pc = [0] * N  # 정답 기록용
num = 0 # 필요한 pc 대수

for _ in range(N):
    s, e = map(int, input().split())
    lst.append((s, e))

lst.sort()  # 시작 시간이 빠른 거 부터!

for i in range(N):
    start, end = lst[i]

    if using: # 여기서만 using 보고, 밑에 코드 중복할 이유 없음
        while using[0][0] < start: # 지금 들어온 시작 시간보다 이 전 끝 시간이 짧으면 # pop은 하지 않고, 상황 보고
            done = heappop(using)[1] # 다 쓴 좌석 인덱스
            # 빈 좌석 인덱스 가능한 좌석 모음에 밀어 넣기
            heappush(able, done)
            if not using:
                break

    # able 중에 가장 위에 있는 거 가져다가 쓰기
    if able:
        now = heappop(able)
        heappush(using, (end, now)) # 제일 위에거 배정 -> 이게 빠졌었음
        pc[now] += 1 # 좌석 수는 + 안 되고, 그 좌석을 거쳐간 사람 수가 추가 됨

    else: # able이 없다 = 사람들이 이전 좌석 계속 쓰는 중이다 # 리팩토링 어떻게 하면 좋지? -> if문으로 엮기?
        pc[num] += 1 # 현 길이 에서 추가
        heappush(using, (end, num))  # 가능한 좌석이 없으면 추가 필요
        num += 1

print(num)
print(*pc[:num])

```
