### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [방문 처리] for문 안에서 방문 처리를 해서 현재 칸이 그 안에서만 -1. 이동 못 할 때 현재 칸이 표시 안 됨
- [BFS] arr 자체가 바뀌면 bfs 안 됨. 한 방향 끝까지 가봐야 하니 최소여도 dfs
- [복구] 사과가 있던 칸은 1로 되돌려야

### 코드 개선 방법
- [백트래킹] 전처리는 입구, 후처리는 출구: 진입하자마자 방문 표시, 자식 끝나면 해제
- [분기] 사과 처리도 위에서 해서 분기 줄이기

### 코드
```python
def btk(d, loc, apple): # 깊이 = 몇 번 가봤니?, 현 위치, 사과 갯수(누적 합)
    # 종료 조건은 더 이상 갈 수 있는 곳 없을 때
    if d == 25: # 모든 칸 다 돌았다!
        return

    r, c = loc[0], loc[1]

    c_apple = apple # 밑에서 업뎃 되든 안 되든 그냥 넘기면 된다
    stat = 0

    if arr[r][c] == 1:
        c_apple += 1 # 임시 변수, 이 변수는 함수 나가면 사라지므로 전달해야
        stat = 1
        if c_apple == 3: # d==25일 때와 같은 레벨의 종료 조건이 아니었음
            # 얘는 오히려 위에 두면 꼬임
            ans.append(d)
            return

    arr[r][c] = -1
    for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
        # 상하좌우
        nr = r + dr
        nc = c + dc
        if 0 <= nr < row and 0 <= nc < col:
            # 이동 할 수 있으면
            if arr[nr][nc] != -1:
                btk(d+1, (nr, nc), c_apple)


    arr[r][c] = stat

# 예외 처리!!! 정신 차리자
row, col = 5, 5
arr = [list(map(int, input().split())) for _ in range(row)]
s_r, s_c = map(int, input().split())
# v = [[0] * col for _ in range (row)]

ans = []
btk(0, (s_r, s_c), 0)

if not ans:
    print(-1)
else:
    print(min(ans))
```
