### 걸린 시간: 2시간 (구상 17분, 구현 1시간 25분, 디버깅 18분) + 추가 디버깅 약 30분 (실패 횟수: -)

### 실패 / 성공 이유
- [들여쓰기] 집중력이 떨어져 한 줄을 한 칸 앞으로 들여씀. 가장 큰 디버깅 포인트
- [로직] 꼭짓점 탐색 시 한 번 쓰인 점을 버림. 그 점이 다른 사각형의 시작점이 될 수 있음
- [좌표] 입력이 c, r 순

### 코드 개선 방법
- [로직] 다음 세대는 지금까지의 방향 리스트를 거꾸로 읽어 +1 회전해 붙이기
- [set] 좌표는 set으로 중복 제거. | 합집합, - 차집합
- [습관] 제출 전 들여쓰기 확인. 체력 관리도 실력

### 코드
```python
# 입력
N = int(input())
dragon_lst = [tuple(map(int, input().split())) for _ in range(N)]


# 함수 설계
def is_range(r, c):
    return 0 <= r <= 100 and 0 <= c <= 100


direction = {0: (0, 1), 1: (-1, 0), 2: (0, -1), 3: (1, 0)}


# input이 c, r로 들어옴에 주의

def dragon(sc, sr, dirr, gen):
    dragon_body = set()
    dragon_body.add((sr, sc))

    # 드라군 그려유
    r, c = sr, sc
    direct = dirr  # 방향 키만 새롭게

    dirr_key = []  # 저장할 때 1씩 빼고 저장하기 ~
    for i in range(gen + 1):
        if i == 0:
            dr, dc = direction[direct]
            nr, nc = r + dr, c + dc
            if is_range(nr, nc):
                dirr_key.append(direct)
                dragon_body.add((nr, nc))

            r, c = nr, nc

        else:
            length = len(dirr_key)

            for idx in range(length - 1, -1, -1):  # key를 매번 거꾸로 읽어와서 저장
                key = dirr_key[idx]  # 여기서 거꾸로 접근
                now_key = (key + 1) % 4
                dr, dc = direction[now_key]
                nr, nc = r + dr, c + dc
                if is_range(nr, nc):
                    dirr_key.append(now_key)
                    dragon_body.add((nr, nc))
                    r, c = nr, nc  # 집중력 떨어져서 이거 한 칸 앞으로 들여씀

    return dragon_body


ans_set = set()

for i in range(N):
    # c, r, 방향, 세대
    sc, sr, dirr, gen = dragon_lst[i]
    found_dragon = dragon(sc, sr, dirr, gen)

    ans_set = ans_set.union(found_dragon)  # 어차피 중복 걸러주니깐

ans = 0
for tpl in ans_set:
    cnt = 0
    for dr, dc in ((0, 1), (1, 1), (1, 0)):
        nr, nc = tpl[0] + dr, tpl[1] + dc
        if (nr, nc) in ans_set:
            cnt += 1

    if cnt == 3:
        ans += 1
        # | 이게 합집합, - 이게 차집합 (첫 번째 - 두 번째)

print(ans)

```
