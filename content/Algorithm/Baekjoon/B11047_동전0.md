### 실패 / 성공 이유
- [범위] 역방향 range는 시작과 끝도 반대로, 끝은 포함 안 되므로 -1

### 코드 개선 방법
- 

### 코드
```python
num, goal = map(int, input().split())
coin = [int(input()) for _ in range(num)]
ans = 0

for i in range (len(coin)-1, -1, -1): # 역으로 탐색
    while coin[i] <= goal:
        goal = goal - coin[i]
        #print(goal)
        ans += 1
print(ans)
```
