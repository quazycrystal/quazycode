### 실패 / 성공 이유
- [초기화] 도로가 추가될 때마다 이전 탐색의 방문 정보와 거리(v)가 초기화되지 않음

### 코드 개선 방법
- [초기화] bfs를 몇 번 돌리는지 보고 매번 v 초기화

### 코드
```python
def bfs(s):
    v[s] = 0
    q = []
    q.append(s)

    while q:
        cur = q.pop(0)
        for nxt in adj[cur]:
            if v[nxt] == -1:
                v[nxt] = v[cur] + 1 # 1에서의 거리 구해야 함
                q.append(nxt)
    # 다 돌고 나왔는데 안 되면? 여기서 뭔가 해야겠는데

# 입력
node, edge = map(int, input().split())

# 인접, 방문
adj = [[] for _ in range(node+1)]

for i in range(edge):
    x, y = map(int, input().split())
    adj[x].append(y)
    adj[y].append(x)

fix = int(input())
for j in range(fix):
    x, y = map(int, input().split())
    adj[x].append(y)
    adj[y].append(x)
    v = [-1] * (node + 1) # v 초기화!!!!!!!!!!!! bfs 몇 번 돌리는지?
    bfs(1)
    print(*v[1:])
```
