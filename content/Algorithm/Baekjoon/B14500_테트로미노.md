### 걸린 시간: 48분 (구상 8분, 구현 30분, 디버깅 10분) (실패 횟수: -)

### 실패 / 성공 이유
- [백트래킹] bfs로 퍼지면 경우의 수가 겹쳐서 백트래킹으로 선회
- [엣지 케이스] 연속 백트래킹으로는 ㅗ 모양을 못 찾음 (한 번 돌아와야 함)

### 코드 개선 방법
- [함수 설계] ㅗ는 함수를 따로: 본인 중심 상하좌우 중 3칸 고르기
- [속도] 한 번 순회로 max 찾는 게 가지를 다 도는 것보다 빠름 (148ms vs 1860ms). 가지치기 추가

### 코드
```python
from collections import deque
from itertools import *

# 입력
row, col = map(int, input().split())
arr = [list(map(int, input().split())) for _ in range(row)]
v = [[0]*col for _ in range(row)]
ans = 0

# 백트래킹을... : ㅗ 빼고 찾을 수 있음
def btk(d, sr, sc, sm):
    global ans
    if d == 4:
        ans = max(ans, sm)
        return

    v[sr][sc] = 1

    for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
        nr, nc = sr+dr, sc+dc
        if 0 <= nr < row and 0 <= nc < col:
            if v[nr][nc] == 0:
                v[nr][nc] = 1
                btk(d+1, nr, nc, sm + arr[sr][sc])
                v[nr][nc] = 0

    v[sr][sc] = 0

# ㅗ 찾는 함수
def findU(sr, sc):
    global ans
    lst = []
    mx = 0
    for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
        nr, nc = sr+dr, sc+dc
        if 0 <= nr < row and 0 <= nc < col:
            lst.append((nr, nc))

    if len(lst) >= 3:
        for combi in combinations(lst, 3):
            r1, c1 = combi[0]
            r2, c2 = combi[1]
            r3, c3 = combi[2]
            sm = arr[sr][sc] + arr[r1][c1] + arr[r2][c2] + arr[r3][c3]
            if sm > mx:
                mx = sm

    ans = max(ans, mx)

for i in range(row):
    for j in range(col):
        btk(0, i, j, 0)
        findU(i, j)

print(ans)

```
