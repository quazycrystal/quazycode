algorithm: [백트래킹, 조합]
data_structure: [2차원 배열, set]
technique: [가지치기]
---

### 걸린 시간: 1차: 구상 9분, 구현 35분 (시험 중 3시간 16분 시점부터) / 2차: 2시간 더 (실패 횟수: 1차 시험 중 못 품, 2차 중간 시간 초과 여럿)

### 실패 / 성공 이유
- [시간 복잡도] 후보 270개 중 3개 * 사다리 판정 while → 거의 30억
- [문제 읽기] 가로선끼리 이어지면 안 됨
- [무한 루프] 사다리를 탔으면 즉시 아래로 내려가야. 아니면 두 열 사이를 왔다갔다
- [재귀] btk 인자를 잘못 넘김, 판정 함수를 두 번 호출

### 코드 개선 방법
- [가지치기] 선 하나로 고칠 수 있는 열은 2개뿐. 남은 횟수로 고칠 수 있는 것보다 어긋난 열이 많으면 컷
- [가지치기] 답이 나오면 바로 컷
- [자료구조] 바로 다음 좌표만 보는 상황은 set보다 2차원 배열 조회가 빠름
- [전처리] 놓을 수 있는 좌표만 미리 뽑아 넘기고 백트래킹에선 놓냐 안 놓냐만. 앞에서 놓은 선과 이어지는지는 체크

### 코드
```python
from itertools import *

# 입력
col, cross_num, row = map(int, input().split())
ladder = set()
for _ in range(cross_num):
    r, c = map(int, input().split())
    ladder.add((r, c)) # 1 인덱스 그대로

# 함수 - 사다리 판별
def run_ladder():
    cnt = 0
    for s_col in range(1, 1+col):
        sr, sc = 0, s_col
        r, c = sr, sc
        while r <= row: # 아까 1000만에다가 여기서 30번씩 10번 더 보니끼

            if (r, c) in ladder: # 분기가 있으면 옆으로
                r, c = r+1, c + 1 # 오른쪽 한 칸

            if (r, c-1) in ladder: # 여기는 접점이 왼쪽에
                r, c = r+1, c - 1 # 왼 쪽 한 칸

            if (r, c) not in ladder and (r, c-1) not in ladder:
                r, c = r+1, c # 그냥 내려감

        if c != s_col:
            cnt += 1
            # 다른 열만 본다

    return cnt # return 안 되고 다 돌아 왔으면 정답


# 백트래킹 써보자
pos_range = set(product(range(1, row+1), range(1, col))) - ladder
# 이중 for문이므로 우려하는 중복은 안 생기지만 ladder 제거
pos_range = list(pos_range)

ans = 4

def btk(d, nxt, ladder):
    global ans
    if d == 4 or d > ans:
        return

    result = run_ladder()
    if result == 0:
        ans = d
        return
    else:
        if result > 2*(3-d):
            # 한 번 선을 그을 때 고칠 수 있는 경우는 2개 뿐!
            return # 3번밖에 못 고치는데 그 경우보다 고쳐야 할 게 많으면 가망 없다
        else:
            for i in range(nxt, len(pos_range)):
                nxtr, nxtc = pos_range[i]
                if (nxtr, nxtc-1) not in ladder:
                    if (nxtr, nxtc+1) not in ladder:
                        ladder.add(pos_range[i])
                        btk(d+1, i+1, ladder)
                        ladder.remove(pos_range[i])

btk(0, 0, ladder)
if ans == 4:
    ans = -1
print(ans)
```
