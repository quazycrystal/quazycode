### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [입력] 가로 한 칸에 RGB 3개라 arr 열은 col의 3배. 쪼개서 써야 함
- [자료형] 멋대로 int 하지 말 것

### 코드 개선 방법
- [자료형] float 대신 기준값을 미리 3배
- [인덱스] 0, 3, 6으로 가려면 step 3 후 j//3

### 코드
```python
def bfs(sr, sc):
    v[sr][sc] = 1
    q = []
    q.append((sr, sc))
    while q:
        cur = q.pop(0)
        r = cur[0]
        c = cur[1]
        for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
            nr = r+dr
            nc = c+dc
            if 0 <= nr < row and 0 <= nc < col:
                if f_arr[nr][nc] == 255 and v[nr][nc] == 0:
                    v[nr][nc] = visit
                    q.append((nr, nc))

row, col = map(int,input().split())
arr = [list(map(int, input().split())) for _ in range(row)]
f_arr = [[0]*col for _ in range(row)]
v = [[0]*col for _ in range(row)]
T = 3 * (int(input())) # 기준값 미리 3배
visit = 0

for i in range(row):
    for j in range(0, col*3, 3): # !!!!!!!! 0, 012, 3, 345, 6, 678 가게 하고 싶으면 step 후에 j//3
        c1 = j
        c2 = j+1
        c3 = j+2
        if arr[i][c1] + arr[i][c2] + arr[i][c3] >= T:
            f_arr[i][j//3] = 255
        else:
            f_arr[i][j//3] = 0

for k in range(row):
    for l in range(col):
        if f_arr[k][l] == 255 and v[k][l] == 0:
            visit += 1
            bfs(k, l)

print(visit)
```
