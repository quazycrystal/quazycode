### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 전수 조사 → 자르기 순서. 반대로 생각했었음
- [재귀] 각 꼭짓점별 재귀를 생각 못 함. 결국 트리 구조

### 코드 개선 방법
- [변수] 1차원은 시작·끝 인덱스, 2차원은 시작 좌표 + 길이
- [재귀] 결과는 전역 변수에 누적, True/False 플래그로 바로 빠져나오기

### 코드
```python
def cut(sr, sc, l): # 세로, 가로, 길이
    global blue
    global white
    if l == 0: # 길이 1일때도 체크는 해야
        return # 돌아오는 값 안 받아도 전역 변수에 다 나누어 저장 됨
    cnt = 0
    # 색종이인지 체크
    for row in range(sr, sr + l):
        for col in range(sc, sc + l):
            if arr[row][col] == 1:
                cnt += 1

    if cnt == l**2: # 파란색!
        blue += 1
    if cnt == 0: # 흰 색!
        white += 1

    if cnt != 0 and cnt != l**2:
        nl = l//2
        cut(sr, sc, nl)
        cut(sr, sc + nl, nl) # 다음으로 넘어가니까 l은 다 //2
        cut(sr + nl, sc, nl)
        cut(sr + nl, sc + nl, nl)


N = int(input()) # 2의 제곱수
arr = [list(map(int, input().split())) for _ in range(N)]

blue = 0
white = 0
cut(0, 0, N)
print(white)
print(blue)

# True False 플래그로 false 되면 바로 나오게!
```
