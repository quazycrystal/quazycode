### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [제어 흐름] mid 계산을 자꾸 while 밖에 넣음
- [조건] 총합이 예산보다 작으면 다 줌

### 코드 개선 방법
- [이진 탐색] mid가 상한선. 상한선 이하면 그대로, 넘으면 상한선만큼 더해 비교

### 코드
```python
# B2512 예산
def binary(s, e):
    global ans

    while s <= e:
        mid = (s + e) // 2  # mid가 threshold
        # -> 자꾸 while 밖에 넣음..
        sm = 0
        for i in lst:
            if i <= mid:
                sm += i  # 상한선 보다 작거나 같으면 본인 더하기
            else:
                sm += mid  # 아니면 상한선

        if sm <= goal:
            # 정답 조건
            ans = mid
            s = mid + 1

        else:
            e = mid - 1

N = int(input())
lst = list(map(int, input().split()))
goal = int(input())
ans = 0

# 1. lst 총 합이 goal보다 작으면 다 준다
if sum(lst) <= goal:
    ans = max(lst)
else:
    binary(1, goal) # 다 1 이상

print(ans)

```
