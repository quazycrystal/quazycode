### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [범위] 범위 2^7

### 코드 개선 방법
- [이진 탐색] 카드 리스트를 정렬하고 거꾸로 num을 찾기

### 코드
```python
card = int(input())
card_lst = list(map(int, input().split()))
card_lst.sort()
num = int(input())
num_lst = list(map(int, input().split()))
ans = [0] * num
# 역으로 카드 리스트에서 num을 찾자

# 이진 탐색
for i in range(num): # num만큼 반복
    goal = num_lst[i] # 찾아야 하는 수
    s = 0
    e = card-1 # 인덱스

    while s <= e:
        m = (s + e) // 2
        if card_lst[m] == goal:
            ans[i] = 1
            break
        elif card_lst[m] > goal: # 왼쪽 값 써야
            e = m-1 # 본인 포함 할 이유 없음
        else:
            s = m+1

print(*ans)
```
