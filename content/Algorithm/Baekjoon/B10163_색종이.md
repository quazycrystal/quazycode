### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [범위] 왼쪽 아래 좌표 + 크기에서 끝 좌표는 미포함

### 코드 개선 방법
- [구현] 판에 들어온 순서 번호를 칠하고 남은 숫자 개수 세기

### 코드
```python
num = int(input())
arr = [[0]*1001 for _ in range(1001)] # 입력 범위만큼 공백
ans = []

for i in range(num):
    x, y, dx, dy = map(int, input().split())
    for j in range(x, x+dx):
        for k in range(y, y+dy):
            arr[j][k] = i+1 # 판에 색종이 붙이기, 들어오는 순서 = 색종이 면적에 넣을 숫자

for row in arr:
    row = [x for x in row if x != 0]
    ans.extend(row)  # 0 다 제거

for n in range(num): # 남은 것에서 각 숫자가 몇 개 있는지 추출
    print(ans.count(n+1))
```
