### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [DP] 오큰수와 다르게 앞 수를 다 훑어야 함. 1000*1000이라 2중 가능

### 코드 개선 방법
- [DP] dp[i]는 i번째 숫자를 마지막으로 포함. 나보다 작은 이전 값 뒤에 붙고, 최솟값은 1

### 코드
```python
# B11053 가장 긴 증가하는 부분 수열
N = int(input())
lst = list(map(int, input().split()))
stk = []
dp = [1]*N

for i in range(N):
    if i > 0:
        flag = 0
        mx = 1 # 나보다 큰 애 없어두 최솟값은 1
        for j in range(i): # 내가 이전의 모든 애들보다 클 때만 길이 갱신
            if lst[j] < lst[i]: # 나보다 작은 이전 애를 발견하면
                pos = dp[j] + 1 # 현재까지 나보다 작은 애들 뒤에 붙는다
                if pos > mx:
                    mx = pos
        dp[i] = mx
print(max(dp))

```
