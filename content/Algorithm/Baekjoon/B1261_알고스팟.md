### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [가중치] 이동 횟수가 아니라 부순 벽 개수가 가중치
- [힙] hq.append로 넣으면 일반 리스트가 됨. heappush

### 코드 개선 방법
- [다익스트라] 좌표를 그래프로 바꾸지 않고 bfs를 조금 바꿔서: (가중치, r, c)를 힙큐에
- [다익스트라] 꺼낸 가중치가 테이블 값보다 크면 이미 탐색된 쓰레기값이라 건너뜀

### 코드
```python
from heapq import *

col, row = map(int, input().split())
arr = [list(map(int, input())) for _ in range(row)]
v = [[10 ** 18] * col for _ in range(row)]  # 다익스트라 테이블 역할


def bfs(sr, sc):
    v[sr][sc] = 0  # 시작 값은 0!!! - 방문 관리 겸 다익스트라 테이블
    hq = []
    heappush(hq, (0, sr, sc))  # 힙큐를 큐로, 가중치를 앞에다 두고 힙큐에 넣기
    while hq:
        w, r, c = heappop(hq)
        # w, r, c = cur[0], cur[1], cur[2]

        # 중요!!!
        if v[r][c] >= w:

            for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
                nr = r + dr
                nc = c + dc
                if 0 <= nr < row and 0 <= nc < col:
                    # 가중치: arr 값
                    if v[nr][nc] > w + arr[nr][nc]:
                        v[nr][nc] = w + arr[nr][nc]
                        weight = v[nr][nc]
                        heappush(hq, (weight, nr, nc))

bfs(0, 0)
print(v[row - 1][col - 1])


```
