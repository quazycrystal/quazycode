### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [메모리] a, b가 10^9까지라 인접 리스트, 방문 배열을 못 만듦. 중복 판정 때문에 공간이 터짐
- [거리] while문 돌 때마다 레벨 변수를 따로 늘려서 틀림 (두 연산의 레벨이 섞임)

### 코드 개선 방법
- [자료구조] 방문 처리는 dict. key는 값, value는 거리(레벨)
- [큐] 큐에 현재 값과 연산 횟수를 튜플로 묶기
- [로직] 연산의 최솟값이니까 BFS. 액션 2개짜리 트리로 보기

### 코드
```python
def bfs(s, e):
    # 초기화
    global ans
    q = []  # q를 set으로 만들어 중복 방지...?
    v = {s:1}  # 방문 처리, 레벨도 저장해야 하니까 딕셔너리
    q.append(s)
    
    while q:
        cur = q.pop(0)
        count = cur[1]
        # 연산 1: 2 곱하기
        n1 = cur*2
        # 연산 2: 1 오른쪽에 추가
        n2 = int(str(cur)+"1")

        if n1 not in v or n2 not in v: # 계산한 key가 아닐 때
            count = v[cur]  # value로 거리 저장해 뒀으니
            v[n1] = v[cur] + 1

            if n1 == e or n2 == e:
                ans = count
                break

# 입력
a, b = map(int, input().split())
ans = 0  # 최소 연산
bfs(a, b)

print(ans)  # 최소 + 1
```
