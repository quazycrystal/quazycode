### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [가지치기] 확률은 작아지면 더 못 커지므로 현재 최댓값 이하면 버림
- [초기화] 곱하기는 1로 시작

### 코드 개선 방법
- [출력] 소수점 자리는 f'{ans:.6f}'

### 코드
```python
def btk(n, per):
    global ans
    if per <= ans: # 같거나 작으면 버린다!!! 작기만 해도 통과가 안 됨
        return # 퍼센트는 이미 작아져버리면 다음 확률이 100프로라도 더 못 커짐

    if n == N:
        if ans < per:
            ans = per
        return

    for col in range(N):
        if v[col] == 0:
            v[col] = 1
            btk(n+1, per * (arr[n][col] / 100))
            v[col] = 0

T = int(input())
for tc in range(1, 1+T):
    N = int(input())
    arr = [list(map(int, input().split())) for _ in range(N)]
    ans = 0
    v = [0] * N
    btk(0, 1)  # 곱하기는 항상 1
    ans = ans * 100
    print(f'#{tc} {ans:.6f}') # 변수:.6f
```
