### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [조건] 두 문제 이상, 난이도 차이 ≥ X, 합은 L 이상 R 이하

### 코드 개선 방법
- [재귀] 포함 / 미포함 각각 최대·최소를 인자로 넘기기

### 코드
```python
def camp(n, cnt, mx, mn, sm): # 깊이, 문제 갯수, 최대 난도, 최소 난도, 합
    global ans
    if n == N:
        #print(n, cnt, mx, mn, sm)
        if cnt >= 2: # 두 문제 이상 골랐고
            if mx - mn >= dif: # 문제 간 난이도 차이는 dif보다 크거나 같
                if sm >= low_sm: # 문제 난이도 합은 하한선 보다 크거나 같
                    if sm <= high_sm: # 문제 난이도 합은 상한선 보다 작거나 같
                        # print(mx, mn, sm, cnt)
                        ans += 1
        return
    # 일단 미포함 먼저 불러!
    camp(n + 1, cnt, mx, mn, sm) # 미포함
    # 새 원소가 포함 안 되어서 최소 최대도 갱신되지 않은 상태


    # 최대 최소 갱신
    if problem[n] > mx:
        mx = problem[n]

    if problem[n] < mn:
        mn = problem[n]

    camp(n + 1, cnt+1, mx, mn, sm + problem[n]) # 포함

N, low_sm, high_sm, dif = map(int, input().split())
problem = list(map(int, input().split()))
ans = 0
camp(0, 0, 0, 10**6, 0)
print(ans)

```
