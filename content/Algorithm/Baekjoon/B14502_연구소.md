### 걸린 시간: 1시간 50분 가량 (구상 20분, 풀이 26분, 디버깅 34분) (실패 횟수: 시간 내 못 품)

### 실패 / 성공 이유
- [복사] arr[:]는 2차원 이상에서 내부 리스트까지 복사 못 함. v를 고치면 arr도 바뀜
- [전역 변수] q를 전역에 두면 bfs 부를 때마다 사라짐. v, q는 bfs 안에서 매번 초기화
- [백트래킹] 행에 하나씩만 벽을 세움. 같은 행에서도 여러 개 골라야 함
- [시간 복잡도] 벽 3개라 빈 칸 전부 완전탐색 가능. for i, for j가 맞았는데 터질 거라 생각함

### 코드 개선 방법
- [습관] 안 된다고 단정하지 말고 조건을 하나하나 적어 보기
- [복사] 2차원은 [line[:] for line in arr] 또는 copy.deepcopy
- [조합] 빈 칸에서 3개 뽑기 (itertools.combinations)
- [속도] 1044ms → 리팩토링 296ms. 빈 칸 전처리

    q = deque() # 시작 지점도 오염 되지 않게

import sys
from collections import deque
from itertools import combinations

dy = [-1, 0, 1, 0]
dx = [0, 1, 0, -1]


# 1. TO GET THE INPUT

row_count, col_count = map(int, sys.stdin.readline().split())

grid = []
for row in range(row_count):
    grid.append(list(map(int, sys.stdin.readline().split())))


# 2. TO STORE BLANKS

blanks = []

for row in range(row_count):
    for col in range(col_count):
        if grid[row][col] == 0:
            blanks.append((row, col))


ans = 0

for now_case in combinations(blanks, 3):

    # (1) To install firewall

    for row, col in now_case:
        grid[row][col] = 1

    # (2) BFS - To spread fire

    queue = deque([])
    visited = [[0 for col in range(col_count)] for row in range(row_count)]

    for row in range(row_count):
        for col in range(col_count):
            if grid[row][col] == 2:
                queue.append((row, col))
                visited[row][col] = 1

    while queue:
        now_row, now_col = queue.popleft()
        for idx in range(4):
            next_row = now_row + dy[idx]
            next_col = now_col + dx[idx]
            if 0 <= next_row < row_count and 0 <= next_col < col_count:
                if not visited[next_row][next_col] and grid[next_row][next_col] != 1:
                    queue.append((next_row, next_col))
                    visited[next_row][next_col] = 1

    # (3) To count safe areas

    safe_count = 0
    for row in range(row_count):
        for col in range(col_count):
            if grid[row][col] == 0 and not visited[row][col]:
                safe_count += 1
    ans = max(ans, safe_count)

    # (4) To un-install firewall

    for row, col in now_case:
        grid[row][col] = 0

print(ans)
