### 실패 / 성공 이유
- [조건] 10만 이상이라 이진 탐색. 찾을 리스트(B)는 sort 하면 안 됨

### 코드 개선 방법
- 

### 코드
```python
N = int(input()) # lstA 길이
lstA = list(map(int, input().split()))
M = int(input()) # lstB 길이
lstB = list(map(int, input().split()))

lstA.sort()
# lstB는 sort 하면 안 됨

def binary(s, e, g): # 인덱스
    global ans
    while s <= e:
        mid = (s+e) // 2
        if lstA[mid] == g:
            ans = 1
            break
        elif lstA[mid] < g:
            s = mid + 1
        else:
            e = mid - 1
    print(ans)


for target in lstB:
    ans = 0
    binary(0, N-1, target)

```
