### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [문제 읽기] 서로 다른 숫자
- [로직] 불러본 값을 예상치와 비교. 거꾸로 비교하면 안 됨

### 코드 개선 방법
- [완전탐색] 수가 적으니 for 3개로 경우를 다 만들고 결과와 대조

### 코드
```python
def baseball(exp, real, result):  # for 문 3개 돌린 값 vs 결과 값

    global pos
    global cnt
    a, b, c = real[0], real[1], real[2]
    d, e, f = exp[0], exp[1], exp[2]

    strike = 0
    ball = 0

    if a == d:
        strike += 1
    elif a == e or a == f:
        ball += 1

    if b == e:
        strike += 1
    elif b == d or b == f:
        ball += 1

    if c == f:
        strike += 1
    elif c == d or c == e:
        ball += 1

    if result[0] == str(strike) and result[1] == str(ball):
        cnt += 1
        if cnt == N:
            pos.append(expect)
    # 다르면 break code
    else:
        return


N = int(input())
calls = []
results = []
pos = []
cnt = 0

for _ in range(N):
    call, s, b = input().split()
    calls.append(call)
    results.append((s, b))

for i in range(1, 10):
    for j in range(1, 10):
        if j == i:
            continue
        for k in range(1, 10):
            if k == i:
                continue
            if k == j:
                continue
            cnt = 0
            for calling in range(N):
                expect = str(i) + str(j) + str(k)
                baseball(expect, calls[calling], results[calling])

print(len(pos))

```
