### 실패 / 성공 이유
- [문제 읽기] 키보드 그림에서 모음 b가 한 칸 밀려 있음. 키 누르는 데도 1초

### 코드 개선 방법
- 

### 코드
```python
left = {'q': (0, 0), 'w': (0, 1), 'e': (0, 2), 'r': (0, 3), 't': (0, 4),
        'a': (1, 0), 's': (1, 1), 'd': (1, 2), 'f': (1, 3), 'g': (1, 4),
        'z': (2, 0), 'x': (2, 1), 'c': (2, 2), 'v': (2, 3)}


right = {'y': (0, 0), 'u': (0, 1), 'i': (0, 2), 'o': (0, 3), 'p': (0, 4),
        'h': (1, 0), 'j': (1, 1), 'k': (1, 2), 'l': (1, 3),
        'b': (2, -1), 'n': (2, 0), 'm': (2, 1)}
        # 문제 키보드 보자....... 모음 b가 한 칸 밀려 있다

f_left, f_right = input().split() # 시작 문자
s_left, s_right = left[f_left], right[f_right] # 시작 좌표

calls = list(input())
time = 0
pre_left, pre_right = s_left, s_right # 시작 좌표

for call in calls:
    if call in right:
        cur = right[call]
        r, c = cur[0], cur[1] # 현 좌표
        pr, pc = pre_right[0], pre_right[1] # 이전 좌표

        dist = abs(r-pr) + abs(c-pc)
        time += (dist + 1)

        pre_right = cur # 이전 좌표 갱신

    if call in left:
        cur = left[call]
        r, c = cur[0], cur[1]  # 현 좌표
        pr, pc = pre_left[0], pre_left[1] # 이전 좌표

        dist = abs(r - pr) + abs(c - pc)
        time += (dist + 1) # 키 누르는 데도 1초;;

        pre_left = cur

print(time)
```
