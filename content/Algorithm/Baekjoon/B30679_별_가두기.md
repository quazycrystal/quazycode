### 실패 / 성공 이유
- [문제 읽기] 열은 고정이고 시작 행만 달라지는데 for를 2번 돎
- [엣지 케이스] 같은 좌표로 돌아와도 방향이 다르면 무한 루프가 아님 (E자 모양)

### 코드 개선 방법
- [상태 확장] 방문 여부는 좌표 + 방향으로. 같은 방향으로 같은 좌표에 오면 가둔 것
- [시간 복잡도] 같은 상태를 만나면 컷하니 열 길이 * 4배 이내

```python
d = {0: (0, 1), 1: (1, 0), 2: (0, -1), 3: (-1, 0)} # 우 하 좌
idx = 0
def move(s):
    global idx
    r, c = s[0], s[1]
    dr, dc = d[idx % 4]
    dist = arr[r][c]
    nr, nc = r + (dr * dist), c + (dc * dist)
    idx += 1
    if 0 <= nr < row and 0 <= nc < col:
        if (nr, nc) != start:
            print(nr, nc)
            return (nr, nc)
        else:
            ans.append(begin)
            return 0
    else:
        return 0

row, col = map(int, input().split())
arr = [list(map(int, input().split())) for _ in range(row)]
ans = []

for i in range(row):
    for j in range(col):
        start = (i, j)
        begin = start
        while True:
            begin = move(begin)
            if begin == 0:
                break


print(ans)
```
