### 코드
```python
# 테케 갯수 자꾸 헷갈리는데, 일단 예제 보고 판단

lines = []
while True:
    try:
        lines.append(input())
    except EOFError:
        break

#for line in lines:
answer = ''
temp_sum = 0
price_sum = int(lines[0])
for i in range(int(lines[1])):
    price, number = map(int, lines[i+2].split())
    temp_sum += price * number
if temp_sum == price_sum:
    answer = 'Yes'
else:
    answer = 'No'

print(answer)
```
