### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 가로로 자르면 세로가 등분됨

### 코드 개선 방법
- 

### 코드
```python
row, col = map(int, input().split())
cut = int(input())
r = [0, row]
c = [0, col]

for i in range(cut):
    dir, val = map(int, input().split())
    if dir == 0:
        c.append(val)
    if dir == 1:
        r.append(val) # 가로로 자르면 세로가 등분됨
r.sort()
c.sort()

mx_r = 0
mx_c = 0
for j in range(len(r) - 1):
    cr = r[j+1] - r[j]
    if cr > mx_r:
        mx_r = cr

for k in range(len(c) - 1):
    cc = c[k+1] - c[k]
    if cc > mx_c:
        mx_c = cc

print(mx_c * mx_r)
```
