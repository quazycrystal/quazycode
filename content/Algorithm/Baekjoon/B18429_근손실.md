### 실패 / 성공 이유
- [조건] 증량이 같아도 키트가 다르면 다른 경우
- [가지치기] 하루라도 500 이하로 떨어지면 컷

### 코드 개선 방법
- 

### 코드
```python
def health(n, pw):
    global ans
    if pw < 500: # 하루라도 500 이하로 떨어지면
        return
    if n == N:
        ans += 1
        return
    for col in range(N):
        if v[col] == 0:
            v[col] = 1
            health(n+1, pw - loss + kit[col])
            v[col] = 0


N, loss = map(int, input().split())
kit = list(map(int, input().split()))
v = [0] * N
ans = 0
health(0, 500)
print(ans)
```
