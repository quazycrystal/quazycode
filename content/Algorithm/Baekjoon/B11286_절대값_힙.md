### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [힙] 음수로 들어온 값은 음수로 나와야 함

### 코드 개선 방법
- [힙] (절댓값, 원래 값) 튜플로 우선순위

### 코드
```python
import heapq
# 음수로 들어온 애는 음수로 나와야 함!
lst = []
hq = []
while True:
    try:
        i = int(input())
        lst.append((abs(i), i))
    except EOFError:
        break

N = lst.pop(0)[1]

for x in range(N):
    if lst[x] == (0, 0):
        if hq:
            ans = heapq.heappop(hq) # 괄호 안 리스트 이름
            print(ans[1])
        else:
            print(0)

    else:
        heapq.heappush(hq, lst[x])  # 모듈 이름.기능

```
