### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [범위] 숫자가 커서 백트래킹 아님
- [좌표] x, y 순 (col, row)

### 코드 개선 방법
- [로직] |사대 - 동물x| + y ≤ L이니 동물마다 가능한 사대 범위를 구해 그 안에 사대가 있는지 확인
- [가지치기] y가 사정거리를 넘는 동물은 미리 쳐내기

### 코드
```python
guns, animals, dist = map(int, input().split())
gun_lst = list(map(int, input().split()))
ani_loc = []
for _ in range(animals):
    x, y = map(int, input().split())
    if y > dist: # 너무 많으니까 일단 동물 y 거리가 사정거리 초과인 애들 쳐내
        continue
    # 식은 |사대-동물x| + y이므로
    ani_loc.append((x - (dist-y), x + (dist-y))) # 이 범위 안에 사대 숫자가 들어오면 가능

ani_loc.sort(key = lambda x:x[1])
gun_lst.sort()

ans = 0
animals = len(ani_loc)

i = 0
j = 0

# 그리디한 회의실 문제처럼, 끝에보다 적게?
while 0 <= i < guns and 0 <= j < animals:
    if ani_loc[j][0] <= gun_lst[i] and gun_lst[i] <= ani_loc[j][1]:
        ans += 1
        j += 1
    else:
        if i < guns-1:
            i += 1
        else:
            j += 1

print(ans)
```
