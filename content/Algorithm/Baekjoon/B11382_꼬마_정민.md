### 코드 개선 방법
- [입출력] sys.stdin으로 줄 단위 입력 받기

### 코드
```python
# while 분기 사용
lines = list()
while True:
    try:
        lines.append(input())
    except EOFError:
        break

for test_case in lines:
    answer = 0
    x, y, z = map(int, test_case.split())
    answer = x + y + z

    print(answer)
```
