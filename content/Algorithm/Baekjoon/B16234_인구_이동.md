### 걸린 시간: 총 57분 (구상 약 15분, 구현 30분, 디버깅 12분) (실패 횟수: -)

### 실패 / 성공 이유
- [방문 처리] 단순 방문과 연합된 국가를 구별해야 함. 연합이면 양수, 아니면 음수
- [방문 처리] 조건이 완전히 맞을 때만 방문 표시해야 하는데 범위만 맞으면 표시함
- [시간 복잡도] 50^4가 걱정됐지만 방문처리로 걸러져 통과
- [엣지 케이스] 하루에 서로 떨어진 연합이 여럿 생길 수 있음

### 코드 개선 방법
- [구상] 하루에 bfs를 몇 번 돌고 날짜마다 넘길 인자를 먼저 적고 시작
- [속도] 그냥 방문한 곳은 -2로 표시 (1152 → 1096ms). bfs 안에서 바로 값을 바꾸면 700ms대

### 코드
```python
from collections import deque
def bfs(sr, sc):
    global sm, cnt
    local_sm = 0
    num = 0
    # 이 한 영역에서 생기는 값 다 더하기
    q = deque()
    q.append((sr, sc))
    while q:
        r, c = q.popleft()
        for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
            nr, nc = r+dr, c+dc
            if 0 <= nr < size and 0 <= nc < size:
                if v[nr][nc] == -1 and (nr, nc) != (sr, sc):
                    if mini <= abs(arr[nr][nc] - arr[r][c]) <= maxi:
                        v[nr][nc] = cnt # 방문처리도 조건이 다 맞았을 때만!
                        local_sm += arr[nr][nc]
                        num += 1
                        q.append((nr, nc))

    # bfs 다 끝나고...
    if local_sm != 0:
        local_sm += arr[sr][sc] # 조건에 맞은게 하나라도 있으면 초기값 추가
        num += 1
        v[sr][sc] = cnt # 최초 진입이 모든 조건에 맞았을 때만 방문 처리

        sm.append((local_sm, num))
        cnt += 1 # 다음 번에 조건에 맞는 함수 돌 때 더 커진 수가 방문에 찍히게
    else:
        v[sr][sc] = -2



# 입력
size, mini, maxi = map(int, input().split())
arr = [list(map(int, input().split())) for _ in range(size)]

sm = []
cnt = 0

ans = 0
while True:
    v = [[-1] * size for _ in range(size)]
    for row in range(size):
        for col in range(size):
            if v[row][col] == -1:
                bfs(row, col)

    flag = 0
    for row2 in range(size):
        for col2 in range(size):
            nation_idx = v[row2][col2]
            if 0 <= nation_idx < len(sm):
                ppl, nation_num = sm[nation_idx]
                arr[row2][col2] = ppl//nation_num # 혹시나 하루에 서로 떨어진 연합이 여럿 생길까봐...
            else: # 값이 -1 / -2 이다!
                flag += 1

    if flag == (size*size):
        break
    else:
        ans += 1

print(ans) # 확인하느라 루프 한 번 더 돎 -> 나중에 분기로 ans+1해서 -1 안 해도 되게
```
