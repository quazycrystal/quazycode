### 코드 개선 방법
- [문법] 제너레이터 표현식은 [] 대신 소괄호

### 코드
```python
lst = [list(input()) for _ in range(5)]
mx = max(len(row) for row in lst) #제너레이터 표현식, []대신 소괄호
answer = ''

# 공백도 없이, 그냥 공백을 채울 수도 있다
for i in range(5):
    if len(lst[i]) < mx:
        for _ in range(mx-len(lst[i])):
            lst[i].append('')
lst_t = list(zip(*lst))

for j in range(mx):
    for k in range(5):
        answer += lst_t[j][k]
print(answer)
```
