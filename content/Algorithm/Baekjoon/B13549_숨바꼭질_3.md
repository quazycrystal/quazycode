### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [범위] 10만, 2초. 순간이동이 0초라 가중치가 다름

### 코드 개선 방법
- [다익스트라] 힙에 (시간, 위치). 순간이동 0초, 걷기 1초
- [가지치기] 음수로 떨어지거나 너무 커지면 최선이 될 수 없으니 컷

### 코드
```python
from heapq import *

def find(now):
    v[now] = 0
    hq = []
    heappush(hq, (0, now))
    while hq:
        dist, loc = heappop(hq)
        # 정답
        if loc == dong:
            break

        if dist <= v[loc]:
            for i in range(3):
                nxt = loc
                nxt_dist = dist
                if i == 0:
                    nxt = loc - 1
                    nxt_dist = dist + 1
                elif i == 1:
                    nxt = loc + 1
                    nxt_dist = dist + 1
                else:
                    nxt = loc * 2
                    nxt_dist = dist

                if 0 <= nxt <= 100000:
                    if nxt_dist < v[nxt]:
                        v[nxt] = nxt_dist
                        heappush(hq, (nxt_dist, nxt))


# 입력
subin, dong = map(int, input().split())
# 방문 배열
v = [10**18] * 100001
find(subin)
print(v[dong])
```
