### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [시간 복잡도] 범위 1000만이라 for문에서 매번 합을 새로 구하면 시간 초과
- [반례] 자기 자신을 못 찾음 (4, 15). range 문제
- [무한 루프] 답 나왔을 때 개수만 더하면 무한 루프

### 코드 개선 방법
- [투 포인터] 합이 부족하면 end를 더하고 넘치면 start를 빼기. 포인터 변수가 곧 더할 숫자. while 하나로 됨

### 코드
```python
goal = int(input())

i = 1
j = 1
sm = 1
ans = 0


while i <= goal:
    if sm < goal:
        j += 1
        sm += j # 더하는 건 1 더하고 가고

    if sm > goal:  # 자기 자신의 경우도 여기에 걸림
        sm -= i # 빼는 건 먼저 1 빼고 가고 (시작 포인터와 끝 포인터가 같은 위치이므로)
        i += 1

    if sm == goal:
        ans += 1
        # 답 나왔을 때 답 갯수만 더하면 무한 루프
        j += 1
        sm += j
        # 답을 벗어나게

print(ans)
```
