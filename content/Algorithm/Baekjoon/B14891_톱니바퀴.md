### 걸린 시간: 1시간 30분 (실패 횟수: -)

### 실패 / 성공 이유
- [방향] 1은 시계, -1은 반시계. rotate(1)은 뒤 -> 앞, rotate(-1)은 앞 -> 뒤
- [인덱스] 톱니 번호는 1 크게 들어옴. 인접 관계는 커지는 쪽은 1 빼고, 작은 쪽은 본인 인덱스로 접근
- [시간 복잡도] 회전 100 * 톱니 4라 여유

### 코드 개선 방법
- [구현] bfs 대신 기준점에서 dist를 for문으로 늘려가며 양쪽으로 퍼지기
- [함수 설계] 상태 갱신(refresh)과 톱니 돌리기 함수 분리

### 코드
```python
def refresh():
    global adj_topni
    adj_topni = [[t[0][2], t[1][6]], [t[1][2], t[2][6]], [t[2][2], t[3][6]]]
    # 현 톱니 상태 읽어와요

def bingle(cmd):
    loc, dirr = cmd
    loc -= 1 # 톱니 인덱스 1 크게 들어옴
    top_dirr = [0, 0, 0, 0] # 현재 설정된 톱니 방향
    top_dirr[loc] = dirr

    for dist in range(1, 4):
        big = loc + dist
        small = loc - dist
        if big < 4:
            adj = adj_topni[big - 1]
            if adj[0] != adj[1]: # 서로 인접 톱니가 달라!
                top_dirr[big] = -top_dirr[big-1]
                # 인접 친구 방향의 -

        if small >= 0:
            adj = adj_topni[small]
            if adj[0] != adj[1]: # 서로 인접 톱니가 달라!
                top_dirr[small] = -top_dirr[small+1] # 정답에 가까운 쪽을 보아라 ~
                # 인접 친구 방향의 -


    for idx in range(4):
        now_dirr = top_dirr[idx]
        if now_dirr == 1:
            last = t[idx].pop()
            t[idx].insert(0, last)
        elif now_dirr == -1:
            last = t[idx].pop(0)
            t[idx].append(last)


# 입력
t = [list(map(int, input())) for _ in range(4)]
cmd_num = int(input())
cmd_lst = [tuple(map(int, input().split())) for _ in range(cmd_num)]
adj_topni = []

for command in cmd_lst:
    refresh()
    bingle(command)

ans = 0
for i in range(4):
    if t[i][0] == 1:
        ans += 2**i

print(ans)

```
