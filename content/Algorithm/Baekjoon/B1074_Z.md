### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [재귀] 4분면을 모두 채우면 터짐. 정답이 속한 사분면 하나만 보고 반씩 쪼개기

### 코드 개선 방법
- [가지치기] 정답 좌표에서 현재 반 길이를 빼서 음수/양수로 사분면 판정. 앞 사분면 칸 수(4^(N-d))만큼 더함
- [좌표] 사분면 시작점을 더해야 절대 좌표처럼 동작

### 코드
```python
# B1074 Z
def btk(d, length, num, jwa):  # d, length + 뭘로 채워? + 어디를 채워?
    global ans
    if d == N:  # 이미 칸이 골라진 거 # 여기서 채워야 해!!!
        ans = num
        return

    length = length // 2
    r, c = jwa # 사분면 시작 좌표 ex) (0, 0)

    # 사분면 고르기 코드
    four_r = gr - (length + r) # 시작점을 더해야 절대좌표처럼 동작
    four_c = gc - (length + c)

    i = 0
    if four_r < 0 and four_c < 0:
        i = 0
    elif four_r < 0 and four_c >= 0:
        i = 1
    elif four_r >= 0 and four_c < 0:
        i = 2
    elif four_r >= 0 and four_c >= 0:
        i = 3

    if i == 1:
        c = c + length
    elif i == 2:
        r = r + length
    elif i == 3:
        r = r + length
        c = c + length

    num += i * (length * length)
    # num_nxt += i * (length * length)
    btk(d+1, length, num, (r, c))

# 입력
N, gr, gc = map(int, input().split())

ans = 0
flag = 0
btk(0, 2**N, 0, (0, 0))
print(ans)

```
