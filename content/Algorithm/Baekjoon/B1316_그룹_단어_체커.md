### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 자기 자신까지 appeared에 넣은 채로 비교해서 틀림 (ba처럼 한 글자씩 다르면 false negative)
- [문법] {}는 set이 아니라 dict로 인식

### 코드 개선 방법
- [로직] 이전에 저장된 문자와 비교를 마친 뒤에 추가하기 (셀프 비교 방지)

### 코드
```python
n = int(input())
answer = 0
for i in range(n):
    string = input()
    answer += 1
    appeared = set()  # {}는 딕셔너리로 인식

    for j in range(len(string)):
        if j > 0:
            if string[j-1] != string[j] and string[j] in appeared:
                answer -= 1
                break
        if string[j] not in appeared:
            appeared.add(string[j])
print(answer)
```
