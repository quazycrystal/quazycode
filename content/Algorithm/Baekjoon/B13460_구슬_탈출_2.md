### 걸린 시간: 5시간 11분 (15:13 - 20:24), 디버깅 2시간 넘게 (실패 횟수: 1트 실패)

### 실패 / 성공 이유
- [제어 흐름] 파란 구슬이 먼저/같이 빠진 경우는 continue여야 하는데 return해서 남은 경우의 수까지 종료. return은 정답일 때만
- [복사] 함수 인자로 넘긴 배열도 원본 참조. 복사나 재할당 필요 (40분+)
- [문제 읽기] 1트: '동시에 들어온다(뒤에 따라 들어온다)'의 정의를 안 잡음

### 코드 개선 방법
- [BFS] (빨강 좌표, 파랑 좌표) 쌍을 set에 방문 표시. 같은 상황은 다시 큐에 안 넣음
- [이동] 다음이 벽이 아니고 현재가 구멍이 아닐 때까지 이동 → 구멍까지는 감
- [동시 이동] 두 공 다 끝까지 보내고, 겹치면 더 많이 이동한 공을 한 칸 뒤로
- [가지치기] 같은 방향 연속 2번이면 컷
- [시간 복잡도] 4^10 ≈ 10^6

### 코드
```python
# 지난번 방향 저장해두면 가지치기도 가능

# set 방문 체크 좀 더 잘 떠올려보자

# 입력
row, col = map(int, input().split())
arr = [list(input()) for _ in range(row)]

# 방향
direction = {0: (-1, 0), 1: (1, 0), 2: (0, -1), 3: (0, 1)}


# 함수 설계
def move(tpl, color, dirr, v):
    v_copy = [line[:] for line in v]

    dr, dc = direction[dirr]
    r, c = tpl
    bong = 0
    goal = 0
    while True:
        nr, nc = r + dr, c + dc

        if 0 <= nr < row and 0 <= nc < col:
            if v_copy[nr][nc] == "#":
                break

            elif v_copy[nr][nc] == "R" or v_copy[nr][nc] == "B":

                if color == "R":
                    bong = 1
                break

            elif v_copy[nr][nc] == ".":
                v_copy[nr][nc] = color
                v_copy[r][c] = "."
                r, c = nr, nc

            else:  # "O"일 때

                if color == "R":
                    goal = 1

                if color == "B":
                    goal = -1

                v_copy[nr][nc] = color
                v_copy[r][c] = "."
                r, c = nr, nc
                break

        else:
            break

    return (r, c), bong, goal, v_copy


# 백트래킹...
def btk(d, v, red, blue):
    global ans
    if d == 10:
        return
    if d > ans:
        return

    for cmd in range(4):

        new_red, bong, red_goal, v1 = move(red, "R", cmd, v)
        new_blue, _, blue_goal, v2 = move(blue, "B", cmd, v1)
        if bong == 1:
            new_red, bong, red_goal, v2 = move(new_red, "R", cmd, v2)

        # 1. 정답 도착 했는지부터 v2 봐야 함

        if blue_goal == -1:
            continue  # blue가 먼저 도달 - red 볼 필요도 없다

        if red_goal == 1:
            # 바로 뒤에 blue가 있는지 없는지
            dr, dc = direction[cmd]
            rr, rc = new_red
            back_r, back_c = rr - dr, rc - dc

            if v2[back_r][back_c] == "B":  # 뒤에 blue면 종료
                continue  # 뒤에 정답 있을수도
            else:
                loc_ans = d + 1
                ans = min(ans, loc_ans)  # 요때가 정답
                return

        if new_red == red and new_blue == blue:
            continue  # return하면 함수 자체가 종료되므로,,, 구냥 다음 경우의 수 보게 continue

        btk(d + 1, v2, new_red, new_blue)


# 전처리
s_red = ()
s_blue = ()
goal = ()

for i in range(row):
    for j in range(col):
        if arr[i][j] == "R":
            s_red = (i, j)
        elif arr[i][j] == "B":
            s_blue = (i, j)
        elif arr[i][j] == "O":
            goal = (i, j)

# 풀이
INF = float("inf")
ans = INF
btk(0, arr, s_red, s_blue)

if ans == INF:
    ans = -1

print(ans)
```
