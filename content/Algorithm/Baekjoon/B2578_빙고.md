### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 11개 부르기 전까지는 빙고가 안 됨
- [함수 설계] 무엇을 넘겨줄지 몰라서 함수화 실패

### 코드 개선 방법
- [로직] 좌표를 찍어두고 하나 변할 때 영향받는 줄만 카운트

### 코드
```python
me = [list(map(int, input().split())) for _ in range(5)]
call = []
for _ in range(5):
    call.extend(list(map(int, input().split())))

ans = 0  # 빙고 갯수


# 함수화 못 했던게 뭘 어떻게 넘겨줄 지 몰라서

def get_pos(no):
    for row in range(5):
        for col in range(5):
            if me[row][col] == no:
                me[row][col] = 0


for i in call:
    get_pos(i)  # 내 빙고판 표시
    # me[r][c] = 0  # 내 빙고판 표시

    for r in range(5):
        for c in range(5):
            if me[r][c] == 0:
                for dr, dc in ((-1, 1),
                               (0, 1),
                               (1, 1),
                               (-1, 0)):  # 오목처럼 왼쪽 시작점일때만 본다
                    cnt = 1  # 초기화를 for 문 안에서
                    for j in range(1, 5):
                        nr = r + dr * j
                        nc = c + dc * j
                        if 0 <= nr < 5 and 0 <= nc < 5:
                            if me[nr][nc] == 0:
                                cnt += 1
                                if cnt == 5:
                                    print(call.index(i) + 1)
                                    ans += 1  # 빙고
                                    if ans == 3:
                                        print(call.index(i) + 1)
                            else:
                                cnt = 1





```
