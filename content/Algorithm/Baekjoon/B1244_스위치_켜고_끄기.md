### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [제어 흐름] while문은 한 단계 더 가서 break 됨. 1씩 더하고 빼야
- [문법] del은 index로, 점(.)없음

### 코드 개선 방법
- 

### 코드
```python
num = int(input())
switch = ["x"] + list(map(int, input().split()))
ppl = int(input())
for i in range(ppl):
    gender, get = map(int, input().split())
    if gender == 1:
        change = num // get # 받은 수의 배수가 되는 스위치 모두 바꿈
        for idx in range(1, change+1):
            s_idx = get * idx
            if switch[s_idx] == 0:
                switch[s_idx] = 1
            else:
                switch[s_idx] = 0

    elif gender == 2:
        delta = 0
        mn = get
        mx = get
        while mx <= num: # 아하 이거 넘으면 자동 종료라서 가능
            if switch[mn] != switch[mx]:
                break
            delta += 1
            mn = get - delta
            mx = get + delta

        for k in range(mn+1, mx): # while 문은 한 단계 더 가서 break 됨 -> 1씩 더하고 빼야
            if switch[k] == 1:
                switch[k] = 0
            else:
                switch[k] = 1

del switch[0] # del도 index, . 없음!!!
for line in range(0, num, 20):
    ans = switch[line: line+20]
    if ans:
        print(*ans)
```
