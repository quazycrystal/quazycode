### 걸린 시간: 58분 (구상 5분, 구현 25분, 디버깅 28분) (실패 횟수: -)

### 실패 / 성공 이유
- [덱] 리스트가 아니라 덱으로 선언해야 rotate. rotate(1)은 맨 뒤가 맨 앞, (-1)은 두 번째가 맨 앞
- [구현] 후진은 - 이동인데 +로 감
- [문제 읽기] 주변 네 칸을 먼저 보는 게 아니라, 반시계로 돌면서 청소 안 된 칸을 찾아 그쪽으로
- [엣지 케이스] 후진할 때는 청소된 칸도 갈 수 있음. == 0으로 조건을 잡으면 엣지

### 코드 개선 방법
- [자료구조] 방향은 dict, 회전은 덱 rotate

### 코드
```python
# 입력
from collections import deque
row, col = map(int, input().split())
cr, cc, dr = map(int, input().split()) # 시작 위치, 현 방향
arr = [list(map(int, input().split())) for _ in range(row)]
dir_d = deque([0, 3, 2, 1]) # 덱으로 돌려가며...
d = {0:(-1, 0), 3:(0, -1), 2:(1, 0), 1:(0, 1)} # 반 시계 방향, 어딜 볼 건지

# 방향 초기화
while dir_d[0] != dr:
    dir_d.rotate(-1) # 맨 앞 인덱스 현 방향으로 맞춰둔다


# 현재 칸 본다
def bfs(sr, sc):
    global dir_d
    q = deque()
    q.append((sr, sc))
    while q:
        r, c = q.popleft()
        #  1. 현재 칸 청소
        if arr[r][c] == 0:
            arr[r][c] = 2  # 청소 한 곳이면 2
        # 2. 주변 칸 둘러 본다

        # 2-1 청소되지 않은 빈 칸이 있다
        flag = 0
        for i in range(4):
            dir_d.rotate(-1) # 한 칸 돌리기
            direct = dir_d[0]
            nxt_r, nxt_c = r + d[direct][0], c + d[direct][1]
            if 0 <= nxt_r < row and 0 <= nxt_c < col:
                if arr[nxt_r][nxt_c] == 0: # 다음 위치 청소 안 됐으면
                    q.append((nxt_r, nxt_c)) # 다음 위치는 저 곳
                    break
                else:
                    flag += 1


        # 2-2 청소되지 않은 빈 칸이 없다
        if flag == 4:
            direct = dir_d[0]
            nxt_r, nxt_c = r - d[direct][0], c - d[direct][1] # 후진이니 -
            if 0 <= nxt_r < row and 0 <= nxt_c < col:
                if arr[nxt_r][nxt_c] != 1: # 벽이 아니면 후진
                    q.append((nxt_r, nxt_c))
                # 만약 벽이라 후진할 수 없으면 작동 멈추므로 q에 넣지 않는다

# bfs 호출
bfs(cr, cc)

# 답
ans = 0
for rr in arr:
    ans += rr.count(2)

print(ans)
```
