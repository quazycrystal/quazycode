### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [원본 수정] del로 원본을 지우면 idx error. 어떤 경우에도 원본 지우지 말기
- [제어 흐름] break는 for문 하나만 나감
- [시간] sum을 for문 안에서 하면 런타임 에러 가능성

### 코드 개선 방법
- [원본 수정] del 대신 다른 리스트에 복사

### 코드
```python
lst = [int(input()) for _ in range(9)]
lst_f = []
flag = False
sm = sum(lst) # sum이 for문 안이면 런타임 에러 가능성 높음

for i in range(8): # 위가 n-1
    for j in range (i+1, 9): # 아래가 n
        val = sm - (lst[i] + lst[j])
        if val == 100:
            for k in range (9):
                if k != i and k != j:
                    lst_f.append(lst[k])
            flag = True
            break
        if flag:
            break

lst_f.sort(reverse = True)
for i in range (7): # 범위 주의
    print(lst_f.pop()) # 좀 더 파이썬스러운 출력
```
