---
algorithm: [시뮬레이션]
data_structure: [2차원 배열]
technique: [달팽이, 룩업 테이블]
---

### 걸린 시간: 1시간 16분 (구상 10분, 풀이 57분, 디버깅 9분) (실패 횟수: -)

### 실패 / 성공 이유
- [좌표] 모래 날리기 함수 좌표 r, c. 이름 찍어가며 보니 보임
- [초기화] 이동 변수(check, turn, go)를 for 안에서 초기화

### 코드 개선 방법
- [달팽이] 이만큼 가면 방향 전환, 두 번 전환마다 거리 +1
- [룩업 테이블] 방향별 퍼센트 좌표를 테이블로. 쓰인 모래는 빼고 나머지는 α 칸으로
- [함수 설계] 모래 날리기 함수를 먼저 만들고 따로 디버깅
- [정답] 처음 총 모래 - 남은 모래 = 밖으로 나간 모래

### 코드
```python
# 시간 복잡도 O(N^2) - 퍼센트도 곱해서 10N^2 정도라 생각

from collections import deque

# 입력
size = int(input())
arr = [list(map(int, input().split())) for _ in range(size)]

# 미리 모래 얼마나 있는지 알아두자요
sm = 0
for rr in arr:
    sm += sum(rr)

# 방향, 퍼센트 룩업테이블
direction = deque([(0, -1), (1, 0), (0, 1), (-1, 0)])
# 왼 아래 오 위

# 함수: 모래 계산
mid = size // 2 # 중심부터 시작

def is_range(sr, sc):
    if 0 <= sr < size and 0 <= sc < size:
        return True
    else:
        return False

def sand_blow(sr, sc): # 폭풍이 와 있는 현 위치 - 얘는 (0,0) 직전까지만 돌아
    dr, dc = direction[0]
    side = []
    if dr == 0: # 좌 우
        side = [(-1, 0), (1, 0)] # 하 상
    else:
        side = [(0, -1), (0, 1)] # 좌 우

    full_sand = 0 # 여기서 쓰인 모래 다 빼줘야
    sand_1 = 0
    sand_2 = 0
    sand_5 = 0
    sand_7 = 0
    sand_10 = 0
    leftover = 0
    # 여긴 내가 가려는 방향의 앞
    yr, yc = sr + dr, sc + dc # 여기 전체 모래
    if is_range(yr, yc):
        full_sand = arr[yr][yc]
        sand_1 = int(full_sand * 0.01)
        sand_2 = int(full_sand * 0.02)
        sand_5 = int(full_sand * 0.05)
        sand_7 = int(full_sand * 0.07)
        sand_10 = int(full_sand * 0.1)
        leftover = full_sand - ((sand_1 + sand_2 + sand_7 + sand_10) * 2 + sand_5)
        arr[yr][yc] = 0

    ar, ac = yr + dr, yc + dc
    if is_range(ar, ac):
        arr[ar][ac] += leftover # 모래는 더해진다
    r5, c5 = ar + dr, ac + dc
    if is_range(r5, c5):
        arr[r5][c5] += sand_5

    # 여기서부터는 양 옆...!
    for side_r, side_c in side:
        r7, c7 = yr + side_r, yc + side_c
        if is_range(r7, c7):
            arr[r7][c7] += sand_7

        r2, c2 = r7 + side_r, c7 + side_c
        if is_range(r2, c2):
            arr[r2][c2] += sand_2

        r10, c10 = r7 + dr, c7 + dc
        if is_range(r10, c10):
            arr[r10][c10] += sand_10

        r1, c1 = r7 - dr, c7 - dc
        if is_range(r1, c1):
            arr[r1][c1] += sand_1

# 이동 풀이
r, c = mid, mid
check = 0 # 방향 전환을 이만큼 하면
turn = 1 # 이 숫자만큼 가면 방향 전환
go = 0 # 현재 몇 칸 만큼 같은 방향으로 갔는지?

for i in range(size*size):

    dr, dc = direction[0]
    nr, nc = r + dr, c + dc
    if is_range(nr, nc):
        sand_blow(r, c)
        r, c = nr, nc

    if go < turn:
        go += 1

    if go == turn:
        go = 0
        direction.rotate(-1)
        check += 1

    if check == 2:
        turn += 1
        check = 0

# 정답
left = 0
for rowrow in arr:
    left += sum(rowrow)

ans = sm - left
print(ans)

```
