algorithm: [시뮬레이션]
data_structure: [3차원 배열]
technique: [배열 회전]

### 걸린 시간: 1트 3시간 (구상 35분, 구현 1시간 5분, 디버깅 1시간 20분) (실패 횟수: 1트 실패)

### 실패 / 성공 이유
- [로직] 옆 면 12칸만 돌림. 돌아가는 면 자체도 회전해야 함
- [변수] 2트: temp 변수 이름 오타
- [디버깅] 인덱스 문제라고 확신하고 시야가 매몰됨. '무조건 맞아야 하는데'가 제일 위험

### 코드 개선 방법
- [디버깅] 면별 출력 대신 전개도로 이어서 출력하면 뒤집힘 없이 보기 쉬움
- [구현] 다음 걸 읽어서 현재에 덮어씌우는 방식으로 옆 면 회전
- [습관] 계속 안 되면 다른 원인/방법을 의심

### 코드
```python
U_idx = [[15, 16, 17], [18, 21, 24], [38, 37, 36], [35, 32, 29]]
Uside_idx = [[0, 1], [2, 5], [8, 7], [6, 3]]

D_idx = [[42, 43, 44], [26, 23, 20], [11, 10, 9], [27, 30, 33]]
Dside_idx = [[45, 46], [47, 50], [53, 52], [51, 48]]

F_idx = [[6, 7, 8], [24, 25, 26], [47, 46, 45], [33, 34, 35]]
Fside_idx = [[36, 37], [38, 41], [44, 43], [42, 39]]

B_idx = [[2, 1, 0], [29, 28, 27], [51, 52, 53], [20, 19, 18]]
Bside_idx = [[17, 16], [15, 12], [9, 10], [11, 14]]

L_idx = [[0, 3, 6], [36, 39, 42], [45, 48, 51], [9, 12, 15]]
Lside_idx = [[29, 32], [35, 34], [33, 30], [27, 28]]

R_idx = [[8, 5, 2], [17, 14, 11], [53, 50, 47], [44, 41, 38]]
Rside_idx = [[24, 21], [18, 19], [20, 23], [26, 25]]

# 돌리는 함수
def solve(cmd, dirr):
    now_idx = []
    now_side_idx = []

    if cmd == "U":
        now_idx = U_idx
        now_side_idx = Uside_idx

    elif cmd == "D":
        now_idx = D_idx
        now_side_idx = Dside_idx

    elif cmd == "F":
        now_idx = F_idx
        now_side_idx = Fside_idx

    elif cmd == "B":
        now_idx = B_idx
        now_side_idx = Bside_idx

    elif cmd == "L":
        now_idx = L_idx
        now_side_idx = Lside_idx

    elif cmd == "R":
        now_idx = R_idx
        now_side_idx = Rside_idx

    nxt_idx = [line[:] for line in now_idx]
    nxt_side_idx = [line[:] for line in now_side_idx]

    if dirr == "+":
        last = nxt_idx.pop()
        nxt_idx.insert(0, last)

        last_side = nxt_side_idx.pop()
        nxt_side_idx.insert(0, last_side)

    else: # dirr == "-"
        first = nxt_idx.pop(0)
        nxt_idx.append(first)

        first_side = nxt_side_idx.pop(0)
        nxt_side_idx.append(first_side)

    temp = []
    for i in range(4):
        for j in range(3):
            nxt_one = nxt_idx[i][j]
            temp.append(cube[nxt_one]) # 다음 걸 읽어서

    for k in range(4):
        for l in range(3):
            now_one = now_idx[k][l]
            idx = (3*k + l)
            cube[now_one] = temp[idx] # 현재에 덮어씌움

    # 윗 면 안에서 도는 애들
    temp2 = []
    for aa, bb in nxt_side_idx:
        temp2.append(cube[aa])
        temp2.append(cube[bb])


    for tpl_idx, tpl in enumerate(now_side_idx):
        dd, ee = tpl
        cube[dd] = temp2[tpl_idx * 2]
        cube[ee] = temp2[tpl_idx * 2 + 1]


# 입력
T = int(input())

for tc in range(1, 1+T):
    mingle_num = int(input())
    commands = input().split()
    cube = ["w"] * 9 + ["o"] * 9 + ["b"] * 9 + ["g"] * 9 + ["r"] * 9 + ["y"] * 9
    # tc마다 큐브 초기화

    # 풀이
    for index in range(mingle_num):
        cmd = commands[index][0]
        dirr = commands[index][1]
        nxt_idx = solve(cmd, dirr)

    ans = cube[:9]
    for i in range(0, 9, 3):
        print("".join(ans[i:i+3]))
```
