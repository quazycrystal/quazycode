### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [DP] 사탕 최대 개수는 직전 단계에만 의존 (최적 부분 구조). 미로가 커서 백트래킹은 어려움

### 코드 개선 방법
- [DP] 그리디는 지금 최선, DP는 이 일이 일어나려면 직전에 어떻게 했어야 했는지

### 코드
```python
row, col = map(int, input().split())
arr = [list(map(int, input().split())) for _ in range(row)]

# 점화식
for r in range(row):
    for c in range(col):
        mx = 0
        for dr, dc in ((-1, 0), (-1, -1), (0, -1)):
            pr, pc = r+dr, c+dc # 이전 좌표들에서 올 수 있는 값
            if 0 <= pr < row and 0 <= pc < col:
                if arr[pr][pc] > mx:
                    mx = arr[pr][pc]

        arr[r][c] = arr[r][c] + mx

print(arr[row-1][col-1])
```
