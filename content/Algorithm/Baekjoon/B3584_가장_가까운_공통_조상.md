### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 깊이가 다르면 A, B가 번갈아 올라오는 게 아니라 한쪽이 계속 올라와야 할 수도. 일단 A를 루트까지 다 올리기

### 코드 개선 방법
- [자료구조] 부모 idx에 자식을 넣는 대신 자식 idx에 부모를 넣기

### 코드
```python
T = int(input())
for tc in range(T):
    nodes = int(input())
    adj = [0] * (nodes + 1)  # 0 안 쓴다

    for _ in range(nodes - 1):
        parent, child = map(int, input().split())
        adj[child] = parent

    A, B = map(int, input().split())

    lstA = []  # 마지막이 루트.,,
    lstB = []

    while A != 0:
        lstA.append(A)
        A = adj[A]  # 한 칸 한 칸...

    while B != 0:
        lstB.append(B)
        B = adj[B]  # 한 칸 한 칸...

    i = 0
    j = 0

    lstA.reverse()
    lstB.reverse()

    ans = 0
    for i in range(min(len(lstA), len(lstB))):
        if lstA[i] == lstB[i]:
            ans = lstA[i]
        else:
            break

    print(ans)

```
