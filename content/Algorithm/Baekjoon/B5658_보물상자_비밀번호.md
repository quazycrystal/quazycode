### 코드 개선 방법
- [문법] 16진수 변환은 int(s, 16)
- [회전] 덱 rotate로 N//4번 돌리며 변마다 잘라 set에 모으기
- [정렬] 내림차순 정렬 후 K번째

### 코드
```python
from collections import deque

# 입력
T = int(input())
for tc in range(1, 1+T):
    n_num, goal = map(int, input().split())
    nums = deque(list(input()))

    able_nums = set()

    # n_num을 4로 나눔
    rotate_num = n_num // 4

    for i in range(rotate_num):
        nums.rotate(1)
        new_nums = list(nums)

        for j in range(0, n_num, rotate_num):
            new_str = ""
            for k in range(j, j+rotate_num):
                new_str += new_nums[k]
            able_nums.add(new_str)

    able = list(able_nums)
    able.sort(reverse=True)
    ans_hex = able[goal-1]
    print(f"#{tc}", int(ans_hex, 16))

```
