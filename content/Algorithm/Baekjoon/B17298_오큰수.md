### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [시간 복잡도] 수열 100만이라 for 2중은 터짐. 1중으로
- [로직] 스택 전체를 훑으면 앞에 큰 수가 있을 때 잘못된 값이 나옴

### 코드 개선 방법
- [스택] 값 대신 index를 넣고 ans는 -1로 미리 채우기
- [스택] 짝을 만났다 / 못 만났다로 생각. 스택에는 아직 큰 수를 못 찾은 것만 남음
- [스택] 내가 누군가를 갱신했더라도 나도 갱신될 수 있으니 나도 넣기

n = int(input())
lst = list(map(int, input().split()))
stk = []
# idx = []

        if lst[0] > lst[1]:  # 두 번째 보다 첫 번째 수가 크면 방해 되니까 빼고 생각

                    stk.append([i, lst[i]])  # 스택에 차곡 차곡 오름차순으로 인덱스 모은다
                if lst[i] > lst[0] and temp == stk[0]:
                    temp = lst[i]  # 첫 수보다 큰 수가 나온게 처음이면 temp 값 바꿔두기

`W4/B17298_오큰수.py`

```python
stk = []
N = int(input())
lst = list(map(int, input().split()))
ans = [-1] * N
for i in range(N):

    while stk and lst[i] > lst[stk[-1]]: # 나보다 큰 수 찾았다!
        idx = stk.pop()
        ans[idx] = lst[i]
    stk.append(i) # 내가 비록 누군가를 갱신했더라도 나도 갱신될 수 있음

print(*ans)

```
