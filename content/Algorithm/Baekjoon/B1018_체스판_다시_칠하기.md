technique: [패딩]

### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [문법] `arr[i:i+8][j:j+8]` 이중 슬라이싱 불가
- [로직] 왼쪽 위가 흰 칸 / 검은 칸 두 경우 중 최소. 64 - w = b
- [누적합] 누적 합 공식이 빠져서 틀림

### 코드 개선 방법
- [누적합] 0 패딩하고 W 시작 패턴과 다른 칸을 누적. 영역 합 = 전체 - 위 - 왼 + 대각 위
- [공간] 8*8 대신 한 줄만 비교하거나 0, 1로 보고 비트 연산

### 코드
```python
row, col = map(int, input().split())
arr = [list(input()) for _ in range(row)]
white = [['W','B','W','B','W','B','W','B'], ['B','W','B','W','B','W','B','W'], ['W','B','W','B','W','B','W','B'], ['B','W','B','W','B','W','B','W'], ['W','B','W','B','W','B','W','B'], ['B','W','B','W','B','W','B','W'], ['W','B','W','B','W','B','W','B'], ['B','W','B','W','B','W','B','W']]
black = [['B','W','B','W','B','W','B','W'], ['W','B','W','B','W','B','W','B'], ['B','W','B','W','B','W','B','W'], ['W','B','W','B','W','B','W','B'], ['B','W','B','W','B','W','B','W'], ['W','B','W','B','W','B','W','B'], ['B','W','B','W','B','W','B','W'], ['W','B','W','B','W','B','W','B']]

ans = []
for i in range(0, row-7):
    for j in range(0, col-7):
        w = 0
        b = 0

        for k in range(i, i+8):
            r = k-i # 들어오는 값에서 초기 값을 빼면 0-8
            for l in range(j, j+8):
                c = l-j
                if white[r][c] != arr[k][l]:
                    w += 1
                if black[r][c] != arr[k][l]:
                    b += 1
                # elif 안됨! 그리고 64-w = b임
        mn = min(w, b) # 답은 for 문 다 끝나고... for 문 때문에...
        ans.append(mn) # ans에는 체스판 만큼 자른게 다 들어있다
print(min(ans))

# 0 패딩
n, m = map(int, input().split()) # m이 행
board = [[0] * (m+1) for _ in range (n+1)] # 받아야 하는 배열보다 가로 세로 한 칸 많이
for i in range(1, n+1):
    line = list(input().rstrip()) # 줄바꿈 문자 엔터 삭제
    board[i] = [0] + line


S = [[0] * (m+1) for _ in range (n+1)] # S[i][j]는 W 시작 패턴과 다른 칸의 누적 갯수
for i in range (1, n+1):
    for j in range(1, m+1): #0 패딩해서
        if (i+j) % 2 == 0: # 짝수 = 색이 같음
            t_clr = 'W' # 타깃 컬러 흰 색
        else:
            t_clr = 'B'
        diff = 1 if board[i][j] != t_clr else 0

        # 누적 합 공식 (이게 빠졌었어요!)
        S[i][j] = S[i - 1][j] + S[i][j - 1] - S[i - 1][j - 1] + diff

# 구간합 탐색
mn_re = 64
# 루프가 층 나뉘어져 있어서 ok
for i in range(8, n+1):
    for j in range (8, m+1):
        w_srt = S[i][j] - S[i-8][j] - S[i][j-8] + S[i-8][j-8]
        mn_re = min(mn_re, w_srt, 64-w_srt) # 64, 왼쪽 위 흰색, 검은색인 경우 중 최소

print(mn_re)

```
