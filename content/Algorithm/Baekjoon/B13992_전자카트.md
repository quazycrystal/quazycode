### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [조건] 순서 중요 (e[2][1] != e[1][2]), 자기 자신 제외
- [재귀] 도착한 곳에서 다시 출발해야 하므로 현 위치도 넘겨야 함
- [종료 조건] 첫 칸을 방문한 셈 치니 깊이 n-1에서도 돌아야 함. 마지막에 1로 돌아오는 비용 추가

### 코드 개선 방법
- [재귀] 넘길 것: 깊이, cost 합, 현 위치
- [습관] 불친절한 문제는 테케 보고 감 잡기

### 코드
```python
def btk(n, cur, sm):
    global ans
    if ans <= sm:
        return

    if n == N:
        ans = min(ans, sm + arr[cur][0]) # 마지막에 추가
        return

    for nxt in range(1, N): # 여기도 맨 앞 0 방문한 셈 치고 뒤부터
        # 1에서 출발해 1로 돌아와야 하므로 맨 뒷 col은 무조건 1이어야
        if v[nxt] == 0:
            v[nxt] = 1
            btk(n+1, nxt, sm + arr[cur][nxt]) #
            v[nxt] = 0

T = int(input())
for tc in range(1, 1+T):
    N = int(input())
    arr = [list(map(int, input().split())) for _ in range(N)]
    v = [0] * N
    ans = 100 * N # 100 이하의 자연수

    btk(1, 0, 0) # 맨 앞인 0 이미 방문한 셈 치고 1부터 (깊이 -1)
    print(f"#{tc}",ans)
```
