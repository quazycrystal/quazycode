### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [정렬] 끝나는 시간이 같으면 시작이 이른 것부터 봐야 둘 다 세어짐. (4,4)가 먼저 세어지면 1~3 시작 회의가 빠짐
- [시간] 이미 들어 있는지 not in으로 확인하면 시간 초과

### 코드 개선 방법
- [그리디] 마지막 회의의 끝 시간만 저장. 끝남과 동시 시작 가능이라 등호
- [정렬] 시작 기준 sort 후 끝 기준 sort

### 코드
```python
N = int(input())
lst = []
for _ in range(N):
    s, e = map(int, input().split())
    lst.append((s, e))

lst.sort() # x[0] 기준 한 번 더 sort
lst.sort(key = lambda x: x[1]) # 끝나는 시간 기준 sort


end = -1 # 초기값 일단 작게!!
ans = 0
for time in lst:
    s, e = time[0], time[1]
    if s >= end: # 끝남과 동시 시작 가능이므로 등호
        ans += 1
        end = e

print(ans)
```
