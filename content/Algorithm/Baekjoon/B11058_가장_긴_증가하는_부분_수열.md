### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [문제 읽기] 부분 수열은 원래 순서 유지. 같은 값이 증가인지 명시 안 됨

### 코드 개선 방법
- [로직] 뒤에서부터 보며 나를 포함/미포함

### 코드
```python
N = int(input())
lst = list(map(int, input().split()))
lst.reverse() # 뒤에서부터 보기
dp = [0] * (N+1)
length = 1 # 맨 첫 원소는 넣고 시작
ans = []
mx = 0 # 1부터 주어지고, 현 증가하는 수열의 가장 끝 값

for i in range(1, N):
    # 나를 포함 또는 미포함, 뒤에 다 나보다 작으면 나를 넣으면 안 됨
    if lst[i] < lst[i-1]: # 점점 인덱스 커질수록 원본 수열의 앞으로 감
        length += 1
        if length > mx:
            mx = length

    else:
        length = 1

print(mx)
```
