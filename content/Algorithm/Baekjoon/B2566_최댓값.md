### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [인덱스] 1차원으로 넣어 나누면 나머지 9일 때 몫이 바뀌어 복잡함. 2차원으로 받기
- [엣지 케이스] 모든 값이 0이면 row, col이 갱신되지 않음

### 코드 개선 방법
- 

### 코드
```python
# 2차원 리스트로 값 받기
lst = [list(map(int, input().split())) for _ in range (9)]
mx = 0
row = 0
col = 0
for i in range (9):
    for j in range (9):
        if lst[i][j] >= mx: #모든 arr가 0일때는 row, col이 들어오지 않음
            mx = lst[i][j]
            row = i+1
            col = j+1 #idx 보정
print(mx)
print(row, col)
```
