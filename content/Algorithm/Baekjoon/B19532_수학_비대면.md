### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [범위] 답이 -999 ~ 999라고 강조했으면 그 범위로 완전탐색
- [로직] 이차 방정식처럼 풀면 지저분하고 범위 조건 넣기 까다로움. zero division 주의

### 코드 개선 방법
- [문법] x, y = None, None으로 값 없이 선언 가능, 값 넣기 전 연산 불가

### 코드
```python
# 연립방정식
a, b, c, d, e, f = map(int, input().split())

for x in range(-999, 1000):
    for y in range(-999, 1000):
        if a*x + b*y == c and d*x + e*y == f:
            print(x, y) # int 쓸 필요도 없고
```
