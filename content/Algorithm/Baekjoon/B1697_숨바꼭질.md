### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [조건] 줄어드는 동작도 있고 1씩 움직이므로 답이 없는 경우가 없음

### 코드 개선 방법
- [구현] 정답 체크는 nxt가 아니라 cur 꺼낸 직후에

### 코드
```python
# 숨바꼭질
def bfs(s, e):
    global ans
    v = {s:0}
    q = []
    q.append(s)
    while q:
        cur = q.pop(0)
        # 정답은 cur 선언 직후! nxt 말고 cur 보는게 좋다
        if cur == e:
            ans = v[cur]

        n1 = cur-1
        n2 = cur+1
        n3 = cur*2
        # 범위, 조건, 방문, q
        if n1 not in v:
            if 0 <= n1 <= 100000:
                q.append(n1)
                v[n1] = v[cur] + 1

        if n2 not in v:
            if 0 <= n2 <= 100000:
                q.append(n2)
                v[n2] = v[cur] + 1

        if n3 not in v:
            if 0 <= n3 <= 100000:
                q.append(n3)
                v[n3] = v[cur] + 1

ans = 0
srt, end = map(int, input().split())
bfs(srt, end)
print(ans)
```
