### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [거리] sm += 1로 세면 같은 레벨 노드를 개별로 셈
- [방문 처리] 0, 1로 방문을 표시하면 거리와 섞임

### 코드 개선 방법
- [거리] v를 -1로 시작하고 거리를 바로 저장 (시작은 0)

### 코드
```python
def bfs(s, e):
    global ans
    v[s] = 0
    q = []
    q.append(s)
    while q:
        cur = q.pop(0)
        for nxt in adj[cur]:
            # 범위 내, 미방문, 조건
            if v[nxt] == -1: # 초기화가 -1
                v[nxt] = v[cur] + 1 # 스스로는 거리가 0이고
                # 깊이는 같은데 위치는 다른 곳 셀 때 들어오게 된 현 위치를 참고
                q.append(nxt)
                if nxt == e:
                    ans = v[nxt]
                    return
    if ans == 0:
        ans = -1

ans = 0
node = int(input())
srt, end = map(int, input().split())
edge = int(input())
adj = [[] for _ in range(node+1)]
v = [-1] * (node+1) # v에다가 얼마만큼 멀리 왔는지 바로 저장할거니까
for _ in range(edge):
    t = list(map(int, input().split()))
    adj[t[0]].append(t[1])
    adj[t[1]].append(t[0]) # 촌수는 서로간 양방향
    # 각 사람의 부모는 최대 한 명: 하나씩만 연결..

bfs(srt, end)
print(ans)
```
