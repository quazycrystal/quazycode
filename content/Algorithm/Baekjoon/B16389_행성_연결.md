### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [문제 읽기] '모든 행성 연결 시 최소 비용'은 다익스트라가 아니라 유니온 파인드

### 코드 개선 방법
- [속도] 힙큐 대신 sort, 윗 대각선(row+1부터)만 받아서 중복 제거 (4092 → 1528ms)
- [유니온] union 후에 매번 find 안 해도 됨

### 코드
```python
# from heapq import *

# 입력
nodes = int(input())
arr = [list(map(int, input().split())) for _ in range(nodes)]
adj = [0] * nodes
q = []
for row in range(nodes):
    for col in range(row+1, nodes): # row + 1 해야 중복 방지임
        w = arr[row][col]
        s = row
        e = col
        # heappush(hq, (w, s, e))
        q.append((w, s, e))

# 유니온 파인드
p = [x for x in range(nodes)]


def find(x):
    if p[x] != x:  # 부모 값이랑 자식값이 다르면: 루트가 아니면
        p[x] = find(p[x])  # 루트 값을 찾아서 그 값을 내 부모로
    return p[x]


def union(a, b):
    root_a = find(a)
    root_b = find(b)
    if root_a != root_b:  # 부모끼리 다르면
        p[root_a] = root_b  # 부모가 다른 그룹의 루트가 됨
        return True
    else:
        return False


# 유니온 파인드로 하나의 큰 그룹 만들기
ans = 0
cnt = 0
q.sort(reverse=True)
while q:
    weight, start, end = q.pop()
    # union 후에 find를 매번 해야 하나? - 논노
    if union(start, end):
        cnt += 1
        ans += weight

    if cnt == nodes - 1:
        break

print(ans)
```
