### 코드 개선 방법
- [문법] a, b = b, a처럼 콤마로 서로 값을 바꿈

### 코드
```python
basket_num, change_num = map(int, input().split())
basket = []

for i in range(basket_num):
    basket.append(i+1)

for j in range(change_num):
    ball1, ball2 = map(int, input().split())
    basket[ball1-1], basket[ball2-1] = basket[ball2-1], basket[ball1-1]
    # 전치행렬처럼, 콤마로 찍고 서로간 값을 바꿈
print(*basket)
```
