### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [참조] 전역 리스트에 계산 중인 리스트를 append하면 함수 종료 후 pop되어 빈 리스트만 남음. 리스트는 주소
- [문제 읽기] A[0]-A[1], A[1]-A[2]... 연속 차이의 합

### 코드 개선 방법
- [재귀] 함수 안에서 직접 계산하고 값만 추가

### 코드
```python
def dif(n, l): # n은 깊이!!!
    global mx
    if n == N: # 여기는 함수 마지막이니까 무한 반복 아님, 종료 조건
        sm = 0
        for i in range(1, N):
            sm += abs(l[i-1] - l[i])

        if sm > mx:
            mx = sm

        return

    for col in range(N):
        if v[col] == 0:
            v[col] = 1
            l.append(A[col])
            dif(n+1, l)
            l.pop()
            v[col] = 0

N = int(input())
A = list(map(int, input().split()))
v = [0] * N

mx = 0
```
