### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [초기화] 곱이라 음수일 때 mx = 0으로 두고 갱신하면 안 됨
- [조건] 열은 1부터, 같으면 큰 열

### 코드 개선 방법
- [문법] 리스트에서 max가 같으면 뒤의 idx가 큰 게 추출되게

### 코드
```python
T = int(input())
for tc in range(T):
    col, row = map(int, input().split())
    # 열은 1부터 시작, 같으면 가장 큰 곱
    arr = [list(map(int, input().split())) for _ in range(row)]
    t_arr = list(zip(*arr))

    mx = []

    for c in range(len(t_arr)):
        idx = c+1 #
        mul = 1  # 곱하기이므로...
        for i in t_arr[c]:
            mul *= i
        mx.append((mul, idx)) #음수일 때 그냥 mx = 0 해두고 갱신하면 안됨!!!!!!!!!

    ans = max(mx)
    print(ans[1])
```
