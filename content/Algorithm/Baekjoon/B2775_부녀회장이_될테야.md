### 실패 / 성공 이유

### 코드 개선 방법
- 

### 코드
```python
# https://www.acmicpc.net/problem/2775
t = int(input())
for tc in range (t):
    lv = int(input()) #층
    ho = int(input()) #호
    ho_sm = 0
    ans = 0
    ho_lst = [[] * ho for _ in range(lv+1)]
    for i in range (lv+1): # 0층부터 있음
        ho_sm = 0
        for j in range (ho): # 1호부터 있음
            if i == 0:
                ho_sm += 1
                ho_lst[0].append(ho_sm)
            else:
                ho_sm += ho_lst[i-1][j]
                ho_lst[i].append(ho_sm)

    ans = ho_lst[i][j]
    print(ans)
```
