### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 한 번 돌리면 [2, 3, 4, 1, 5]처럼 작은 수가 앞으로 못 옴

### 코드 개선 방법
- [로직] 작으면 앞이랑 계속 비교하기

### 코드
```python
n = int(input())
lst = [int(input()) for _ in range(n)]
for i in range(n-1):
    # 가장 작은 값을 앞에 세우고 시작 해야 할 것 같은데?
    for j in range(i+1, n):
        while lst[i] > lst[j]:
            lst[i], lst[j] = lst[j], lst[i]
for k in lst:
    print(k)
```
