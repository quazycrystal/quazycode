### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 하나 추가될 때마다 이전 묶음이 다시 더해짐. ans*2 + n이 아님
- [출력] 출력 초과는 너무 큰 수를 출력할 때도 발생

### 코드 개선 방법
- [힙] 다 넣은 뒤 가장 작은 두 묶음을 합치고 다시 힙에 넣기

### 코드
```python
import heapq
hq = []
sm_hq = []
N = int(input())
ans = 0

for _ in range(N):
    cards = int(input())
    heapq.heappush(hq, cards) # 리스트 먼저 쓰고, item 쓰고

for i in range(N):
    while len(hq) > 1:
        card1 = heapq.heappop(hq)
        card2 = heapq.heappop(hq)
        sm = card1 + card2
        ans += sm
        heapq.heappush(hq, sm)

print(ans)
```
