data_structure: [2차원 배열, 덱]
technique: [배열 회전, 상대 좌표, 슬라이싱]

### 걸린 시간: 2시간 15분 (구상 9분, 구현 2시간 6분) + 추가 약 1시간 (실패 횟수: -)

### 실패 / 성공 이유
- [좌표] 부분 회전에서 안쪽 k, l까지 절대 좌표로 잡아 상대 좌표 구하기가 꼬임 (1시간 10분 소모)
- [인덱스] for 안에서 arr[k][l] = arr2[l][k]처럼 행열을 바꾸면 읽는 순서가 다름
- [동시 갱신] 얼음은 동시에 녹음. 순차로 줄이면 다음 칸 판정에 영향

### 코드 개선 방법
- [상대 좌표] 안쪽 for는 상대 좌표로 돌고 시작점만 더하기
- [배열 회전] 시계 90도 = 열을 거꾸로 읽어 행으로. 슬라이싱 + zip 가능
- [동시 갱신] 녹일 칸을 먼저 모아두고 한꺼번에 처리
- [문제 읽기] 하나의 단계로 묘사되면 동시에 일어나야 함

### 코드
```python
# B20058 마법사 상어와 파이어스톰
from collections import deque

# 추가 시간 1시간 정도 (뒷 bfs 구현 + "동시에" 이슈)

# 디버깅도 못 해보고 시간 끝

# 시간 4O(NM^2)라고 생각 = Q * N**4

# 입력
N, cmd_num = map(int, input().split())
size = 2 ** N  # 한 변의 길이! N은 지수
arr = [list(map(int, input().split())) for _ in range(size)]
lv_lst = list(map(int, input().split()))


# 함수 설계 - 90도 회전 함수
def rotate_90(arr, lv):
    level = 2 ** lv
    row, col = size, size
    new_arr = [[0] * col for _ in range(row)]
    # arr = list(zip(*arr))

    for i in range(0, row, level):
        for j in range(0, col, level):
            # 시작점 잡아줘요
            for k in range(i, i + level):
                for l in range(j, j + level):  # 열 거꾸로 읽음

                    new_col = level + (2 * j) - 1
                    # 행 열을 바꿔 읽을 땐 다시 상대 좌표 구해서,,,
                    rel_k = k - i
                    rel_l = l - j  # 이거 알아내는데 너무 오래 걸렸다
                    new_arr[k][new_col - l] = arr[i + rel_l][j + rel_k]
                    # ㅠㅠㅠ

    return new_arr


for lv in lv_lst:
    new = rotate_90(arr, lv)
    arr = new

    # 상태 판정 배열...
    have_to_melt = []
    for row in range(size):
        for col in range(size):

            cnt = 0
            for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
                nr, nc = row + dr, col + dc
                if 0 <= nr < size and 0 <= nc < size:
                    if arr[nr][nc] > 0:
                        cnt += 1  # 얼음이 있을 때만 추가인디...

            if cnt < 3:
                if arr[row][col] > 0:
                    have_to_melt.append((row, col))  # 얼음 녹여야 할 거 미리 빼두고 나중에 한꺼번에 처리

    for r, c in have_to_melt:
        arr[r][c] -= 1

# 여긴 final arr
ans_sm = 0
for rr in arr:
    ans_sm += sum(rr)


def bfs(sr, sc):
    v[sr][sc] = 1
    q = deque()
    q.append((sr, sc))
    cnt = 1  # 스스로부터 시작
    while q:
        r, c = q.popleft()
        for dr, dc in ((0, -1), (0, 1), (-1, 0), (1, 0)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < size and 0 <= nc < size:
                if arr[nr][nc] > 0 and v[nr][nc] == 0:
                    v[nr][nc] = 1
                    q.append((nr, nc))
                    cnt += 1
    return cnt


# bfs
v = [[0] * size for _ in range(size)]
max_chunk = 0
for i in range(size):
    for j in range(size):
        if arr[i][j] > 0 and v[i][j] == 0:
            chunk = bfs(i, j)
            if chunk > 1:  # 하나만 포함이면 덩어리가 아니다
                max_chunk = max(max_chunk, chunk)

print(ans_sm)
print(max_chunk)

```
