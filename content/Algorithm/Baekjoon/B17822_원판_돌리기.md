---
algorithm: [시뮬레이션]
data_structure: [2차원 배열, 덱]
technique: [델타 탐색]
---

### 걸린 시간: 2시간 20분 (구상 20분, 구현 1시간, 2차 구현 20분, 디버깅 30분) (실패 횟수: -)

### 실패 / 성공 이유
- [문제 읽기] 원판 안의 수뿐 아니라 원판끼리도 인접함을 놓쳐 dict를 고름 → 2차원 배열로 갈아엎음
- [나눗셈] 수가 모두 0이 되면 예외 분기를 지나 else로 들어가 ZeroDivision

### 코드 개선 방법
- [자료구조] 원판 i, 위치 j는 2차원 배열. 회전은 rotate 또는 인덱스
- [델타 탐색] 4방 탐색 기본, 열만 % 처리, 행은 범위 제한
- [동시 갱신] 같은 수를 다 찾은 뒤 일괄 삭제
- [나눗셈] 0 아닌 개수로 나누기 전에 0인지 확인. int와 float 비교는 가능

### 코드
```python
# 2시간 20분 솔

# 시간 복잡도: 4*O(N)

def rotation(x, d, s):
    for i in range(disk_num):
        if (i + 1) % x == 0:
            new = disks[i]
            for _ in range(s):
                if d == 0:
                    last = new.pop()
                    new.insert(0, last)
                elif d == 1:
                    first = new.pop(0)
                    new.append(first)

            disks[i] = new  # dict 갱신


# 2. 인접 하면서 수가 같은 걸 모두 지운다, 모든 원판!!
def find_del():  # 여기서 완탐 느낌으로...
    same_lst = set()

    # 그냥 4방 탐색 하고, 열 처리만 다르게 해도 되겠다, 리팩토링 가능

    for i in range(disk_num):  # 디스크 번호
        for idx in range(on_disk):  # 원판에 숫자가 몇 개인지
            # 양 끝은 특수하게 봐야
            value = disks[i][idx]
            if value == 0:
                continue
            left = idx - 1
            right = idx + 1
            flag = 0
            if 0 <= left < on_disk and 0 <= right < on_disk:
                pass
            elif left < 0:
                left = (on_disk - 1)
            elif right >= on_disk:
                right = 0
            # === 값 맞추기 ===
            if disks[i][left] == value:
                same_lst.add((i, left))
                flag = 1

            if disks[i][right] == value:
                same_lst.add((i, right))
                flag = 1

            down, up = (i + 1), (i - 1)

            if down < disk_num:
                if disks[down][idx] == value:
                    same_lst.add((down, idx))
                    flag = 1

            if 0 <= up:
                if disks[up][idx] == value:
                    same_lst.add((up, idx))
                    flag = 1

            if flag:
                same_lst.add((i, idx))

    # 다 돌고 수 같은 것이 있다면 일괄 처리
    if same_lst:
        for row, col in same_lst:  # 값이 같았던 애들 일괄 지운다
            disks[row][col] = 0


    # 수 같은 것이 없으면 다시 판끼리 돌기
    else:
        sm = 0
        lenn = 0
        for row in range(disk_num):
            for col in range(on_disk):
                if disks[row][col] != 0:
                    sm += disks[row][col]
                    lenn += 1

        if sm == 0:
            aver = 0
        else:
            aver = sm / lenn  # 주의! 0 아닌 수로 해야!

        for r in range(disk_num):
            for c in range(on_disk):
                if disks[r][c] != 0:  # 일단 0인 건 지운것이므로...

                    if disks[r][c] < aver:
                        disks[r][c] += 1
                    elif disks[r][c] > aver:
                        disks[r][c] -= 1


# 입력
disk_num, on_disk, cmd_num = map(int, input().split())
disks = []
commands = []
for idx in range(disk_num):
    disks.append(list(map(int, input().split())))  # 인덱스 1부터 시작함에 주의

for _ in range(cmd_num):
    commands.append(tuple(map(int, input().split())))

for x, d, s in commands:
    rotation(x, d, s)
    find_del()

ans = 0
for dd in disks:
    ans += sum(dd)

print(ans)

```
