### 걸린 시간: 1시간 반 + 16분 디버깅 (구상 7분, 구현 26분, 2차 구현 33분, 디버깅 14분) (실패 횟수: -)

### 실패 / 성공 이유
- [제어 흐름] while에서 time이 한 번 더 증가. time이 언제 더해지는지(함수 전/후) 안 봄
- [제어 흐름] 마지막 방향 전환 후 이동 없이 끝남. 마지막에도 이동이 한 번 더 있어야 함
- [순서] 사과 O / 사과 X / 죽음 분기를 다 거친 뒤 arr에 표시해야 하는데 일부 분기에서 먼저 표시
- [구상] 몸통이 꺾일 때 나머지 몸이 어떻게 되는지 확신 없이 시작 (구상 7분)

### 코드 개선 방법
- [시각화] 머리 append, 꼬리 pop. q를 찍어보면 몸통 좌표까지 보여 디버깅도 쉬움
- [제어 흐름] 시간 상한(10100)까지 for로 흘리고 해당 인덱스에 방향 전환 커맨드를 두면 맞는 시간에 자연히 회전
- [디버깅] 의심 지점에서 인자(time)와 arr를 함께 출력. 2차원이면 arr부터 찍기
- [습관] 손 드라이는 '완벽히'. 쉬워 보일수록 꼼꼼히, 1 더하고 빼보는 식으로 고치지 않기

### 코드
```python
# 5분 남은 이 시점에서 while문 문제인 게 확실해 졌으나...

from collections import deque
d = deque([(0, 1), (1, 0), (0, -1), (-1, 0)])
# 시계 방향 우 하 좌 상

def snake(sr, sc):
    global die, s_r, s_c, temp
    # 현재 보고 있는 방향
    dr, dc = d[0]
    nr, nc = sr + dr, sc + dc # 맨 앞 칸만!

    if 0 <= nr < size and 0 <= nc < size:
        if arr[nr][nc] == 1:
            die = 1 # 스스로 부딪히면

        else:
            if arr[nr][nc] == 0:
                fr, fc = temp.popleft()  # 꼬리칸 빼기
                arr[fr][fc] = 0

            temp.append((nr, nc))
            arr[nr][nc] = 1 # 맨 나중에 바꿔야

            # 다음 좌표 초기화
            s_r, s_c = nr, nc

    else:
        die = 1 # 칸 밖으로 나가면 죽음

# 입력
size = int(input())
arr = [[0] * size for _ in range(size)]

# 뱀 표시 = 1
arr[0][0] = 1

# 사과 표시 = 2
apple_cnt = int(input())
for _ in range(apple_cnt):
    r, c = map(int, input().split())
    arr[r-1][c-1] = 2  # 1행 1열

# 명령 입력
cmd_cnt = int(input())
commands = deque()
for _ in range(cmd_cnt):
    time, direction = input().split()
    # D가 시계, L이 반시계
    if direction == "D":
        direction = -1 # rotate 함수 방향
    else:
        direction = 1
    commands.append((int(time), direction))
# commands.append((10 ** 9 + 1, 1))

# 죽는 플래그
die = 0
s_r, s_c = 0, 0
temp = deque([(0, 0)])

# 풀이
time = 0 # 들어가는 순간 1
turn_time, dirr = 0

while True:
    time += 1
    if commands and time > commands[0][0]: # 시간 4 됐을 때 돌림
        turn_time, dirr = commands.popleft()
        d.rotate(dirr)

    snake(s_r, s_c)
    #   time += 1
    if die == 1: # false 반환 시
        break


print(time)

```
