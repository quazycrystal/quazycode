### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [변수 범위] 함수 안에 없는 변수는 전역을 읽을 수 있지만, 바꾸려고 하면 같은 이름의 새 변수가 되어 동작 안 함
- [로직] 5개 이상이면 찾자마자 break, '정확히' 5개면 다음 칸에 돌이 없어야 함
- [범위] idx 에러 안 나게 범위 제한

### 코드 개선 방법
- [델타] 8방향 대신 4방향(세로, 가로, 대각선, 역대각선) + 반대는 -dx, -dy
- [변수] 함수 안과 밖 변수 이름을 다르게

### 코드
```python
# 답: https://alcoding.tistory.com/51

def cont(board, N): # 안전히 입력 하나 더 받기
    dy = [0, 1, 1, -1]
    dx = [1, 0, 1, 1] # 세로, 가로, 대각선, 역 대각선

    for i in range (N):
        for j in range (N):
            if (board[i][j] == 'o'): #돌 있다
                for k in range(4):
                    x = i
                    y = j
                    cnt = 0
                    while(x < N) and (0<= y <N) and (board[x][y] =='o'):
                        x += dx[k]
                        y += dy[k] # 한 쪽으로 계속
                        cnt += 1
                        if(cnt == 5):
                            return 'YES'
    return 'NO' # 함수에서는 else 안 써도 알아서 걸러짐

T = int(input())
for test_case in range(1, T+1):
    n = int(input())
    arr = [list(input()) for _ in range(n)]
    ans = cont(arr, n) # 헷갈리지 않게 함수 안과 밖 변수 이름도 다르게

    print(f'#{test_case} {ans}')
```
