### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [문법] 음수에 //를 쓰면 몫이 하나 작아짐. 양수로 바꿔 나눈 뒤 부호

### 코드 개선 방법
- [재귀] 첫 값을 nums[0]으로 넣고 연산자 개수만큼 깊이

### 코드
```python
def btk(n, sm):
    if n == N-1: # 연산은 연산자의 갯수만큼
        ans.append(sm)
        return
    for idx in range(N-1):
        if v[idx] == 0:
            v[idx] = 1
            op = opr[idx]

            if op == "+":
                btk(n+1, sm + nums[n+1])
            elif op == "-":
                btk(n + 1, sm - nums[n + 1])
            elif op == "*":
                btk(n + 1, sm * nums[n + 1])
            else: # op == "//":
                if sm >= 0: # 양수
                    btk(n + 1, sm // nums[n + 1])
                else: # 음수
                    btk(n + 1, -(abs(sm) // nums[n + 1]))

            v[idx] = 0

# 입력
N = int(input())
nums = list(map(int, input().split()))
a, b, c, d = map(int, input().split())
opr = ["+"] * a + ["-"] * b + ["*"] * c + ["//"] * d
v = [0] * (N-1)
ans = []

# 첫 값을 nums[0] 넣어주기
btk(0, nums[0])
print(max(ans))
print(min(ans))
```
