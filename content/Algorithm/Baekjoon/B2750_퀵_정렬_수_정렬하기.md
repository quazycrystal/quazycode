### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [피벗] 피벗을 자꾸 넘기지 말고 고정. 같은 값, 빈 left도 존재

### 코드 개선 방법
- [재귀] return quick(left) + [pivot] + quick(right)로 돌아오면서 합치기
- [메모리] 리스트 더하기는 복사본이라 안전하지만 메모리 많이 씀

### 코드
```python
def quick(lst):
    if len(lst) <= 1:  # 없거나 하나면
        return lst

    pivot = lst[0]
    left = []
    right = []
    for i in range(len(lst)):
        if lst[i] > pivot:
            right.append(lst[i])
        elif lst[i] < pivot:
            left.append(lst[i])

    # 그냥 피벗을 left right 사이에 끼면 됨!
    return quick(left) + [pivot] + quick(right)

# 입력
N = int(input())
origin = [int(input()) for _ in range(N)]
# ans = [0] * N -> 이게 인덱스 작업?

for i in quick(origin):
    print(i)

```
