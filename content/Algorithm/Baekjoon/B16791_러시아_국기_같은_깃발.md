### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [조건] 첫 줄 흰색, 끝 줄 빨간색 고정, 색마다 최소 한 줄

### 코드 개선 방법
- [전처리] 각 행에 색깔이 몇 개씩인지 먼저 세기

### 코드
```python
T = int(input())
for tc in range(1, 1 + T):
    row, col = map(int, input().split())
    arr = [list(input()) for _ in range(row)]
    color_map = []
    mn_ans = []
    # 브루트포스

    # 일단 각 행에 색깔이 몇 개씩 들어있는지 파악
    for i in range(row):
        white = arr[i].count("W") # 흰: 0
        blue = arr[i].count("B") # 파: 1
        red = arr[i].count("R") # 빨: 2
        temp = [white, blue, red]
        color_map.append(temp)

    ans = 0

    # 브루트 포스
    for w_line in range(1, row-1):
        for b_line in range(w_line+1, row): # 최소 한 줄 보장
            for r_line in range(b_line, row):

                ans = 0
                whites = color_map[1: w_line]
                blues = color_map[w_line: b_line]
                reds = color_map[b_line:row-1]

                for w in whites:
                    ans += (sum(w) - w[0])
                for b in blues:
                    ans += (sum(b) - b[1])
                for r in reds:
                    ans += (sum(r) - r[2])

                # 첫 줄 흰색 끝 줄 빨간색 고정
                ans += color_map[0][1] + color_map[0][2]
                ans += color_map[row - 1][0] + color_map[row - 1][1]

                mn_ans.append(ans)

    print(f"#{tc}", min(mn_ans))

```
