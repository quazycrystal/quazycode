### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [시간 복잡도] N, M 20000 이상인데 마음이 급해서 그냥 2중으로 감

### 코드 개선 방법
- [가지치기] sort 후 넘는 순간 멈추기

### 코드
```python
T = int(input())
for tc in range(T):
    A, B = map(int, input().split())
    lstA = list(map(int, input().split()))
    lstB = list(map(int, input().split()))

    lstA.sort(reverse= True)
    lstB.sort()

    ans = 0

    # N, M 20000 이상... 마음이 너무 급했다

    i = 0
    j = 0

    for i in range(A):
        for j in range(B):
            if lstA[i] > lstB[j]:
                ans += 1
            else:
                break
    # sort로 가지치기...?

    print(ans)
```
