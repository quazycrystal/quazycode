### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [조건] 가진 동전 수가 정해져 있고, 금액이 정확히 맞아야 함

### 코드 개선 방법
- [발상 전환] (가진 총 금액 - 목표 금액)을 최소 동전으로 맞추면, 남은 동전이 최대 개수

### 코드
```python
goal = int(input())
have_coin = list(map(int, input().split()))
coin = [500, 100, 50, 10, 5, 1]

# 내가 가진 금액
my_money = 0
for i in range(6):
    my_money += have_coin[i] * coin[i]

new_goal = (my_money - goal)

# 최솟값 구하기
def mini(g):
    for num in range(6):
        while g >= coin[num] and have_coin[num] > 0:
            g -= coin[num]
            have_coin[num] -= 1

mini(new_goal)
print(sum(have_coin))
print(*have_coin)

```
