조건 분기나 반복 계산 대신, 답을 미리 표(리스트·dict)로 만들어 두고 꺼내 쓰기

```mermaid
flowchart LR
    A["입력: (구조물 2, 방향 상)"] --> T["테이블 조회"] --> B["갈 수 있음 / 없음"]
```
if문 여러 개 대신 표 한 번 조회

### 원리
- 검색 대신 조회: 매번 찾는 대신 루프 밖에서 표를 한 번 만들고 루프 안에서는 O(1)로 꺼내기 ([[S4864_문자열_비교]])
- 분기 대신 매핑: 경우마다 if를 쓰는 대신 경우 → 결과를 표로 ([[S1953_탈주범_검거]])
```python
# 상 하 좌 우
value = {(-1, 0): [1, 2, 5, 6],
         (1, 0): [1, 2, 4, 7],
         (0, -1): [1, 3, 4, 5],
         (0, 1): [1, 3, 6, 7]}
```
- 미리 계산한 값을 재사용: 거리·시간처럼 여러 번 쓰는 값은 한 번 계산해 테이블로 ([[B28215_대피소]], [[B15686_치킨배달]])

### 활용
- 방향·회전·반대 방향 표 ([[방향_관리]], [[B17837_새로운_게임2]])
- 블록·구조물에 들어온 방향 → 나가는 방향 ([[S5650_핀볼_게임]], [[S1953_탈주범_검거]])
- 승패·짝 규칙: 가위바위보, 괄호 짝, 마주 보는 주사위 면 ([[S13845_토너먼트_카드_게임]], [[S4866_괄호검사]], [[B2116_주사위_쌓기]])
- 방향별로 퍼지는 칸·비율 ([[B20057_마법사_상어와_토네이도]], [[B23289_온풍기_안녕]])
- 경로 전체를 표로: 달팽이 벡터 ([[C_술래잡기]], [[달팽이]])
- bfs로 거리 표를 만들고 그걸 보며 이동 ([[C_코드트리_빵]], [[C_메이즈러너]]). 도착 시간이 표보다 크면 못 감 ([[C_미지의_공간_탈출]])
- 그룹 번호·크기 표를 만든 뒤 쌍 계산 ([[C_예술성]])
- 회전된 판 4가지를 미리 만들어 두기 ([[B16985_Maaaaaaaaaze]])
- 열·대각선 사용 여부를 배열로 (N-Queen) ([[B9663_NQUEEN]])
- CCTV별 방향 조합을 하드코딩 ([[B15683_감시]])

### 주의
- 표를 손으로 만들면 오타가 숨어 있음. 몇 개 찍어서 그림과 대조 ([[B23289_온풍기_안녕]])
- 인덱스로 만든 표는 번호 시작(0/1)을 맞추기 ([[B17837_새로운_게임2]])
- 하드코딩이 길어지면 규칙이 있는지 먼저 보기. 방향 순서를 (0, 3, 1, 2)처럼 두면 3에서 빼서 반대 방향이 나옴 ([[S1953_탈주범_검거]])
