### 걸린 시간: 2시간 11분 (구상 17분, 구현·검증 1시간 12분, 디버깅 42분) (실패 횟수: -)

### 실패 / 성공 이유
- [쓰레기 값] 소멸한 원자 처리와 루프 범위에서 이슈
- [동시 갱신] 방문 배열을 따로 안 만들면 3개가 한 번에 만나는 경우를 못 잡음
- [좌표] 0.5초에 만나는 경우가 있고, 위쪽이 y 증가

### 코드 개선 방법
- [좌표] 좌표를 2배로 늘려 0.5 단위를 정수로
- [범위] 루프는 4000번. -2000~2000을 넘어가면 다시 만날 수 없으니 제거
- [동시 갱신] 이번 턴 위치를 dict에 모으고 2개 이상인 칸은 한 번에 소멸

### 코드
```python
# S5648 원자 소멸 시뮬레이션

direction = {0: (1, 0), # 상하좌우
             1: (-1, 0),
             2: (0, -1),
             3: (0, 1)}

def move():
    global ans
    stop = 0
    new_info = {}

    info_check = set()
    for y, x in a_info:
        d = a_info[(y, x)][0]
        dy, dx = direction[d]
        ny, nx = y + dy, x + dx

        if -2000 <= nx <= 2000 and -2000 <= ny <= 2000: # 나가면 어차피 못 온다

            if (ny, nx) not in info_check:
                new_info[(ny, nx)] = a_info[(y, x)]
                info_check.add((ny, nx))

            else:
                my_power = a_info[(y, x)][1]  # 옛 정보
                ans += my_power

                if (ny, nx) in new_info:
                    your_power = new_info[(ny, nx)][1]  # 이미 갱신된 정보
                    ans += your_power
                    new_info.pop((ny, nx))

    if not new_info:
        stop = 1

    return new_info, stop

# 입력
T = int(input())
for tc in range(1, 1 + T):
    a_num = int(input())
    a_info = {}

    for _ in range(a_num):
        x, y, d, k = map(int, input().split())  # 좌표 개념임에 주의
        a_info[(2*y, 2*x)] = [d, k] # 2배로?


    # 풀이
    ans = 0
    times = 0
    while times < 4010:
        times += 1
        a_info, stop = move()
        if stop:
            break
    print(f"#{tc}", ans)
```
