### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [문제 읽기] 상하좌우 중 하나라도 없으면 판단 불가. 높으면 = 초과
- [조건] 활화산이 1개 또는 0개면 -1

### 코드 개선 방법
- [범위] 가장자리를 잘라내면 범위 처리 불필요

### 코드
```python
T = int(input())
for tc in range(1, 1+T):
    size = int(input())
    arr = [list(map(int, input().split())) for _ in range(size)]
    ans_lst = []
    ans = 0
    for row in range(1, size-1):
        for col in range(1, size-1):
            # 상하좌우 중 일부라도 없으면 판단 불가이므로 가장자리 쳐내기
            cnt = 0
            for dr, dc in ((-1, 0), (1, 0), (0, -1),(0, 1)):
                nr = row + dr
                nc = col + dc # 앞 뒤 잘라내서 범위 처리 필요 없음
                if arr[row][col] > arr[nr][nc]:
                    cnt += 1
            if cnt == 4:
                ans_lst.append(arr[row][col])

    # 정답 처리
    if len(ans_lst) <= 1: # 활화산 1개 또는 0개
        ans = -1
    else:
        ans = max(ans_lst) - min(ans_lst)

    print(f"#{tc}", ans)
```
