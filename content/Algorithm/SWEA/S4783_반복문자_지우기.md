### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [스택] 현재 문자를 먼저 넣고 다음 문자와 비교하려 해서 i-1, i+1 인덱스가 복잡해짐
- [순서] append 먼저 하고 pop 2번 하면 stack[-1]이 현재 값이 되어 안 됨

### 코드 개선 방법
- [스택] 넣기 전에 top과 같으면 pop, 다르면 push
- [예외] 빈 스택이면 그냥 push

### 코드
```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):
    string = input()
    stack = []
    for i in range (len(string)): 
        #print (stack)
        if stack: # append 먼저 하고 pop 2번 하는 방법은 stack [-1] 값이 현재 값이 되므로 안 됨
            if stack[-1] == string[i]:
                stack.pop()
            else:
                stack.append(string[i])
        else:
            stack.append(string[i])
    answer = len(stack)         

    print (f'#{test_case} {answer}')
```
