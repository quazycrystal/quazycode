### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [유니온] 3-4와 4-3을 다르게 봄 → cycle(find) 함수에서 해결

### 코드 개선 방법
- [크루스칼] 모든 간선을 sort하고 가장 싼 것부터. 부모가 다르면 합치기
- [자료구조] 방문 체크 필요 없음, 인접리스트가 오히려 불편
- [재귀] find는 올라가며 찾고 return하면서 부모 갱신

### 코드
```python
# Kruskal 템플릿
import heapq
def find(x):
    if p[x] != x:
        p[x] = find(p[x]) # 재귀로 올라가면서 찾고, return하면서 값 부모로 변경
    return p[x] # 부모인 애 찾아지면 줄줄이로 찾아짐

def union(a, b):
    flag = False
    if p[find(b)] == find(a): # 너랑 나 부모가 같아??? - 같으면 T 반환
        flag = True
    else:
        p[find(b)] = find(a) # 다르면 서로 합치기
    return flag

T = int(input())
for tc in range(1, 1+T):
    # edge = 10만개까지?? 재귀 터질려나

    nodes, edges = map(int, input().split())

    sm = 0
    ans = 0

    p = [x for x in range(nodes+1)] # 얜 입력과 전혀 다른, 그냥 사이클 확인 용 애

    edge = []
    for _ in range(edges):
        s, e, w = map(int, input().split())
        edge.append((w, s, e)) # s 있으면 e 연결해 보려고 해봐야 함

    edge.sort()

    for info in edge:
        w, s, e = info[0], info[1], info[2]
        cycle = union(s, e)
        if cycle:
            continue
        else:
            ans += w

    print(f"#{tc}", ans)

```
