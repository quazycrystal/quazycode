### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [재귀] sm += i처럼 여기서 직접 바꾸면 부모 값이 바뀌어 답이 안 나옴. 인자로 넘기면 자식 값만 바뀜

### 코드 개선 방법
- [부분집합] 포함 / 미포함의 이진으로도 가능

### 코드
```python
# 부분 집합은 이진으로도 가능: 포함, 미포함
def btk(n, s, sm, l):
    global ans
    if n == N:
        if sm == K:
            ans += 1
        return
    for i in range(s, 13):  # (1, 13)
        btk(n + 1, i + 1, sm + i, l + [i])  # 순서가 달라지는것도 빼야하는데?

T = int(input())
for tc in range(1, 1 + T):
    N, K = map(int, input().split())
    ans = 0
    lst = []
    btk(0, 1, 0, lst)
    print(f"#{tc} {ans}")
```
