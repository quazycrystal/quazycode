### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [그리디] 끝나야 다음을 배치하니 끝이 빠른 순 (회의실 문제)
- [조건] 이전 끝 시간보다 앞이면 안 됨

### 코드 개선 방법
- [문법] 람다는 key에만 적용됨

### 코드
```python
T = int(input())
for tc in range(1, 1+T):

    works = int(input())
    sche = []
    sheet = [0] * 25 # 시작 0시, 끝도 마지막 0시
    ans = 0

    for _ in range(works):
        s, e = map(int, input().split())
        sche.append((s, e))

    sche.sort(key=lambda x: x[1])

    for i in range(works):
        cur = sche[i]
        s, e = cur[0], cur[1]

        # 이전 끝 시간보다 앞이면 안 됨,,
        for j in range(s, e):
            flag = 0
            if sheet[j] == 1:
                flag = 1
                break

        if flag == 0:
            for k in range(s, e):
                sheet[k] = 1

            ans += 1

    print(f"#{tc}", ans)

```
