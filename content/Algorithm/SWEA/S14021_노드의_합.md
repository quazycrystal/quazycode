### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 형제 노드끼리 더하는 이전 재귀는 완전 이진 트리일 때만 가능
- [트리 순회] 왼, 오 다음 부모라 후위 순회로 풀어야 함

### 코드 개선 방법
- [재귀] 값이 있으면 바로 return(메모이제이션), 없으면 왼 + 오 합을 저장 후 return. 종료 조건 잘 보기

### 코드
```python
def post_ord(n):
    if 0 < n < node+1:
        if lst[n] == 0:
            lst[n] = post_ord(2 * n) + post_ord(2 * n + 1)
        return lst[n]
        # 값이 나와야 다음 함수로 넘어감...

    else:
        return 0 # 그냥 return 아니고...

T = int(input())
for tc in range(1, 1+T):
    node, leaf, goal = map(int, input().split())
    lst = [0] * (node + 1) # idx 0은 안 씀
    for i in range(leaf): # 노드 저장 리스트에 값 채우기
        idx, val = map(int, input().split())
        lst[idx] = val
    #recur(node) # 노드부터 역추적
    post_ord(1)
    #print(lst)
    print(f"#{tc}", lst[goal])

```
