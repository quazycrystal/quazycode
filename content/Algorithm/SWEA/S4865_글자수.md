### 코드 개선 방법
- [set] str1은 중복 연산을 피하려 set
- [dict] dict.get(k, 0) + 1로 if-else 없이 한 줄
- [문법] max(d[c] for c in s1)로 루프를 한 줄로

### 코드
```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):

    str1 = set(input())
    str2 = input()
    t_dict = {} # {철자:나온 횟수}
    answer = 0
    for index in range (len(str2)):
        if str2[index] not in t_dict:
            t_dict[str2[index]] = 1
        else:
            t_dict[str2[index]] += 1
    for letter in str1: 
        if answer < t_dict[letter]:
            answer = t_dict[letter]
        else:
            pass
    print (f'#{test_case} {answer}')

```
