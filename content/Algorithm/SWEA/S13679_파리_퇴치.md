### 실패 / 성공 이유
- [속도] 인덱스 for문 4개는 매번 새로 다 더함

### 코드 개선 방법
- [슬라이딩 윈도우] 행마다 가로 합을 이전 합 - 왼쪽 + 오른쪽으로 구하고, 그 합을 다시 세로로 슬라이딩

### 코드
```python
# 파리 퇴치
T = int(input())
for tc in range(1, 1+T):
    arr_size, hit_size = map(int, input().split())
    arr = [list(map(int, input().split())) for _ in range(arr_size)]

    mx = 0
    sm = 0

    def sliding_window_2d(arr, arr_size, hit_size):
        row_sums = []
        for r in range(arr_size):
            row_s = []
            # 각 행의 첫 번째 윈도우 합 계산
            current_row_sum = sum(arr[r][0:hit_size])
            row_s.append(current_row_sum)
            # 행 구해다가 리스트에 넣어야...

            # 가로로 슬라이딩하며 나머지 합 계산
            for c in range(1, arr_size - hit_size + 1):
                current_row_sum = current_row_sum - arr[r][c - 1] + arr[r][c + hit_size - 1]
                row_s.append(current_row_sum)
            row_sums.append(row_s)

        final_results = []

        # 가로 위치(c)를 고정하고 세로로 내려갑니다.
        for c in range(arr_size - hit_size + 1):
            # 첫 번째 사각형(맨 위) 합 계산
            current_rect_sum = 0
            for r in range(hit_size):
                current_rect_sum += row_sums[r][c]

            # 이제 아래로 슬라이딩!
            for r in range(1, arr_size - hit_size + 1):
                current_rect_sum = current_rect_sum - row_sums[r - 1][c] + row_sums[r + hit_size - 1][c]
```
