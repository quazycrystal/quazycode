### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [문제 읽기] # 하나도 정사각형인지, 모든 막힌 부분이 정사각형이어야 하는지 헷갈림
- [엣지 케이스] 행 끝에 왔을 때도 체크

### 코드 개선 방법
- [방문 처리] 본 부분은 '.'으로 바꿔 방문 처리

### 코드
```python
T = int(input())
for tc in range(1, 1 + T):
    size = int(input())
    arr = [list(input()) for _ in range(size)]
    ans = "no"
    check = 0  # 1칸짜리 체크,..
    # 본 부분 다 "."으로 방문 처리 해도 됨!

    flag = 0
    for row in range(size):
        cnt = 0
        jwa = ()

        if flag == 1:
            break

        for col in range(size):
            if arr[row][col] == "#":
                arr[row][col] = "." # 중복 방문 방지

                cnt += 1
                if col == size - 1:
                    if cnt > 1: # 행 끝에 왔으면 체크 해 줘야지
                        jwa = (cnt, row, col + 1)  # 뒤에 포함 안 되게

                    if cnt == 1:
                        check += 1

            else: # 점 만남
                if cnt > 1:
                    jwa = (cnt, row, col)  # 마지막으로 막혔던 곳 바로 다음 좌표
                    # 어차피 이게 포함 안 되게 좌표 짤 거라 괜찮

                if cnt == 1:
                    check += 1

                cnt = 0

        if jwa != ():  # 좌표에 값 있으면 정사각형 체크 들어갑니당
            count, rr, cc = jwa
            if rr + count <= size:
                if rr + count < size:
                    for i in range(cc-count, cc):
                        if arr[rr + count][i] == "#":
                            flag = 1
                            break  # 아랫 열 확인 후

                    if flag == 1:
                        break

                for r in range(rr + 1, rr+count):  # 행
                    for c in range(cc-count, cc):  # 열
                        if arr[r][c] == ".":
                            flag = 1
                            break
                        if arr[r][c] == "#":
                            arr[r][c] = "." # 방문 표시
                            # 위의 두 경우 다 무조건 전체 모양이 정사각형이 못 됨
                    if flag == 1:
                        break
                if flag == 1:
                    break

                # break 안 당하고 오면
                check += 1
                break

    if check == 1:
        ans = "yes"

    print(f"#{tc}", ans)

```
