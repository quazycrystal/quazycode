### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [문제 읽기] 방이 두 줄로 마주봄. 정렬 후 비교하면 일렬로 놓은 것과 같아져 2-3, 4-6 같은 엣지 케이스

### 코드 개선 방법
- [구현] 방 번호를 복도 번호로 바꾸고 지나갈 때마다 +1, 최댓값이 답

### 코드
```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):
    stu = int(input()) # 돌아가야 할 학생 수
    ans = 1
    lst = [list(map(int, input().split())) for _ in range(stu)]

    cor = [0] * 200  # 복도, 200개 방 마주본다
    for i in range(stu):
        if lst[i][0] > lst[i][1]:
            lst[i][0], lst[i][1] = lst[i][1], lst[i][0] # 앞이 뒤보다 큰 경우 방지

        srt = (lst[i][0] - 1) // 2 # room 1, 2는 복도 idx0, 3, 4는 1...
        end = (lst[i][1] - 1) // 2  # room 1, 2는 복도 idx0, 3, 4는 1...
        # 방 번호를 복도 번호로
        for j in range(srt, end+1): # 앞 친구 경로
            cor[j] += 1

    ans = max(cor) # 한 번 같은 구간 지나갈 때마다 +1 됨
    print(f'#{test_case} {ans}')
```
