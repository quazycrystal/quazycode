### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [다익스트라] 손으로 돌려보면 (11, 3), (9, 3)처럼 같은 노드가 여러 번 나옴. 더 큰 건 안 봐야 함
- [조건] 단방향, 노드 0부터

### 코드 개선 방법
- [다익스트라] 전체 노드를 다 도는 대신 hq에 있는 것만. D[nxt] > D[cur] + w일 때만 넣기
- [초기화] 초기값은 float('inf')

### 코드
```python
# 다익스트라 템플릿
import heapq

T = int(input())
for tc in range(1, 1+T):
    nodes, edges = map(int, input().split())
    hq = []
    dj = [0] + [10**8] * (nodes-1) # 초기 값 왕 크게
    # 무한을 하려면 float("inf")
    adj = [[] for _ in range(nodes)] # 노드 0부터 시작이므로 +1 안 해도 됨
    for _ in range(edges):
        s, e, w = map(int, input().split())
        adj[s].append((w, e)) # weight 우선
        # 단방향

    heapq.heappush(hq, (0,  0)) # 초기 값 넣기
    while hq:
        # dist = weight 누적치, 여기 안에서부터는 dist가 되겠네
        c_weight, cur = heapq.heappop(hq) # weight 제일 작은 것 부터 나옴
        if dj[cur] >= c_weight:
            for n_weight, nxt in adj[cur]: # 다음에 갈 수 있는 노드
                if dj[nxt] > dj[cur] + n_weight:
                    heapq.heappush(hq, (dj[cur] + n_weight, nxt))
                    dj[nxt] = dj[cur] + n_weight

    print(f"#{tc}", dj[nodes-1])

```
