### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [문제 읽기] 출발지 값도 포함이라고 보고 초기값을 arr[sr][sc]로

### 코드 개선 방법
- [다익스트라] v가 곧 다익스트라 테이블. 누적값이 테이블보다 작거나 같을 때만 진행

### 코드
```python
from heapq import *


def djk(sr, sc):
    v[sr][sc] = arr[sr][sc]

    hq = []  # 누적 weight, 좌표
    heappush(hq, (arr[sr][sc], sr, sc))  # 초기 누적 값 0
    while hq:
        w, r, c = heappop(hq)
        if w <= v[r][c]:  # 지금 내가 들고 있는 누적값이 내 다익스트라 테이블보다 작거나 같으면 (더 짧은 거리 갱신)
            for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):  # 이동
                nr, nc = r + dr, c + dc
                if 0 <= nr < size and 0 <= nc < size:
                    if v[nr][nc] > arr[nr][nc] + v[r][c]:  # 나를 거쳐 갈 때 다음 갈 곳이 더 싸지면
                        v[nr][nc] = arr[nr][nc] + v[r][c]
                        heappush(hq, (v[nr][nc], nr, nc))


# 입력
T = int(input())
for tc in range(1, 1 + T):
    size = int(input())
    s_r, s_c, g_r, g_c = map(int, input().split())  # 출발, 도착
    arr = [list(map(int, input())) for _ in range(size)]  # 지도
    v = [[10 ** 18] * size for _ in range(size)]  # 최대 100*100*10

    # 다익스트라 실행
    djk(s_r, s_c)

    print(f"#{tc}", v[g_r][g_c])
```
