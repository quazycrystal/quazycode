### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [트리 순회] 중위는 왼 - 부 - 오. 전위는 나부터 저장, 후위는 자식 다 다녀온 뒤 저장

### 코드 개선 방법
- [재귀] 거시적으로 보기. 더 갈 수 없으면 저장하고 올라옴

### 코드
```python
# 트리 탐색 - in-order이므로  왼 - 부 - 오
def in_ord(n):
    if n < 1 or n > num: #노드 갯수 넘어가면
        return
    else:
        in_ord(n * 2) # 자식 왼쪽 보고 - 하나만 보는게 아니라 끝까지 갈 때 까지 계속 저기에 걸림
        ans.append(lst[n]) # 더 이상 갈 수가 없으면 나를 저장, 그리고 다시 올라옴(return)
        in_ord(n * 2 + 1) # 자식 오른쪽 봄
        # 뭔가 수렴 배울 때 처럼 거시적으로 본다
        
for tc in range(1, 10):
    num = int(input()) # 노드의 갯수
    lst = [[] for _ in range(num+1)] # 노드 갯수 +1 (0 안 씀)
    for i in range(num):
        s = input().split()
        idx, node = int(s[0]), s[1] #input().split()은 리스트로 반환하므로
        lst[idx] = node
    ans = []

    in_ord(1)
    print(f"#{tc}", "".join(ans)) # 분리 문자, join, 붙이고 싶은 거(리스트)
    # 왜 1 넣었는데 도는거지?
```
