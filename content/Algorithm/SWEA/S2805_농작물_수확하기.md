### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 윗 삼각형, 아랫 삼각형으로 for 2개 나누면 안 됨

### 코드 개선 방법
- [구현] 행마다 범위를 튜플로 계산해 슬라이스 합

### 코드
```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for tc in range(1, T + 1):
    n = int(input()) # 농장 크기
    arr = [list(map(int, input())) for _ in range(n)]
    sm = 0
    hf = int(n//2) # 5 넣으면 2

    for i in range(0, hf+1): # 범위 튜플로 뱉고 넣자
        a = hf-i
        b = hf+i+1
        u = arr[i]
        sm += sum(u[a:b])

    for j in range(hf+1, n):
        c = j-hf
        d = n-j+hf
        b = arr[j]
        sm += sum(b[c:d])

    print(f'#{tc} {sm}')

# for문 2개 쓰면 안 됨
```
