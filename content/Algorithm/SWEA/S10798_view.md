### 실패 / 성공 이유
- [초기화] 분기가 달라질 때 이전 값이 남아 있는 것 주의. 음수가 나오면 저장된 값 지우기

### 코드 개선 방법
- 

### 코드
```python
for test_case in range(1, 11):
    input()
    hgt = list(map(int, input().split()))
    answer = 0
    mn = 0
    df = []
    for i in range(2, len(hgt)-1):
        df = []
        answer += mn
        mn = 0
        for j in range (i-2, i+3):
            diff = hgt[i] - hgt[j]
            # print(diff)
            if diff < 0:
                mn = 0 # 중간에 음수 나온 경우에 mn에 저장된 양수 값 지우기
                break
            elif diff > 0:
                df.append(diff)
                mn=min(df)
    print (f'#{test_case} {answer}')
    # 분기 달라질 때 값 남아있는 것 주의

# 답
```
