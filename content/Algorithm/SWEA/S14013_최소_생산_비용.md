### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [범위] 15개까지라 가지치기 필요

### 코드 개선 방법
- [가지치기] 들어오자마자 현재 최솟값보다 크면 return
- [초기화] 비용 최대 99라 초기값 100 * n

### 코드
```python
def btk(n, sm):
    global ans
    # 가지치기는 들어 오자 마자
    if sm > ans: # 최솟값 보다 크면 볼 필요 없다
        return
    if n == N:
        ans = min(ans, sm)
        return
    for col in range(N):
        if v[col] == 0: # 방문한 열인지 따져 봐야지
            v[col] = 1 # 계속 변하는 변수가 들어가야
            btk(n+1, sm+arr[n][col])
            v[col] = 0

T = int(input())
for tc in range(1, 1+T):
    N = int(input())
    arr = [list(map(int, input().split())) for _ in range(N)]
    ans = 100 * N
    v = [0] * N
    btk(0, 0)
    print(f"#{tc}", ans)
```
