### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 리스트를 뒤에서부터 봐야 함

### 코드 개선 방법
- 

### 코드
```python
T = int(input())

# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):
    l = int(input())
    lst = list(map(int, input().split()))
    mx = lst[l-1]
    ans = 0
    for i in range(l-2, -1, -1):
        if lst[i] < mx:
            ans += mx - lst[i]
        elif lst[i] > mx:
            mx = lst[i]
    print (f'#{test_case} {ans}')
```
