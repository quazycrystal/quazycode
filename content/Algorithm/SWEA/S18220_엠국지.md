### 실패 / 성공 이유
- [조합] 다음 호출은 i+1부터
- [재귀] 호출했으면 반환값을 받아야

### 코드
```python
def btk (m, s, a):
    global ans
    if m == M:
        if a == K:
            ans += 1
        return

    for i in range(s, N):
        btk(m + 1, i+1, a + country[i]) # 조합 i+1이 되어야 함

# 호출 했으면 받아 줘야
T = int(input())
for tc in range(1, 1+T):
    N, M, K = map(int, input().split())
    country = list(map(int, input().split())) # 국가
    ans = 0
    sm = 0
    btk(0, 0, sm)
    print(f"#{tc}", ans)
```
