### 코드 개선 방법
- [재귀] base case도 위에, 큰 수에서 작은 수로 들어가 바닥 찍고 return하며 더하기

### 코드
```python
def fib(n):
    # base case도 여기, 큰 수에서 작은 수 역으로 들어감
    if n == 1:
        return 1
    if n == 2:
        return 1
    else:
        return fib(n-2) + fib(n-1)

T = int(input())
for tc in range(1, T+1):
    goal = int(input())
    print(f"#{tc}", fib(goal))
```
