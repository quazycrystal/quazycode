### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [재귀] 안에서 1을 반환해도 부모가 받아서 처리하지 않으면 사라짐
- [조건] 이번엔 단방향, 간선 하나만 추가

### 코드 개선 방법
- [재귀] 재귀 return으로 답 넘기지 말고 전역 변수로
- [재귀] 방문 표시와 가지치기(종료 조건)는 함수 맨 위에서. 그러면 시작값이 목표일 때도 적용

### 코드
```python
def dfs(s):
    global ans
    v[s] = 1  # 방문 표시, 첫 방문 시 해야할 것 있다면 처리
    if s == 99:
        ans = 1  # 아하 그래서 여기서 조건 판단이구나!
    for nxt in adj[s]:
        if v[nxt] == 0:
            dfs(nxt)


# 그냥 전역변수로 1 넘기자

# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for tc in range(1, 11):
    ans = 0
    _, num = map(int, input().split())  # 테케 번호, 길의 총 갯수
    v = [0] * 100  # 방문 리스트 목록 0-99까지, 0(start)과 99(end)는 빈다
    adj = [[] for _ in range(100)]  # 인접 리스트
    temp = list(map(int, input().split()))  # input 값 받아 한 줄 리스트
    for i in range(0, num * 2, 2):  # 인접 리스트에 데이터 넣기
        adj[temp[i]].append(temp[i + 1])  # 길이가 num*2라 괜찮
    dfs(0)

    print(f'#{tc} {ans}')
```
