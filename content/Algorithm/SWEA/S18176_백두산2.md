### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [조건] 암석과 대피소에는 확산 불가
- [로직] 여러 시나리오라 arr 하나를 공유할 수밖에 없음

### 코드 개선 방법
- [BFS] 마그마는 초기값을 큐에 모두 넣고 같은 일수별로 확산
- [DFS] 대피 경로는 상하좌우 재귀. 토마토 + 백트래킹

### 코드
```python
from pprint import pprint

T = int(input())
for tc in range(1, 1+T):
    row, col = map(int, input().split())
    arr = [list(map(int, input().split())) for _ in range(row)]
    q = []
    srt = tuple() # 시작점
    flag = 0

    for rr in range(row):
        for cc in range(col):
            if arr[rr][cc] == 3:
                q.append((rr, cc))
            if arr[rr][cc] == 4:
                srt = (rr, cc)
                arr[rr][cc] = 0
                print(rr, cc)

    print(arr)

    q1 = [srt]
    # 마그마 확산 로직
    while q:
        for lv in range(len(q)):  # 같은 일 수 별로 본다
            cur = q.pop(0)
            r, c = cur[0], cur[1]
            for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
                nr = r + dr
                nc = c + dc
                # 범위 체크
                if 0 <= nr < row and 0 <= nc < col:
                    if arr[nr][nc] == 1: # 확산 가능 지대
                        arr[nr][nc] = 3
                        q.append((nr, nc))

        while q1:
            now = q1.pop()
            cr, ccc = now[0], now[1]
            print(cr, ccc)
            for ddr, ddc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
                nnr = cr + ddr
                nnc = ccc + ddc
                # 범위 체크
                if 0 <= nnr < row and 0 <= nnc < col:
                    if arr[nnr][nnc] == 1:  # 확산 가능 지대
                        arr[nnr][nnc] = arr[cr][ccc] - 1
                        q1.append((nnr, nnc))
                    if arr[nnr][nnc] == 2:
                        arr[nnr][nnc] = arr[cr][ccc] - 1
                        q1.append((nnr, nnc))
                        flag = 1
                        break
        print(arr)
    print(flag)
    print(arr)
    if flag == 0:
        print(-1)
```
