### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [거리] 시작, 종료 위치는 칸 수에서 제외 (-2)

### 코드 개선 방법
- [거리] visited에 거리를 더해가며 찾고, 끝 좌표 거리로 구하기
- [BFS] 2중 q: 같은 반경을 while 안의 q에 다 넣기. 반경 제약이 있을 때 좋음

    q = []
    v = [[0] * N for _ in range(N)]

    q.append((si, sj))
    v[si][sj] = 1

    while q:
        ci, cj = q.pop(0)
        if (ci, cj) == (ei, ej):
            return v[ci][cj] - 2  # 시작위치, 종료위치제외 -2
