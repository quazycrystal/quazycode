### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [유니온] 큰 대표값을 작은 대표값으로 바꿔야 하나로 합쳐짐
- [유니온] p에 서로 다른 수 개수를 세면 안 됨. 머리만 바뀌고 나머지는 한 번 더 find 해야 함

### 코드 개선 방법
- [유니온] 마지막에 전체 find를 한 번 더 돌리고 set으로 개수 (0 제외)

### 코드
```python
# 크루스칼
def find(x):
    if p[x] != x:
        p[x] = find(p[x]) # 부모가 아니면 그 수를 다시 재귀에
    return p[x]

def union(s, e):
    E = find(e)
    S = find(s) # 부를 때 값이 달라지나봄...
    if p[E] != S: # 끝의 부모 값과 처음의 부모 값이 다르면
         p[E] = S
    return # 그냥 다 합쳐

T = int(input())
for tc in range(1, 1+T):
    nodes, edges = map(int, input().split())
    p = [x for x in range(nodes+1)]

    apply = list(map(int, input().split()))
    for i in range(0, edges*2, 2):
        start = apply[i]
        end = apply[i + 1]
        union(start, end)

    for i in range(1, nodes+1):
        find(i) # 한 번 더 돌려야,,,

    print(f"#{tc}", len(set(p))-1) # 0 제거를 위해 1 뺀다

```
