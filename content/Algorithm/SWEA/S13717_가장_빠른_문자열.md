### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 안에서 또 루프로 패턴을 비교하면 꼬임

### 코드 개선 방법
- [문법] replace(바꿀 것, 바꿀 값, 횟수)

### 코드
```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):
    goal, pat = input().split() # goal: 만들어야 하는 문자열, pat: 단축키
    ans = 0
    while True:
        if pat in goal:
            goal = goal.replace(pat, '', 1) # 한 번에 하나만 찾게
            ans += 1
        else:
            break
    ans += len(goal)
    print(f'#{test_case} {ans}')
```
