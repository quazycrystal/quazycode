### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [조건] 다음 칸의 구조물이 현재 방향과 연결 가능한지 확인 (위: 1,2,5,6 / 아래: 1,2,4,7 / 오: 1,3,6,7 / 왼: 1,3,4,5)

### 코드 개선 방법
- [룩업 테이블] 구조물별 갈 수 있는 방향을 dict로. 방향을 (0,3,1,2)로 두면 3에서 빼서 반대 방향

### 코드
```python
# 상 하 좌 우
value = {(-1, 0): [1, 2, 5, 6],
         (1, 0): [1, 2, 4, 7],
         (0, -1): [1, 3, 4, 5],
         (0, 1): [1, 3, 6, 7]}

# 봐야 할 다음 곳
d = {1: [(-1, 0), (1, 0), (0, -1), (0, 1)], # 상 하 좌 우
     2: [(-1, 0), (1, 0)], # 상 하
     3: [(0, -1), (0, 1)], # 좌 우
     4: [(-1, 0), (0, 1)], # 상 우
     5: [(1, 0), (0, 1)], # 하 우
     6: [(1, 0), (0, -1)], # 하 좌
     7: [(-1, 0), (0, -1)], # 상 좌
     }

# bfs로 지도 바꾸어 가며 방문 표시 만든다
def go(sr, sc):
     v[sr][sc] = 1
     q = []
     q.append((sr, sc))
     while q:
          cur = q.pop(0)
          r, c = cur[0], cur[1]
          now = arr[r][c]
          # 맨홀은 항상 터널이 있는 곳에서 시작
          for dr, dc in d[now]:
               nr, nc = r + dr, c + dc
               if 0 <= nr < row and 0 <= nc < col:
                    if v[nr][nc] == 0: # 미방문
                         if arr[nr][nc] in value[(dr, dc)]: # 그 다음으로 이동이 가능
                              v[nr][nc] = v[r][c] + 1
                              q.append((nr, nc))
                              if v[nr][nc] > time:
                                   return

T = int(input())
for tc in range(1, 1+T):
     ans = 0
     row, col, sr, sc, time = map(int, input().split())
     arr = [list(map(int, input().split())) for _ in range(row)]
     # 가로 세로 50 이하이므로 하나 더 만들어도 되겠다
     v = [[0] * col for _ in range(row)]
     go(sr, sc)

     # 답
     for rr in range(row):
          for cc in range(col):
               if v[rr][cc] <= time and v[rr][cc] != 0:
                    ans += 1
     print(f"#{tc}", ans)

```
