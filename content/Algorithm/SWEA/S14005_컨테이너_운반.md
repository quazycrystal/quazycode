### 코드 개선 방법
- [그리디] 무거운 컨테이너부터 실을 수 있는 트럭에, 못 실으면 다음 컨테이너

### 코드
```python
T = int(input())
for tc in range(1, 1+T):
    con_num, t_num = map(int, input().split())
    cons = list(map(int, input().split()))
    trucks = list(map(int, input().split()))

    cons.sort(reverse = True)
    trucks.sort(reverse = True)

    ans = 0
    c = 0
    t = 0

    while 0 <= c < len(cons) and 0 <= t < len(trucks):
        if cons[c] <= trucks[t]: # 트럭이 실을 수 있다!
            ans += cons[c]
            c += 1
            t += 1
        else:
            c += 1 # 다음 덜 무거운 컨테이너랑 비교

    print(f"#{tc}", ans)

```
