### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [예외 처리] 범위를 벗어나면 0이나 n-1로 강제 고정 → 끝 칸이 자기 자신·엉뚱한 값과 계산됨
- [분기] 조건 4개를 따로 쓰면 하나만 틀려도 디버깅이 어려움

### 코드 개선 방법
- [델타 탐색] 상하좌우 delta 리스트로 돌고 0 <= ni < n and 0 <= nj < n 한 번에 체크
- [범위] 전체 탐색은 range(n)으로 끝 원소까지

### 코드
```python
T = int(input())
# 델타 탐색  
for test_case in range(1, T + 1):  
    n = int(input())  
    arr = [list(map(int, input().split())) for _ in range(n)]  
    dy = [-1, 1, 0, 0]  
    dx = [0, 0, -1, 1] # 상 하 좌 우  
    ans = 0  
    for i in range(n):  
        for j in range(n): # 전체 arr 탐색  
            for k in range(4): # delta 탐색  
                nxt_i = i + dx[k]  
                nxt_j = j + dy[k]  
  
                if nxt_i<0:  
                    nxt_i = 0  
  
                elif nxt_i>=n:  
                    nxt_i = n-1  
  
                elif nxt_j<0:  
                    nxt_j = 0  
  
                elif nxt_j>=n:  
                    nxt_j = n-1  
  
                ans += abs(arr[i][j] - arr[nxt_i][nxt_j])   
    print(f'#{test_case} {ans}')
```
