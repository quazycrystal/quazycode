### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [예외] 오른 괄호가 맨 처음 나오는 경우를 빼먹음. 빈 스택에서 stack[-1]에 접근해 런타임 에러

### 코드 개선 방법
- [스택] 오른 괄호를 만날 때마다 왼 괄호 스택과 바로 비교. 짝은 dict로
- [예외] 빈 스택이면 바로 실패. 끝나고 스택이 남아도 실패
- [습관] index 0, 길이 0일 때를 한 번 더 생각

### 코드
```python
for index in range (len(check_str)): 
        if check_str[index] in left_map:

        # stack과 체크 로직
        elif check_str[index] in right_map:
            if right_map[check_str[index]] == data_stack[-1]:
                data_stack.remove(data_stack[-1]) #data_stack.pop(-1)

    if len(data_stack) == 0:

    else:
        answer = 0
    print (f'#{test_case} {answer}')
```

```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):
    check_str = input().strip() # 공백 문자 무시
    data_stack = []
    left_map = {'(': 0, '{': 1, '[': 2}
    right_map = {')': 0, '}': 1, ']': 2}
    answer = 0
    for index in range (len(check_str)): 
        if check_str[index] in left_map:
            data_stack.append (left_map[check_str[index]])
        elif check_str[index] in right_map:
            if len(data_stack) == 0:
                answer = 0
                break
            else:
                if right_map[check_str[index]] == data_stack[-1]:
                    data_stack.pop(-1) #data_stack.remove(data_stack[-1])
                    if len(data_stack) == 0:
                        answer = 1
                else:
                    answer = 0
                    break #여기에 stack 비었을 때는 포함이 안 됨... -> if 문 하나 더 쓰기
    print (f'#{test_case} {answer}')
```
