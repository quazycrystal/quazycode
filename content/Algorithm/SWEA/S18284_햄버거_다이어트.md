### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [문제 읽기] 조합이란 말이 있지만 부분집합. 재료 수가 깊이
- [재귀] 포함/미포함을 이미 n마다 하므로 for를 한 번 더 넣으면 안 됨

### 코드 개선 방법
- [가지치기] N 20이라 칼로리 넘으면 바로 컷
- [자료구조] 점수와 칼로리를 튜플로

### 코드
```python
def btk(n, score, cal):
    global ans
    if cal > mx_cal:
        return

    if n == N:
        if ans < score:
            ans = score
        #print(cal)
        return
    btk(n+1, score + score_cal[n][0], cal + score_cal[n][1]) # 포함
    btk(n+1, score, cal) # 미포함

T = int(input())

for tc in range(1, 1+T):

    N, mx_cal = map(int, input().split())
    score_cal = []
    ans = 0

    for _ in range(N):
        sc = tuple(map(int, input().split()))
        score_cal.append(sc)
        # 점수와 칼로리를 튜플로 묶어 score_cal에 저장

    btk(0, 0, 0)
    print(f"#{tc}", ans)

```
