### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 연속 길이는 미래(k+1)를 보지 말 것. 값이 1일 때가 아니라 끊기는 0이 나올 때 길이 체크
- [엣지 케이스] 행 끝에 다다랐을 때도 길이 체크

### 코드 개선 방법
- [전치] 가로를 본 뒤 전치 행렬로 세로도 같은 코드로

### 코드
`W1/S13680_어디에_단어가.py`

```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):
    ans = 0
    void = 0
    num, goal = map(int, input().split())  # n은 배열 크기, k는 목표 단어 길이
    arr = [list(map(int, input().split())) for _ in range(num)]
    # 전치행렬 사용한 풀이
    arr_t = list(zip(*arr))
    for i in range(2):
        for j in range(num):
            void = 0
            for k in range(num):  # k + 1 방식은 성공한 적이 없다, 현 상태를 보고 판단

                if i == 0:  # 원래 행렬
                    if arr[j][k] == 1:
                        void += 1
                        if k == num - 1:  # 열 끝에 다다랐는데 k가 1이면 그냥 넘어가니까
                            if void == goal:
                                ans += 1

                    else:  # 첫 0 나올 때 지금까지 나온 연속 1의 길이 체크
                        if void == goal:
                            ans += 1
                        void = 0

                else:  # 전치 행렬
                    if arr_t[j][k] == 1:
                        void += 1
                        if k == num - 1:  # 열 끝에 다다르면
                            if void == goal:
                                ans += 1

                    else:
                        if void == goal:
                            ans += 1
                        void = 0
    print(f'#{test_case} {ans}')
```
