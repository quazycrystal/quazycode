### 실패 / 성공 이유
- [재귀] 1부터 시작하면 그대로 출력하면 안 됨

### 코드 개선 방법
- [재귀] 리턴할 때 출력하면 역순
- [변수] 밖의 값을 바꿀 땐 global

T = int(input())

def print_N(i):
    # 종료 조건 가장
    j = i  # 위에 기본 변수 선언
    if j < goal:
        return
    lst.append(j)
    j = i - 1
    # lst.append(j) 여기에 하면 j 값 변한 후 추가 됨
    print_N(j)


for tc in range(1, T + 1):
    init = int(input())
    goal = 1  # 목표값
    lst = []
    print_N(init)
    print(f"#{tc}", *lst)
