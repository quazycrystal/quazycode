### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [인덱스] 1번부터, 값이 같으면 작은 인덱스. 앞, 뒤 모두 포함

### 코드 개선 방법
- [룩업 테이블] 가위바위보 승패는 dict로
- [재귀] 돌아올 때 이긴 하나만 들고 오기

### 코드
```python
rcp_lose = {1:2, 2:3, 3:1} # key가 value 한테 짐
def merge(s, e): # 인덱스 넣는다....... (앞, 뒤 모두 포함)
    if s == e:
        return s
    mid = (s + e) //2 # 끝이 포함
    left = merge(s, mid)
    right = merge(mid+1, e) # 인자 아니라 변수!
    # 그냥 돌아올 때 하나 들고 돌아오는 것...

    # 앞에 것이 짐 -> 이때만 뒷 인덱스, 나머지는 다 앞 인덱스
    if card[right] == rcp_lose[card[left]]:
        return right

    else:
        return left
# 인덱스?

T = int(input())
for tc in range(1, 1 + T):
    N = int(input())
    card = [0] + list(map(int, input().split())) # 인덱스 맞춰주기

    ans = merge(1, len(card)-1)
    print(f"#{tc}", ans)

```
