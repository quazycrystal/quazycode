### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [인덱스] p_index, shift를 일일이 계산해 변수가 많고 실수 위험
- [범위] 타겟 범위를 n - m으로 잡아 길이가 같을 때 안 돎. n - m + 1

### 코드 개선 방법
- [슬라이싱] 구간을 잘라 [::-1]과 비교하면 인덱스 계산 불필요
- [투 포인터] 앞뒤 인덱스를 좁혀가며 m//2까지 비교
- [제어 흐름] 변수를 마음대로 건너뛰거나 되돌리려면 for 대신 while
- [출력] 리스트를 str()하면 괄호까지 문자. ''.join 사용

### 코드
```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):

    n, m = map(int, input().split())
    r_input = [list(input()) for _ in range (n)] #list 안에 str이 들어있는 형태
    c_input = list(zip(*r_input))
    answer= []
    target = []
    
    for list_type in r_input, c_input:
        for row in range (n):
            for column in range (n-m+1):
                target = list_type[row][column:column+m] 
                i = 0
                while i <= m//2:
                    #print (i)
                    if target[i] == target[m-i-1]:
                        if i == m//2:
                            answer = "".join(target) # 다시 등장한 join메소드! 중요중요. 앞에 구분자 정할 수 있어 좋음
                            break
                        else:
                            i += 1
                    else:
                        i = 0
                        break
    print (f'#{test_case}', answer) # *answer
```
