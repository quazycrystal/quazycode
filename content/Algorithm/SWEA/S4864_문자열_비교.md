### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [시간 복잡도] while 안에서 rfind()로 매번 검색해 O(NM) 시간초과
- [무한 루프] dict 값이 0이면 shift가 안 늘어 무한 루프
- [범위] shift 상한을 len(t)로 잡으면 인덱스 에러와 불필요한 연산

### 코드 개선 방법
- [룩업 테이블] 패턴을 역순 dict로 미리 만들어 루프 안에서는 조회만 O(1)
- [무한 루프] index 0일 때는 shift 1
- [범위] shift <= len(t) - len(p)

### 코드
```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):

    p = input()
    len_p = len(p)
    p_end = len_p - 1 #index니까 -1
    p_dict =  {char: (p_end - i) for i, char in enumerate(p)}
    t = input()
    shift = 0
    answer = 0 

    while shift <= len(t) - len(p): #shift값 len(t)와 같거나 작을 때 -> 조건 위험
        
        #타깃 알파벳과 패턴 맨 마지막 알파벳 일치 여부 확인
        if p[p_end] == t[shift+p_end]: #일치
            if p_end ==0 and p[0] == t[shift]: #p_end가 0까지 와야만 맨 앞과 끝 문자만 보고 통과시키는 일이 없어짐
                answer = 1
                break
            else:
                p_end -= 1
                #print [shift]
        else: #불일치
            p_end = len_p - 1
            if t[shift+p_end] not in p_dict.keys(): # 타깃 알파벳이 패턴에 없음
                shift += len_p
            else: # 타깃 알파벳이 패턴에 있음
                if p_dict[t[shift+p_end]] == 0: #index = 0 무한 루프 방지
                    shift += 1
                else:
                    shift += p_dict[t[shift+p_end]]
    else:
        answer = 0
    print (f"#{test_case} {answer}")

'''

            p_end = len(p) - 1
            if p.rfind(t[shift+p_end]) == -1: # 타깃 알파벳이 패턴에 없음
                shift += len(p)

                shift += p.rfind(t[shift+p_end])
    else:
        answer = 0
    print (f"#{test_case} {answer}")
