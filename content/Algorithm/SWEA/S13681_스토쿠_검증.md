### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [로직] 행, 열, 3x3을 각각 확인. 3x3은 3칸씩 건너뛰기(step)

### 코드 개선 방법
- [자료구조] lst flag 대신 set이 용량도 아낌
- [함수 설계] 함수로 나누면 변수 이름을 다시 써도 됨. j, i만 바꾸면 전치처럼 열 확인

### 코드
```python
def check_3(arr):
    for __ in range (0,9,3): # 3칸씩 건너뛰며 확인
        for _ in range (0,9,3):
            set1 = set()
            for i in range(3):
                for j in range (3): # 3*3 배열 속 확인을 위한 반복문
                    set1.add(arr[i+__][j+_]) # set에 요소 값 추가, _,__도 쓸 수 있군!
            if len(set1) != 9:
                return False
    return True

def check_row(arr):
    for i in range (9):
        set1 = set() # 다른 함수 안이라서 set1 두 번 써도 되나봐
        for j in range (9):
            set1.add(arr[i][j])
        if len(set1):
            if len(set1) != 9:
                return False
    return True

def check_col(arr):
    for i in range (9):
        set1 = set() # 다른 함수 안이라서 set1 두 번 써도 되나봐
        for j in range (9):
            set1.add(arr[j][i]) # j, i 위치만 바꿔주면! -> 전치행렬처럼 되니까
        if len(set1):
            if len(set1) != 9:
                return False
    return True
# 함수는 위에다 짜놓나봐!

T = int(input())
for tc in range (1, T+1):
    arr = [list(map(int, input().split())) for i in range(9)]
    if (check_3(arr) and check_row(arr) and check_col(arr)):
        print (f'#{tc} 1')
    else:
        print (f'#{tc} 0')


```
