### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [방문 처리] 시작점도 똑같이 방문 표시. 자꾸 빼먹음

### 코드 개선 방법
- [DFS] 방문 표시 → 최근 좌표 쌓기 → 현재 위치 바꾸기

### 코드
```python
def dfs(s):
    global end
    global ans
    stk = []
    cur = s # 초기값 세팅
    # 자꾸 빼먹지 말기, 초기도 똑같이 방문 표시, 스택은 안 쌓아도
    v[cur] = 1
    while True:
        for nxt in adj[cur]:
            if v[nxt] == 0:
                v[nxt] = 1 # 방문 표시
                stk.append(nxt) # 제일 최근 좌표 쌓기
                if nxt == end:
                    ans = 1
                    cur = nxt # 현재 위치 바꾸기
                    break # 중요!!!
        else:
            if stk:
                cur = stk.pop()
            else:
                break


# v, adj
T = int(input())
for tc in range (1, T+1):
    ver, edge = map(int, input().split())
    adj = [[] for _ in range (ver+1)]
    for i in range (edge):
        temp = list(map(int, input().split()))
        adj[temp[0]].append(temp[1])
    srt, end = map(int, input().split())
    #print(end)
    v = [0] * (ver+1)
    ans = 0
    dfs(srt)
    print(f'#{tc} {ans}')
```
