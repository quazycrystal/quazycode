### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [범위] 0부터 돌리면 dx, dy가 0이 되어 본인을 여러 번 더함. 1부터 arr[i][j]까지

### 코드 개선 방법
- 

### 코드
```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):
    dy = [-1, 1, 0, 0] # 상하좌우
    dx = [0, 0, -1, 1]
    r, c = map(int, input().split())
    arr = [list(map(int, input().split())) for _ in range(r)]
    sm = 0
    sm_mx = 0
    for i in range(r):
        for j in range(c):
            sm = arr[i][j]
            for k in range(4):
                for l in range(1, arr[i][j]+1): # 0부터 돌리면 dx dy 0되어서 본인 4번이나 더 더함
                    # arr[i][j]만큼 되려면 arr[i][j]+1로 설정해야
                    x = i + (dx[k] * l)
                    y = j + (dy[k] * l)
                    if 0 <= x < r and 0 <= y < c:
                        sm += arr[x][y]
            if sm_mx < sm:
                sm_mx = sm
    print(f'#{test_case} {sm_mx}')
```
