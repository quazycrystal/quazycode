### 실패 / 성공 이유
- [슬라이싱] 슬라이싱으로 한꺼번에 바꾸려면 오른쪽도 iterable이어야 함

### 코드 개선 방법

### 코드
```python
for test_case in range(1, T + 1):
    lst = list(map(int, input()))
    l = len(lst)
    init = [0]*l
    ans = 0

    for i in range (l):
        if lst[i] == 1 and init[i] == 0:
            ans += 1
            for j in range(i, l):
                init[j] = 1

        elif lst[i] == 0 and init[i] == 1:
            ans += 1
            for k in range(i, l):
                init[k] = 0
    print(f'#{test_case} {ans}')
    # ///////////////////////
```
