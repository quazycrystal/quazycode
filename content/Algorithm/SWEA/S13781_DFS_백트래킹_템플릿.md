### 코드 개선 방법
- [템플릿] 방문 표시, 첫 방문시 할 일 → 연결 노드 반복 → (범위 내), 미방문, 조건이면 재귀 호출
- [템플릿] 반복문 버전: 이동 전 되돌아올 위치 push, 다 보면 pop, 스택이 비면 끝

### 코드
```python
def dfs(cur):
    # [1] 방문표시, 첫 방문시 해야할일 처리
    v[cur] = 1
    ans.append(cur)

    # [2] 연결된 노드/4/8방향 반복처리
    for nxt in adj[cur]:
        if v[nxt] == 0:
            dfs(nxt)  # NXT 기준으로 깊이우선 탐색


TC = int(input())
for tc in range(1, TC + 1):
    V, E = map(int, input().split())
    adj = [[] for _ in range(V + 1)]

    for _ in range(E):
        s, e = map(int, input().split())
        adj[s].append(e)
        adj[e].append(s)

    # 정점을 오름차순으로 방문
    for lst in adj:
        lst.sort()

    ans = []  # 정답(방문순서 저장)
    v = [0] * (V + 1)  # visited 방문표시
    dfs(1)  # 1번 정점부터 탐색 시작!
    print(f'#{tc}', *ans)
```
