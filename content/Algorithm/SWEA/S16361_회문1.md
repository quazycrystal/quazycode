### 코드 개선 방법
- [구현] 가로와 세로를 윈도우 크기만큼 잘라 회문 후보 확인

### 코드
```python
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, 11):
    # 1. 가로와 세로 탐색
    w_size = int(input()) # 윈도우 사이즈
    arr = [list(input()) for _ in range(8)]
    ans = 0

    p_row = []  # 가로에서 가능한 후보
    p_col = []

    for i in range(8):
        row = arr[i]
        col = list(zip(*arr))[i]
        for j in range(8-w_size+1):
            p_row = row[j:j+w_size] # 가로에서 가능한 후보
            p_col = col[j:j+w_size] # 세로에서 가능한 후보

            for k in range(w_size // 2):
                if p_row[k] != p_row[w_size-(k+1)]:
                    break
                if p_row[k] == p_row[w_size - (k + 1)] and k == (w_size // 2)-1:
                    ans += 1

            for k in range(w_size // 2):
                if p_col[k] != p_col[w_size-(k+1)]:
                    #print (p_col[k])
                    break
                if p_col[k] == p_col[w_size - (k + 1)] and k == (w_size // 2)-1:
                    ans += 1
    print(f'#{test_case} {ans}')


```
