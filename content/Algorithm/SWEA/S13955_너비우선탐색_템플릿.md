### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [큐] 리스트 큐는 pop이 아니라 pop(0)
- [조건] 간선 양방향, 낮은 정점부터, 시작 = 1

### 코드 개선 방법
- [템플릿] 시작 값을 큐에 넣고 방문 → 꺼내서 인접 리스트 확인 → 미방문이면 방문 기록(+1) 후 큐 추가

### 코드
```python
def bfs(s):
    # 주석부터
    global ans
    v[s] = 1
    q = []
    q.append(s) # 여기서 처음 시작할 때 시작 값을 큐에 넣음
    ans.append(s)
    while q: # q에 값이 있을 때
        cur = q.pop(0) # 그냥 pop 아니라 pop(0)!!!!!
        for nxt in adj[cur]: # 인접 리스트 오픈
            if v[nxt] == 0: # 방문 안 했으면
                v[nxt] = 1
                q.append(nxt) # 큐에 추가해서 나중에 쓸 수 있게
                ans.append(nxt)
T = int(input())
for tc in range (1, T+1):
    ans = []
    node, edge = map(int, input().split())
    v = [0] * (node + 1)  # 방문 기록
    adj = [[] for _ in range(node+1)] # 항상 +1
    for _ in range(edge):
        temp = list(map(int, input().split()))
        adj[temp[0]].append(temp[1])
        adj[temp[1]].append(temp[0]) # 양 방향

    for i in range(len(adj)):
        adj[i].sort()

    bfs(1)
    print(f'#{tc}', *ans)
```
