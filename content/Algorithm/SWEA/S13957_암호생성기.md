### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [문제 읽기] 한 사이클은 8이 아니라 5
- [조건] 숫자가 0보다 작아지면 0으로 두고 종료

### 코드 개선 방법
- [습관] 마음 급하면 더 돌아감. 문제 잘 읽기

### 코드
```python
for tc in range (1, 11):
    input() # 케이스 넘버 제거
    lst = list(map(int, input().split()))
    # 8개 숫자 입력
    while lst[7] > 0:
        for i in range(5):
            num = lst.pop(0) - (i+1)
            if num < 0:
                num = 0
            lst.append(num)
            if num == 0:
                break
    print(f'#{tc}', *lst)

# break 범위, 숫자가 0보다 작아지면
```
