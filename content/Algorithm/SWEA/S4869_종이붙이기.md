### 코드 개선 방법
- [점화식] 길이 N 직전의 마지막 동작을 보기: +10(1가지) 또는 +20(2가지). f(n) = f(n-10) + 2·f(n-20)
- [중복] 마지막 조각이 이전에 센 조각으로 쪼개지면 중복. +20은 세로로 쪼개지지 않는 것만
- [인덱스] 정답 출력은 for 밖에서 n-1 인덱스

### 코드
```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):

    # 점화식은 마지막만 보자 (재귀 함수 / DP)
    save_list = [1, 3]
    n = int(input())//10
    answer = 0
    for index in range (n):
        if index > 1:
            new_value = int(save_list [index-1]) + (int(save_list[index-2]) * 2)
            save_list.append(new_value)
    answer = save_list[n-1] #index이므로 n-1, 코드블록 주의. 
    print (f'#{test_case} {answer}')
```
