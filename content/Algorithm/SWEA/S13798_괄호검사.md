### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [스택] 빈 스택에 오른 괄호가 들어오는 경우를 처리 안 했음
- [스택] 스택이 비었는지로만 보면 하나도 안 들어와서 빈 건지 짝 맞아 빈 건지 모름

### 코드 개선 방법
- [초기화] 답을 꼼꼼히 초기화하고, 짝 맞아 비는 순간에 정답 처리
- [자료구조] 괄호 종류를 dict로 숫자 매핑

### 코드
```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
l_dict = {'[': 1, '{': 2, '(': 3}  # 각 왼 괄호에 대응 하는 숫자 작성
r_dict = {']': 1, '}': 2, ')': 3}  # 각 오른 괄호에 대응 하는 숫자 작성
for test_case in range(1, T + 1):
    stk = []
    ans = 0
    s = input()
    for char in s:
        # 빈 스택 처리 안 함!!!!!!!!!!!!!
        if char in l_dict:
            stk.append(l_dict[char]) # 왼 괄호 만나면 대응 하는 숫자 스택에 추가
        if char in r_dict:
            if not stk: # 빈 스택에 오른 괄호 들어오면
                ans = 0
                break # 이미 땡
            else:
                if r_dict[char] == stk[-1]: # 왼 괄호와 오른 괄호 번호 맞으면
                    stk.pop() # 뿅
                    if not stk: # 다 돌고 아무 것도 없으면
                        ans = 1
                else: # 왼 괄호와 짝이 맞지 않는 오른 괄호 들어 오면
                    ans = 0
                    break # 아니면 땡

    print(f'#{test_case} {ans}')
```
