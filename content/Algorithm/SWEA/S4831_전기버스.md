### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [범위] 시작점 → 첫 충전소, 마지막 충전소 → 종점 거리를 빼먹음
- [초기화] 케이스마다 초기화할 변수를 가장 바깥 for 밖에 둠

### 코드 개선 방법
- [그리디] 끝이 정해져 있고 앞에서 최대한 가는 게 다음 선택을 막지 않으면 그리디 가능
- [로직] 거리를 더하다 최대 충전 거리를 넘으면 충전 +1, 임시 변수는 0이 아니라 넘치게 만든 구간 값으로
- [범위] range 인자 (i, j, k) 확인

### 코드
```python
T = int(input())
for i in range(1, T + 1):
    knm = list(map(int, input().split()))
    charge = list(map(int, input().split()))
    charge.append(knm[1])
    distance = [] # 케이스 바뀔 때 마다 초기화 때려야
    answer = 0 # 케이스 바뀔 때 마다 초기화 때려야 (이것도 마찬가지...)
    temp = 0 # 케이스 바뀔 때 마다 초기화 때려야 (이것도 마찬가지...)
    for j in range (0, knm[2]+1):
        if j == 0:
            step = charge[j]
        else:
            step = charge[j] - charge[j-1]
        distance.append(step)
    for k in range (len(distance)):
        temp += distance[k]
        if temp > knm[0]:
            answer += 1
            temp = distance[k] #이 순간 나가지는 거 아닌가? -> 맞음
        if distance[k] > knm[0]:
            answer = 0
            break
    print (f"#{i} {answer}") 
```
