### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [조건] 벽이 '아닌' 곳으로 가야 함
- [입력] input은 다 str
- [반복 DFS] cur = s로 다 넣으면 같은 코드 무한 반복

### 코드 개선 방법
- [패딩] arr에 패딩 넣으면 범위 체크 불필요. 시작 2, 끝 3

### 코드
```python
def dfs1(x, y): # 좌표도 2개 받는다, x, y 좌표
    global ans
    v[x][y] = 1 # 사방 찔러본 게 새로운 위치가 되어야 하겠지?
    for dx, dy in ((0, -1),(0, 1),(-1, 0),(1, 0)): # list의 한 요소는 더해지지가 않고
        # 또 각각 요소 매핑 가능!!!
        nx = x+dx
        ny = y+dy
        # 예외 처리 레쯔고
        if 0 <= nx < size and 0 <= ny < size:
            if v[nx][ny] == 0 and arr[nx][ny] != '1': #str 처리
                dfs1(nx, ny)
                if arr[nx][ny] == '3':
                    ans = 1
                    return
# 탐색
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for tc in range(1, T + 1):
    size = int(input())
    arr = [input() for _ in range(size)] # input 거치면 다 str!!
    # 패딩 말고 예외처리로 풀자
    v = [[0]*size for _ in range(size)]

    sx, sy = 0, 0 # 시작 x, y 좌표
    for i in range(size):
        for j in range(size):
            if arr[i][j] == '2': # 시작 위치
                sx = i
                sy = j
            elif arr[i][j] == '3':
                ex = i
                ey = j

    ans = 0
    dfs1(sx, sy)
    #print(v[ex][ey])
    print(f'#{tc} {ans}')
```
