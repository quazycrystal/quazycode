- [인덱스] 색깔은 1부터

### 코드
```python
# from pprint import pprint
T = int(input())
for tc in range(1, 1+T):
    size, colors, goal_color = map(int, input().split()) # 전체 사이즈, 전체 색깔, 찾을 색깔
    arr = [[0] * size for _ in range(size)]
    for i in range(1, 1 + colors): # 색깔 1부터 임에 주의
        r, c, height, width, color = map(int, input().split())
        for row in range(r, r + height):
            for col in range(c, c + width):
                arr[row][col] = i

    ans = 0
    for rr in arr:
        ans += rr.count(goal_color)

    print(f"#{tc}", ans)


# 문제에는 말이 없으므로 들어오는 순서로 진행
```
