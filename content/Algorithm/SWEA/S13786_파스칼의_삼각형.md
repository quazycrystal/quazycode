### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [범위] segmentation error: idx 넘어감

### 코드 개선 방법
- [패딩] 0 패딩하면 앞 상단 + 상단 합으로 바로 계산

### 코드
```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):
    print(f'#{test_case}')
    n = int(input())
    arr = [[0] * (n+1) for _ in range(n)] # 0 패딩
    arr[0][1] = 1
    for j in range(n+1): #열 반복
        for i in range(1, n): #행
            arr[i][j] = arr[i-1][j-1] + arr[i-1][j]

    for row in arr: # 열별로 본다
        f_row = [x for x in row if x !=0] # 0 거른다
        # 리스트 컴프리헨션
        if f_row:
            print(*f_row)

```
