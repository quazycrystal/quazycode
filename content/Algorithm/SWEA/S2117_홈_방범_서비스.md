### 걸린 시간: 1시간 7분 (구상 14분, 구현 53분), 639ms (실패 횟수: -)

### 실패 / 성공 이유
- [접근] 집 위치를 마름모 중심으로 잡아 짰는데 모든 경우를 못 찾음 → 격자 전체 완탐으로 수정

### 코드 개선 방법
- [완전탐색] 모든 칸을 중심으로 K를 늘려가며 집 수 세기. 집 좌표는 미리 리스트로
- [거리] 마름모는 |dr| + |dc| < K로 판정. 중복 안 세게 조건
- [종료 조건] 모든 집이 비용을 내도 운영비를 감당 못 하면 종료

### 코드
```python
# 함수
def is_range(r, c):
    return 0 <= r < size and 0 <= c < size

# 1. 마름모 사이즈에 맞춰 그리는 함수
def draw(sr, sc, ds):
    benefit = 0
    diff = ds
    for r in range(ds+1):
        ur = sr - r
        dr = sr + r
        for nc in range(sc - diff, sc + diff + 1): # 중복으로 세어짐 ㅠ
            if is_range(ur, nc):
                #arr[ur][nc] = 1
                if houses[ur][nc] == 1:
                    benefit += 1
            if dr != sr: # 요 조건 있어야 중복 안 된다
                if is_range(dr, nc):
                    #arr[dr][nc] = 1
                    if houses[dr][nc] == 1:
                        benefit += 1

        diff -= 1

    return benefit

# 2. 집 갯수와 사이즈 재어서 손해 안 보는지 체크
def ok(ds, benefit):
    need = pow(ds, 2) + pow((ds+1), 2)
    pay_sm = benefit*pay
    # print(pay_sm - need, "ds", ds)
    if pay_sm - need >= 0:
        return True
    else:
        return False

# 3. 집 위치 미리 찾기
def find_home():
    sm = 0
    for r in range(size):
        for c in range(size):
            if houses[r][c] == 1:
                sm += 1
    return sm

# 4. 종료 조건
def finish(ds):
    need = pow(ds, 2) + pow((ds+1), 2)
    pay_sm = home_num*pay
    if pay_sm - need < 0:
        return True
    else:
        return False
# 입력
T = int(input())
for tc in range(1, 1+T):
    size, pay = map(int, input().split())
    houses = [list(map(int, input().split())) for _ in range(size)]

    # 1. 집 갯수
    home_num = find_home()

    # 2. 사이즈 늘려가며 최대 집 찾기
    m_size = 0
    ans = 0 # 최대 집 갯수!
    flag = 0
    while True:
        if finish(m_size): # 종료 조건 - 애들 모두가 돈 내도 운영비 감당 안 될 때
            break

        for i in range(size):
            for j in range(size):
                benefit = draw(i, j, m_size)
                if benefit != 0:
                    if ok(m_size, benefit):
                        ans = max(ans, benefit)

        m_size += 1

    print(f"#{tc}", ans)
```
