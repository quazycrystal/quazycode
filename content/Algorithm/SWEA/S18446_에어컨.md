### 걸린 시간: - (실패 횟수: -)

### 실패 / 성공 이유
- [문제 읽기] 필터 종류 + 1개 존재
- [로직] 누적값으로 비교하면 같은 필터 중복 시 전체 필터 칸과 값이 같아질 수 있음

### 코드 개선 방법
- [자료구조] 각 칸을 set으로 두고 모든 종류가 들어 있는지 확인

### 코드
```python
T = int(input())
for tc in range(1, 1+T):
    row, col, fils, f_types = map(int, input().split())
    arr = [[set() for _ in range(col)] for _ in range(row)]

    # 필터 씌우기
    for _ in range(fils): # 필터 갯수
        f_type, sr, sc, r_size, c_size = map(int, input().split())
        for i in range(sr, sr+r_size):
            for j in range(sc, sc+c_size):
                if 0 <= i < row and 0 <= j < col:
                    arr[i][j].add(f_type) # 현재 필터 종류로 채우는 거

    # 정답
    ans = 0
    for rr in range(row):
        for cc in range(col):
            if len(arr[rr][cc]) < (f_types + 1): # set으로 중복 제거
                # '전체' 필터 종류의 수 = f_type's'
                ans += 1

    print(f"#{tc}", ans)
```
