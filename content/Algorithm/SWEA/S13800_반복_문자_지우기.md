### 코드 개선 방법
- [스택] 비었으면 push, top과 같으면 pop, 아니면 push

### 코드
```python
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for test_case in range(1, T + 1):
    stk = []
    s = input()
    for i in s:
        if not stk: # 스택 빈 경우 push
            stk.append(i)
        else:
            if stk[-1] == i: # 스택 맨 윗 글자와 현재 글자가 같으면 pop
                stk.pop(-1)
            else: # 아니면 push
                stk.append(i)
    print(f'#{test_case} {len(stk)}')

```
