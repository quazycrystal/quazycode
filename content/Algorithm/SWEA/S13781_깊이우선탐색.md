### 실패 / 성공 이유
- [조건] 낮은 번호부터 탐색하려면 인접 노드 sort
- [인접 리스트] 양방향, index 0은 안 씀

### 코드
```python
# 재귀
def dfs(s):
    # 초기화
    v[s] = 1
    ans.append(s)
    # 조건:
    for nxt in adj[s]:
        if v[nxt] == 0: # 다음 노드 방문 안 했으면
            # ans.append(nxt) #위에서 이미 해 주고 있다
            dfs(nxt)
# 양방향!!!
T = int(input())
# 여러개의 테스트 케이스가 주어지므로, 각각을 처리합니다.
for tc in range(1, T + 1):
    ver, edge = map(int, input().split())
    adj = [[] for _ in range(ver+1)] # index 0 안 쓰니까 걍 외워
    for i in range(edge):
        s, e = map(int, input().split())
        adj[s].append(e)
        adj[e].append(s) # 양방향!!!!!

    for j in range(len(adj)):
        adj[j].sort()

    v = [0] * (ver+1)
    ans = []
    dfs(1)
    print(f"#{tc}", *ans)
```
