### 코드 개선 방법
- [백트래킹] 행은 깊이로 고정하고 열만 for, 방문만으로 됨
- [초기화] 최솟값이므로 초기값은 최악의 경우로 크게

### 코드
```python
def btk(n, sm):
    # n줄을 다 보면 종료 n은 행
    global ans
    if n == N:
        ans = min(ans, sm) # 현재 답과 방금 돌아서 더해진 것 중에 더 작은 걸로 바꾼다
        return
    for col in range(N): # 열 갯수 돌면서
        if v[col] == 0:
            v[col] = 1
            btk(n+1, sm + arr[n][col]) # j가 몇 번째 열인지
            v[col] = 0 # append 하고 pop 하듯이 다음 함수 부를 때는 다시 깨끗하게

T = int(input())
for tc in range(1, 1+T):
    N = int(input())
    arr = [list(map(int, input().split())) for _ in range(N)]
    v = [0] * N
    # 답은 최솟값 구하기 이므로 크게, 최악의 경우로 초기값 설정
    ans = 10 * N
    btk(0, 0) # 첫 sm은 0이니까 0부터
    print(f"#{tc}", ans)
```
